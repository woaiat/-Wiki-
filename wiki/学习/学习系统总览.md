# 学习系统总览

这套系统的目标，不是把资料记得更满，而是把学习过程本身做成一个可复用、可诊断、可持续维护的系统。

## 四层结构

- `底座`：统一学习骨架、掌握状态、AI 角色边界。
- `教学引擎`：把“材料输入 -> 预读 -> 带学 -> 检测 -> 回退 -> 沉淀 -> 复习”跑成真正的学习会话。
- `执行模板`：在教学引擎还没完全定义好之前，用学习地图、学习单元、项目卡、复习队列等模板先承接学习动作。
- `程序封装`：桌面端、手机端、自动同步等都属于这一层，但现在不优先。

## 当前阶段判断

- 底座已经成形。
- 教学引擎是当前最重要的未完成部分。
- 执行模板已经可以过渡使用，但不是终点。
- 程序封装暂缓，避免头重脚轻。

## 目标形态

`材料输入 -> 完整预读 -> 正式带课 -> 中途检测 -> 不过线回退 -> 会话结束沉淀 -> 间隔复习`

这个流程成立，才算真的比“网课 + 手写笔记”更强。

## 这个系统为什么值得单独成页

- 它是你旧 vault 里最明显、最有主线意识的一组内容。
- 它连接了“你怎么学”和“AI 应该怎么带你学”。
- 它天然适合作为整个高维 wiki 的方法论主轴。
