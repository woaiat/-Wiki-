# 题型卡：一阶线性方程与常数变易

## 识别信号

- 能整理成 `y' + P(x)y = Q(x)`
- 左边是“导数 + 函数本身乘一个系数”的标准线性结构
- 有时题目会绕一点，但最后仍然是标准化问题

## 首步策略

1. 先把方程整理成标准型。
2. 先解对应齐次方程。
3. 再用常数变易，把常数改成函数，求出一个非齐次特解。
4. 最后记住总结构：`非齐次通解 = 齐次通解 + 特解`

## 代表题：求 `y' - 2y/(x+1) = (x+1)^(5/2)` 的通解

### 思路展开

这题一看就已经是标准型，所以不必再去想能不能分离变量，直接走一阶线性主线最稳。

### 具体过程

1. 先看对应齐次方程：

   `y' - 2y/(x+1) = 0`

   即

   `1/y dy = 2/(x+1) dx`

2. 两边积分：

   `ln y = 2 ln(x+1) + ln C`

   所以齐次通解为

   `y = C(x+1)^2`

3. 对非齐次方程做常数变易，令特解形如

   `y* = u(x)(x+1)^2`

4. 求导：

   `y*' = u'(x)(x+1)^2 + 2u(x)(x+1)`

5. 代回原方程，齐次部分会被抵消，最后只剩

   `u'(x)(x+1)^2 = (x+1)^(5/2)`

   所以

   `u'(x) = (x+1)^(1/2)`

6. 积分得到

   `u(x) = (2/3)(x+1)^(3/2)`

7. 因而特解为

   `y* = (2/3)(x+1)^(3/2)(x+1)^2 = (2/3)(x+1)^(7/2)`

8. 最终通解：

   `y = C(x+1)^2 + (2/3)(x+1)^(7/2)`

### 这一题最该记住什么

- 一阶线性题的核心不是死背公式，而是知道“先齐次，再变常数”。
- 常数变易最有手感的地方，就是代回去后齐次项会自动抵消。

## 为什么这类题容易错

- 没先标准化，就误判成别的题型
- 齐次解写对了，但常数变易代回去时漏项
- 只会背总公式，不知道它和“齐通 + 特解”的关系
