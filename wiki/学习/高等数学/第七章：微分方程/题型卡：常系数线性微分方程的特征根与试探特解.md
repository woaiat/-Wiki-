# 题型卡：常系数线性微分方程的特征根与试探特解

## 识别信号

- 方程是常系数线性微分方程
- 如果右端为 `0`，重点是特征根如何决定齐次通解
- 如果右端不为 `0`，重点是先写齐次通解，再判断特解试探时是否撞根

## 首步策略

1. 先写特征方程。
2. 先搞清楚齐次通解结构。
3. 如果是非齐次，再看右端是什么类型：
   - 多项式 / 指数
   - 三角
   - 指数乘多项式
   - 指数乘三角
4. 最后判断 `λ` 或 `λ ± iω` 是否撞根，决定要不要乘 `x^k`。

## 代表题 1：`y'' - 2y' - 3y = 0`

### 思路展开

这是最标准的常系数齐次线性方程，所以第一步就是设 `y = e^(rx)`，把微分问题转成代数问题。

### 具体过程

1. 设

   `y = e^(rx)`

2. 代入方程，得到特征方程

   `r^2 - 2r - 3 = 0`

3. 因式分解：

   `(r - 3)(r + 1) = 0`

4. 得到两个不同实根：

   `r1 = 3, r2 = -1`

5. 所以对应的两个线性无关解是

   `e^(3x), e^(-x)`

6. 最终通解：

   `y = C1 e^(3x) + C2 e^(-x)`

## 代表题 2：`y'' - 5y' + 6y = x e^(2x)`

### 思路展开

这一题最关键的不是一上来代系数，而是先判断右端 `x e^(2x)` 对应的试探特解是否撞根。

### 具体过程

1. 先解对应齐次方程：

   `r^2 - 5r + 6 = 0`

   即

   `(r - 2)(r - 3) = 0`

   所以齐次通解为

   `Y = C1 e^(2x) + C2 e^(3x)`

2. 再看右端：

   `x e^(2x)`

   这里 `λ = 2`

3. 因为 `2` 正好是特征根里的单根，所以这不是“不撞根”情形，而是“撞单根”。

4. 因而特解不能只设成

   `e^(2x)(ax+b)`

   而必须主动补一个 `x`：

   `y* = x(ax+b)e^(2x) = e^(2x)(ax^2 + bx)`

5. 求导并代回原方程，最后得到系数条件：

   `-2a = 1`

   `2a - b = 0`

   所以

   `a = -1/2, b = -1`

6. 因而特解为

   `y* = e^(2x)(-1/2 x^2 - x)`

7. 最终通解：

   `y = (-1/2 x^2 - x + C1)e^(2x) + C2 e^(3x)`

### 这一题最该记住什么

- 常系数非齐次题，真正的灵魂不是算系数，而是先判断撞不撞根。
- 一旦撞根，`x^k` 不是装饰，而是为了补足线性无关性。

## 为什么这类题容易错

- 齐次通解还没写完，就急着试特解
- 看到 `e^(λx)` 只会机械设壳子，不先检查 `λ` 是否是特征根
- 碰到重根时，不知道为什么要乘更高次的 `x`
