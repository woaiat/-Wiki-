# 微分方程补充方法：微分算子法

## 这是什么

微分算子法，是把线性非齐次微分方程写成算子形式来做特解的一种快捷组织方法。

如果把方程写成：

`P(D)y = f(x)`

其中 `D` 表示求导算子，那么特解可以形式化地写成：

`y* = 1 / P(D) · f(x)`

它的价值不在于把问题变神秘，而在于把“不同右端该怎么试特解”这件事整理得更统一。

## 什么时候适合用

这套方法最适合处理常系数线性非齐次微分方程，尤其是右端属于这些类型时：

- `e^{kx}`
- `sin βx`、`cos βx`
- 多项式 `P_n(x)`
- `e^{kx}` 与三角函数、多项式的乘积

如果右端正好落在这些标准族里，微分算子法通常能比纯手推更快看出特解形式。

## 核心思路

### 1. 先把方程写成 `P(D)y = f(x)`

- `Dy = y'`
- `D^2 y = y''`
- 所以像 `y'' + py' + qy = f(x)` 可以写成 `P(D)y = (D^2 + pD + q)y = f(x)`

### 2. 再根据右端类型选规则

- 对指数函数：`P(D)e^{kx} = P(k)e^{kx}`
- 对三角函数：常把 `D^2` 代成 `-k^2`
- 对带指数的右端：用平移公式把 `D` 换成 `D + k`
- 对多项式：把 `1 / P(D)` 做有限展开

### 3. 最后先算特解，再回代检查

这一步不能省。算子法是捷径，不是免检通行证。

## 最关键的判断点：有没有共振

最容易出错的地方，是你直接把 `D` 代进去，结果发现分母为零。

这本质上就是：

- 右端里的指数或三角频率，撞上了齐次方程的特征根
- 也就是常说的“共振”或“重根修正”问题

这时不能再直接写：

`y* = e^{λx} / P(λ)`

而要改成：

- 先看 `λ` 是 `P(D)` 的几重根
- 再额外乘上 `x^m`
- 分母改看相应阶数的导数

你可以把它粗暴地记成一句话：

`撞根了，就先提 x；撞了几次，就提几次。`

## 这篇笔记真正帮你整理出来的 4 类情形

### 指数型右端

当右端是 `A e^{kx}` 时，优先尝试直接代入 `P(k)`。

如果 `P(k) ≠ 0`，通常最省事。
如果 `P(k) = 0`，就进入重根修正。

### 三角型右端

当右端是 `sin βx / cos βx` 时，核心是把它们看成与 `D^2` 的作用有关。

如果对应频率撞根，也要做修正，不能硬代。

### 多项式型右端

当右端是多项式时，可以把 `1 / P(D)` 展成有限算子展开，然后逐项作用到多项式上。

这种情况的优势是：

- 高阶导数最终会消失
- 所以展开不会无限拖下去

### 指数乘三角 / 多项式

这类右端最适合用平移公式先把 `e^{kx}` 提出来，再把问题还原成前面几类。

也就是先降成你熟悉的“纯三角”或“纯多项式”问题。

## 这页的实际用途

这页不是拿来替代课本定义的，而是拿来做这三件事：

1. 快速判断某类右端应该往哪条特解路线走
2. 提醒自己什么时候会撞根，需要修正
3. 把零散例题背后的共同结构收拢成一个方法页

## 目前边界

- 这页只管“特解怎么组织”，不负责完整通解。
- 齐次方程、特征方程、通解结构，仍然是前置基础。
- 如果推导太跳，优先回到原始定义或待定系数法做交叉校验。
