# 题型卡：伯努利方程的线性化

## 识别信号

- 方程能写成 `y' + P(x)y = Q(x)y^n`
- 且 `n ≠ 0, 1`
- 表面是非线性，但通过代换能回到一阶线性方程

## 首步策略

1. 先把方程写成伯努利标准型。
2. 两边除以 `y^n`。
3. 令 `z = y^(1-n)`。
4. 把它改写成关于 `z` 的一阶线性方程，再按线性方法求解。

## 代表题：`y' + y/x = a ln x · y^2`

### 思路展开

这题最重要的不是马上算，而是先看出右边有 `y^2`，所以它已经不是普通线性方程，但又非常像“线性 + 一个幂次偏差”，这正是伯努利的标志。

### 具体过程

1. 原方程是

   `y' + (1/x)y = a ln x · y^2`

   这里 `n = 2`

2. 两边除以 `y^2`：

   `y^(-2) y' + (1/x) y^(-1) = a ln x`

3. 令

   `z = y^(-1)`

   则

   `z' = -y^(-2) y'`

4. 代回去得到

   `-z' + (1/x)z = a ln x`

   即

   `z' - (1/x)z = -a ln x`

5. 这时它已经变成一阶线性方程。

6. 按线性方程公式求解，得到

   `z = x[-(a/2) ln^2 x + C]`

7. 再还原回 `y`：

   `y = 1 / {x[C - (a/2) ln^2 x]}`

### 这一题最该记住什么

- 伯努利方程的本质不是又多了一套新公式，而是“先线性化，再回到一阶线性主线”。
- 真正要有反应的是 `y^n` 这个信号，而不是题目长相本身。

## 为什么这类题容易错

- 看见非线性就慌，没有先识别伯努利标准型
- 设了 `z = y^(1-n)`，但导数关系写错
- 线性化成功后，又不会接回一阶线性方法
