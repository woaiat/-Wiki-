# 题型卡：可分离变量方程

## 识别信号

- 方程能直接改写成 `g(y)dy = f(x)dx`
- 或者整理之后，`x` 的东西和 `y` 的东西可以明确拆到两边
- 有时还会带初值条件，先求通解，再代初值定常数

## 首步策略

1. 先看能不能直接分离变量。
2. 如果分离时要除以某个表达式，先想一下会不会漏掉零解或特殊解。
3. 分离以后就是两边积分，再把常数并回去。

## 代表题 1：求通解 `dy/dx = 2xy`

### 思路展开

第一眼先不急着积分，先注意这里如果直接除以 `y`，会不会漏掉 `y = 0`。

### 具体过程

1. 当 `y = 0` 时，

   `dy/dx = 0 = 2x · y`

   所以 `y = 0` 本身就是原方程的一个解。

2. 当 `y ≠ 0` 时，才能安全地除以 `y`：

   `1/y dy = 2x dx`

3. 两边积分：

   `∫(1/y)dy = ∫2x dx`

   得

   `ln|y| = x^2 + C1`

4. 指数化并把常数吸收：

   `|y| = e^C1 · e^(x^2)`

   所以可写成

   `y = C e^(x^2)`

### 这一题最该记住什么

- 真正的关键不是积分本身，而是“分离前先检查会不会漏特殊解”。
- 很多可分离变量题，难度就卡在这一步的意识上。

## 代表题 2：`xy' + y = 0`，满足 `y(1) = 1` 的特解

### 思路展开

这题本质上仍然是可分离变量，只不过最后多了一个“代初值定常数”的步骤。

### 具体过程

1. 原方程改写成

   `y' = -y/x`

2. 分离变量：

   `-1/y dy = 1/x dx`

3. 两边积分：

   `-ln y = ln x + ln C`

4. 改写后得到

   `ln(1/y) = ln x`

   所以

   `y = C/x`

5. 代入初值 `y(1) = 1`：

   `1 = C/1`

   所以 `C = 1`

6. 最终特解：

   `y = 1/x`

### 这一题最该记住什么

- 可分离变量题加初值，并没有换方法，只是多了一步“把通解收缩成特解”。
- 所以真正的主线始终还是：分离 -> 积分 -> 代条件。

## 为什么这类题容易错

- 一上来就除以 `y`、`x`，忘记检查会不会漏特殊解
- 积分后常数处理混乱
- 求的是特解，却停在通解
