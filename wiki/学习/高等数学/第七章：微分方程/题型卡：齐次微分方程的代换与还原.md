# 题型卡：齐次微分方程的代换与还原

## 识别信号

- 右端能整理成 `φ(y/x)`
- 或者分子分母同时能按同次齐次式约成 `y/x` 的函数
- 这类题表面复杂，但核心都在“先把比例变量抽出来”

## 首步策略

1. 先确认右端是不是只依赖 `y/x`。
2. 如果是，就令 `u = y/x`，也就是 `y = ux`。
3. 把 `y'` 改写成 `u + x du/dx`，再回到可分离变量。

## 代表题：求通解 `y^2 + x^2 y' = xy y'`

### 思路展开

这一题第一眼最重要的不是硬移项，而是看出右端最后能写成 `y/x` 的函数，所以它不是普通代数整理题，而是齐次微分方程。

### 具体过程

1. 先把方程改写成显式导数形式：

   `y' = y^2 / (xy - x^2)`

2. 把分子分母都除以 `x^2`：

   `y' = (y/x)^2 / ((y/x) - 1)`

   到这里就能确认：右端只依赖 `y/x`。

3. 令

   `u = y/x`

   则

   `y = ux`

   并且

   `y' = u + x du/dx`

4. 代回原方程：

   `u + x du/dx = u^2 / (u - 1)`

5. 整理得到

   `x du/dx = u^2/(u-1) - u = u/(u-1)`

6. 分离变量：

   `dx/x = (u-1)/u du`

7. 两边积分：

   `ln x = u - ln u + C`

8. 把 `u = y/x` 代回去：

   `ln x + ln(y/x) = y/x + C`

   所以

   `ln y = y/x + C`

9. 指数化后可写成

   `y = C e^(y/x)`

### 这一题最该记住什么

- 齐次方程真正的难点不是积分，而是“看出它只依赖 `y/x`”。
- 一旦代换成功，后面其实又回到了可分离变量。

## 为什么这类题容易错

- 没先把式子化成 `y/x` 的函数，就误判成别的题型
- 会设 `u = y/x`，但忘了 `y' = u + x du/dx`
- 积分完以后不会把 `u` 还原回 `y/x`
