# 常系数齐次线性微分方程的特征根映射

## 这是什么

这页把“微分方程 -> 特征方程 -> 根的类型 -> 通解项”这条最稳定的映射关系固定下来。

## 什么时候用

- 方程是常系数齐次线性方程时。
- 需要从根的重数和类型直接写通解结构时。
- 非齐次特解要判断有没有撞根时。

## 核心结构

### 1. 先把微分问题变成代数问题

设 `y = e^(rx)` 后，原方程会落到特征方程上。后面的关键不是再做微分，而是读根。

### 2. 根型和通解项的一一对应

- 不同实根 `r`：对应 `e^(rx)`
- `k` 重实根 `r`：对应 `(C1 + C2x + ... + Ck x^(k-1)) e^(rx)`
- 共轭复根 `α ± βi`：对应 `e^(αx)(C1 cos βx + C2 sin βx)`
- 重共轭复根：在上式外再乘多项式链 `1, x, ..., x^(k-1)`

### 3. 真正要记的是“根的重数如何变成自由度”

一旦出现重根，单个指数项给不够线性无关解，所以必须补上 `x` 的幂次链。

## 最小工作例题

例如

`y'' - 3y' + 2y = 0`

特征方程是

`r^2 - 3r + 2 = 0`

有两个不同实根 `1, 2`，所以通解直接写成

`y = C1 e^x + C2 e^(2x)`

这个例子最重要的作用是让我把“微分方程先转成代数根，再由根反推通解”这条映射先踩实。

## 当前边界

- 这页只处理常系数齐次主线，不处理变系数情形。
- 这里的根型判断会直接外溢到非齐次试探特解里的共振判断。
