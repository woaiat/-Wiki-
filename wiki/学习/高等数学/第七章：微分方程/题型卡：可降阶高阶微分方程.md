# 题型卡：可降阶高阶微分方程

## 识别信号

- 右端只含 `x`，如 `y^(n) = f(x)`
- 方程缺 `y`
- 方程缺 `x`

这类题的共同点不是“长得像某个标准公式”，而是“高阶结构里少了一个变量，所以能降阶”。

## 首步策略

1. 先判断到底是哪一种降阶：
   - 直接连续积分
   - 缺 `y`，令 `y' = p(x)`
   - 缺 `x`，令 `y' = p(y)`，再用 `y'' = p dp/dy`
2. 降完一级以后，再按一阶方法做。
3. 最后别忘了把积分链收回来。

## 代表题 1：初值问题 `(x^2+1)y'' = 2xy'，y(0)=1，y'(0)=3`

### 思路展开

这题虽然是二阶，但右边没有直接出现 `y`，所以不是去找特征方程，而是先看出它属于“缺 `y` 型”。

### 具体过程

1. 令

   `y' = p`

   则

   `y'' = p'`

2. 原方程变成

   `p' = (2x/(x^2+1)) p`

3. 分离变量：

   `dp/p = 2x/(x^2+1) dx`

4. 两边积分：

   `ln p = ln(x^2+1) + ln C1`

   所以

   `y' = C1(x^2+1)`

5. 代入初值 `y'(0)=3`：

   `3 = C1`

   所以

   `y' = 3(x^2+1)`

6. 再积分一次：

   `y = x^3 + 3x + C2`

7. 代入 `y(0)=1`：

   `C2 = 1`

8. 最终结果：

   `y = x^3 + 3x + 1`

## 代表题 2：`y y'' - y'^2 = 0`

### 思路展开

这题没有 `x`，所以重点不是把 `y'` 看成关于 `x` 的函数，而是把它改写成关于 `y` 的函数。

### 具体过程

1. 令

   `y' = p`

   则

   `y'' = p dp/dy`

2. 原方程变成

   `y · p dp/dy = p^2`

3. 若 `p ≠ 0`，可化成

   `dp/p = dy/y`

4. 两边积分：

   `p = C1 y`

5. 还原成

   `dy/dx = C1 y`

6. 再分离变量：

   `dy/y = C1 dx`

7. 积分得到

   `ln y = C1 x + ln C2`

8. 最终写成

   `y = C2 e^(C1 x)`

### 这一题最该记住什么

- “缺 `y`”和“缺 `x`”虽然都叫降阶，但换元方向完全不同。
- 真正的记忆抓手不是答案，而是看到少谁，就知道先把谁对应的结构压掉。

## 为什么这类题容易错

- 没先分清是“缺 `y`”还是“缺 `x`”
- 会设 `y' = p`，但不会把 `y''` 改成 `p dp/dy`
- 降了一阶后忘了还要再积分一次
