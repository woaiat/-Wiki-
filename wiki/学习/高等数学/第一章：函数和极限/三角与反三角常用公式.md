# 三角与反三角常用公式

## 这是什么

这页不是为了背公式本身，而是为了把后面极限、导数、积分、微分方程里会反复调用的那批三角工具收成一个稳定节点。

## 什么时候用

- 看到三角函数极限时。
- 需要化简和差、积化和差、半角结构时。
- 右端含 `sin`、`cos` 的微分方程判型时。

## 核心公式组

### 1. 和差化积

- `sin x + sin y = 2 sin((x+y)/2) cos((x-y)/2)`
- `sin x - sin y = 2 cos((x+y)/2) sin((x-y)/2)`
- `cos x + cos y = 2 cos((x+y)/2) cos((x-y)/2)`
- `cos x - cos y = -2 sin((x+y)/2) sin((x-y)/2)`

### 2. 积化和差

- `sin x cos y = [sin(x+y) + sin(x-y)] / 2`
- `cos x cos y = [cos(x+y) + cos(x-y)] / 2`
- `sin x sin y = [cos(x-y) - cos(x+y)] / 2`

### 3. 半角与万能公式

- `tan(x/2) = sin x / (1 + cos x) = (1 - cos x) / sin x`
- 若 `t = tan(x/2)`，则
  - `sin x = 2t / (1+t^2)`
  - `cos x = (1-t^2) / (1+t^2)`
  - `tan x = 2t / (1-t^2)`

### 4. 反三角的最常用约束

- `arcsin x` 的值域是 `[-π/2, π/2]`
- `arccos x` 的值域是 `[0, π]`
- `arctan x` 的值域是 `(-π/2, π/2)`
- `arcsin x + arccos x = π/2`

## 为什么这一页值得独立存在

- 第一章里大量等价无穷小都建立在三角函数母式上。
- 第七章常系数非齐次微分方程里，右端若含 `sin / cos`，也会回到频率与形式判断。
- 后面的导数与积分同样会频繁回调这一页。
