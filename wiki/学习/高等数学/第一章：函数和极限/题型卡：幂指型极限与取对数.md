# 题型卡：幂指型极限与取对数

## 识别信号

- 结构形如 `1^∞`、`0^0`、`∞^0`
- 底数和指数都在变
- 这类题如果直接代入，通常只会看到未定式，不会看到真正主项

## 首步策略

1. 先设整个式子为 `y`
2. 对两边取对数，变成

   `ln y = 指数 · ln(底数)`

3. 先求 `ln y` 的极限
4. 最后再指数化还原 `y`

## 代表题 1：`lim ((1 + tan x)/(1 + sin x))^(1/x^3), x -> 0`

### 思路展开

这题第一眼就该有反应：指数 `1/x^3` 发散，而底数趋近于 `1`，这就是典型的 `1^∞`。

所以别在原式上硬碰，直接取对数。

### 具体过程

1. 设

   `y = ((1 + tan x)/(1 + sin x))^(1/x^3)`

2. 取对数：

   `ln y = (1/x^3) ln((1 + tan x)/(1 + sin x))`

3. 当 `x -> 0` 时，`ln(1+u) ~ u`，所以

   `ln((1 + tan x)/(1 + sin x)) ~ tan x - sin x`

   更精确一点写，就是

   `ln((1 + tan x)/(1 + sin x)) ~ (tan x - sin x)/(1 + sin x)`

4. 所以

   `ln y ~ (1/x^3) · ((tan x - sin x)/(1 + sin x))`

5. 再展开：

   `tan x = x + x^3/3 + o(x^3)`

   `sin x = x - x^3/6 + o(x^3)`

   因而

   `tan x - sin x ~ x^3/2`

6. 所以

   `ln y -> 1/2`

7. 最终

   `y -> e^(1/2)`

### 这一题最该记住什么

- 幂指型极限真正要算的不是原式，而是 `ln y`
- 取对数以后，题目本质通常会掉回“主项比较”

## 代表题 2：`lim x^(sin x), x -> 0+`

### 思路展开

这题表面看像 `0^0`，但一样遵循幂指型统一套路：先取对数。

### 具体过程

1. 设

   `y = x^(sin x)`

2. 取对数：

   `ln y = sin x · ln x`

3. 当 `x -> 0+` 时，

   `sin x ~ x`

   所以

   `sin x · ln x ~ x ln x`

4. 又因为

   `x ln x -> 0`

   所以

   `ln y -> 0`

5. 因而

   `y -> e^0 = 1`

### 这一题最该记住什么

- 只要是幂指型，先别管它看起来像什么，统一先取对数。
- 很多题看起来复杂，其实只是取对数后的一个简单乘积极限。

## 为什么这类题容易错

- 看到 `1^∞`、`0^0` 还想直接代
- 取对数以后不会把 `ln(1+u)` 再压成 `u`
- `ln y` 算出来了，却忘了最后还要指数化
