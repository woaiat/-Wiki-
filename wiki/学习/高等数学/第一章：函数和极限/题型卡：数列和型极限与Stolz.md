# 题型卡：数列和型极限与Stolz

## 识别信号

- 题目对象从函数切到数列
- 有大和式、递推、`n` 次方根、比值极限
- 这类题往往不靠单一展开，而是靠夹逼、积分定义、Stolz 或递推结构

## 首步策略

1. 先看是不是“和式像积分”。
2. 如果是两列比值并且都发散，考虑 Stolz。
3. 如果是递推，优先看能不能转成更稳定的新量。

## 代表题 1：`lim Σ(i/n^2) sin(i/n), i=1..n`

### 思路展开

这题最核心的判断是：它像一个黎曼和，不要把它当普通代数和式去硬算。

### 具体过程

1. 原和式写成

   `Σ [ (i/n) sin(i/n) ] · (1/n )`

2. 这里

   `i/n`

   正好在 `[0,1]` 上取点，而 `1/n` 是小区间长度

3. 所以它正对应积分

   `∫_0^1 x sin x dx`

4. 直接积分：

   `∫ x sin x dx = -x cos x + sin x`

5. 代入 `0` 到 `1`：

   `sin 1 - cos 1`

### 这一题最该记住什么

- 数列和型极限里，能看出黎曼和，题就已经做完一大半了。
- 真正的难点是把和式重写成“函数值 × 区间长度”。

## 代表题 2：已知 `a_(n+1) = a_n + 1/a_n`，证明 `lim a_n / sqrt(2n) = 1`

### 思路展开

这题直接看 `a_n` 不好办，但递推里既有 `a_n` 又有 `1/a_n`，很自然会想到平方化，把它揉成更稳定的量。

### 具体过程

1. 先看

   `a_(n+1)^2 = (a_n + 1/a_n)^2 = a_n^2 + 2 + 1/a_n^2`

2. 所以

   `a_(n+1)^2 - a_n^2 = 2 + 1/a_n^2`

3. 于是考虑极限

   `a_n^2 / (2n)`

4. 这时可用 Stolz 定理：

   `lim a_n^2 / (2n) = lim (a_(n+1)^2 - a_n^2) / (2n+2 - 2n)`

5. 代入差分式：

   `= lim (2 + 1/a_n^2) / 2 = 1`

6. 因而

   `a_n^2 / (2n) -> 1`

   最终得到

   `a_n / sqrt(2n) -> 1`

### 这一题最该记住什么

- 递推题很多时候不是直接攻原量，而是先换成更稳的新量。
- Stolz 真正适合的是“分子分母都在增长，而且差分更容易算”的场景。

## 为什么这类题容易错

- 和式题不会主动往黎曼和想
- 递推题死盯 `a_n` 本身，不肯换量
- Stolz 的适用场景判断不清
