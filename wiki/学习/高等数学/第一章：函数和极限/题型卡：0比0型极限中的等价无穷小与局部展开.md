# 题型卡：0比0型极限中的等价无穷小与局部展开

## 识别信号

- 极限点多半在 `x -> 0`
- 分子分母都趋于 `0`
- 结构里混有 `sin x`、`cos x`、`ln(1+x)`、`e^x-1`、`arcsin x` 这类经典局部展开对象
- 这类题通常不是硬做代数，而是靠“抓主导小量”

## 首步策略

1. 先判断能不能直接拆成几块经典无穷小。
2. 如果能，就优先用等价无穷小或局部展开去抓主项。
3. 如果有相消结构，要特别注意保留到足够阶数，不能换得太快。

## 代表题 1：`lim (e^(x^2) - cos x) / (x sin x), x -> 0`

### 思路展开

这题第一眼的关键是：分子不是一个整体去做，而是拆成两块熟对象。

`e^(x^2) - cos x = (e^(x^2)-1) + (1-cos x)`

这样马上就能接上第一章最常用的局部展开。

### 具体过程

1. 原式改写成

   `(e^(x^2)-1 + 1-cos x) / (x sin x)`

2. 在 `x -> 0` 时，

   - `e^(x^2)-1 ~ x^2`
   - `1-cos x ~ x^2/2`
   - `sin x ~ x`

3. 所以分子主项是

   `x^2 + x^2/2 = 3x^2/2`

4. 分母主项是

   `x · x = x^2`

5. 因而极限为

   `(3x^2/2) / x^2 = 3/2`

### 这一题最该记住什么

- 遇到复杂分子，先拆成熟悉的局部块。
- 真正快的地方不是“公式多”，而是会不会把复杂式子改写成能直接用经典等价的小块。

## 代表题 2：`lim (x - arcsin x) / ((1 - sqrt(cos x)) sin x), x -> 0`

### 思路展开

这题的难点在于分子和分母都不是最常见的一阶结构，必须先分别抓它们的主项阶数。

### 具体过程

1. 先看分子：

   `arcsin x = x + x^3/6 + o(x^3)`

   所以

   `x - arcsin x ~ -x^3/6`

2. 再看分母里的

   `1 - sqrt(cos x)`

   可以先用

   `1 - sqrt(1+u) ~ -u/2`

   这里 `u = cos x - 1 ~ -x^2/2`

   所以

   `1 - sqrt(cos x) ~ x^2/4`

3. 又因为

   `sin x ~ x`

   所以分母主项为

   `(x^2/4) · x = x^3/4`

4. 原式极限就变成

   `(-x^3/6) / (x^3/4) = -2/3`

### 这一题最该记住什么

- 难题里真正值钱的是“先分块估阶，再做比值”。
- 不是所有题都能一步看出答案，但多数题都能先看出主项阶数。

## 为什么这类题容易错

- 看到 `0/0` 就只想洛必达，不先看主项结构
- 相消结构里保留阶数不够
- 会背等价无穷小，但不会组合使用
