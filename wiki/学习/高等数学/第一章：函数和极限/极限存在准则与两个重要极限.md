# 极限存在准则与两个重要极限

## 这是什么

这页处理的不是“怎么算极限”，而是“极限为什么存在”，以及两个几乎贯穿整本高数的重要锚点极限。

## 什么时候用

- 题目里有震荡、夹逼、求和或递推时。
- 直接算不动，但能先证明极限存在时。
- 需要把三角、指数和 `1^\infty` 型极限统一收进一套框架时。

## 核心结构

### 1. 夹逼准则

当一个量本身不好直接算，但能被两个同极限的量夹住时，优先考虑夹逼。

### 2. 单调有界准则

递推数列最常见的路线不是硬算，而是先证：

- 单调
- 有界

然后再设极限求方程。

### 3. 柯西准则

它给出的不是显式极限值，而是“收敛的内部判据”。当题目强调数列自身的稳定性时，这条准则很重要。

### 4. 第一个重要极限

`sin x / x -> 1` 是三角函数进入极限体系的入口。后面很多等价无穷小、本质导数和三角化简都会回到它。

### 5. 第二个重要极限

`(1 + 1/x)^x -> e` 是指数极限和 `1^\infty` 型处理的基础母式。很多幂指型化简，本质上都在往它靠。

## 最小工作例题

例如

`lim (sin x) / x, x -> 0`

这题的值并不靠“代进去”得到，而是靠第一个重要极限直接锁住为 `1`。它的意义不只是会做这一题，而是提醒我：只要后面看到三角函数在 `0` 附近参与极限，很多化简最后都会往这个锚点上靠。

## 容易混的点

- “会算”不等于“知道为什么存在”。
- 单调有界准则最怕只证单调不证有界，或者反过来。
- `1^\infty` 型别直接带进去，通常要先转成指数形式。
