# 题型卡：0比0型极限中的积分与复合结构

## 识别信号

- 题里出现定积分上下限也在变
- 指数、对数、三角套在一起，局部结构不止一层
- 表面还是 `0/0`，但核心在于“先把积分核或复合层拆出来”

## 首步策略

1. 如果出现积分，先看积分核能不能等价替换，再积分。
2. 如果是复合函数，先把最内层的小量单独抽出来。
3. 尽量把“复杂整体”变成“经典主项 + 小修正”。

## 代表题 1：`lim ∫_0^(x^2)(e^(t^2)-1)dt / ln(1+x^6), x -> 0`

### 思路展开

这题的难点不是积分技巧，而是意识到：极限点很小时，积分核 `e^(t^2)-1` 本身就可以先近似。

### 具体过程

1. 当 `t -> 0` 时，

   `e^(t^2) - 1 ~ t^2`

2. 所以分子可先近似为

   `∫_0^(x^2) t^2 dt`

3. 直接积分：

   `∫_0^(x^2) t^2 dt = (1/3)(x^2)^3 = x^6/3`

4. 再看分母：

   `ln(1+x^6) ~ x^6`

5. 所以极限就是

   `(x^6/3) / x^6 = 1/3`

### 这一题最该记住什么

- 变上限积分题，常常不是先微积分技巧，而是先把被积函数做局部等价。
- 一旦核函数被压成最简单主项，整个题就会非常清楚。

## 代表题 2：`lim (e^(sin x) - e^(x cos x)) / x^3, x -> 0`

### 思路展开

这题如果硬拆两个指数，很容易乱。真正快的想法是：把两个指数的差，改写成“一个指数因子乘上一个经典 `e^u - 1` 结构”。

### 具体过程

1. 原式改写为

   `e^(x cos x) · (e^(sin x - x cos x) - 1) / x^3`

2. 因为 `x -> 0` 时

   `e^(x cos x) -> 1`

   所以关键只剩

   `(e^(sin x - x cos x) - 1) / x^3`

3. 令

   `u = sin x - x cos x`

   当 `x -> 0` 时，`u -> 0`

   所以

   `e^u - 1 ~ u`

4. 原式就转成

   `(sin x - x cos x) / x^3`

5. 再展开：

   `sin x = x - x^3/6 + o(x^3)`

   `x cos x = x(1 - x^2/2 + o(x^2)) = x - x^3/2 + o(x^3)`

6. 所以

   `sin x - x cos x ~ (-1/6 + 1/2)x^3 = x^3/3`

7. 因而极限为

   `1/3`

### 这一题最该记住什么

- 复合结构最怕硬拆，最快的路往往是先抽出一个标准小量 `u`。
- `e^u - 1 ~ u` 这种替换，本质上就是把复杂复合差转回经典局部结构。

## 为什么这类题容易错

- 一看到积分就想上洛必达
- 复合指数差不会转成 `e^u - 1`
- 会局部展开，但不会先抓“最内层小量”
