# 题型卡：无穷减无穷型极限

## 识别信号

- 结构形如 `A - B`
- 两部分单独看都发散或都很大
- 真正关键不是分别算，而是先重组成同一个分式或同一个主项框架

## 首步策略

1. 先别分别求极限，那样通常没有意义。
2. 优先考虑：
   - 通分
   - 有理化
   - 抓共同主项
3. 把“两个大东西相减”改写成“一个可控的小差商”。

## 代表题 1：`lim (1/ln(1+x) - 1/x), x -> 0`

### 思路展开

这题最典型的点在于：两个部分各自都发散，必须先通分，把问题改成一个真正能比较主项的分式。

### 具体过程

1. 先通分：

   `(1/ln(1+x) - 1/x) = (x - ln(1+x)) / (x ln(1+x))`

2. 当 `x -> 0` 时，

   `ln(1+x) ~ x`

   所以分母主项是

   `x · x = x^2`

3. 再看分子：

   `ln(1+x) = x - x^2/2 + o(x^2)`

   所以

   `x - ln(1+x) ~ x^2/2`

4. 因而整个极限为

   `(x^2/2) / x^2 = 1/2`

### 这一题最该记住什么

- `∞ - ∞` 型不是算两个无限大，而是先把它们揉成一个可比结构。
- 通分之后，往往就回到了“主项比较”的老路。

## 代表题 2：`lim (sqrt(n + 3sqrt(n)) - sqrt(n - sqrt(n))), n -> ∞`

### 思路展开

这里两个根式直接相减最不稳，第一反应应该是有理化。

### 具体过程

1. 乘以共轭：

   `sqrt(n + 3sqrt(n)) - sqrt(n - sqrt(n))`

   `= 4sqrt(n) / (sqrt(n + 3sqrt(n)) + sqrt(n - sqrt(n)))`

2. 当 `n -> ∞` 时，分母两项都和 `sqrt(n)` 同阶

3. 所以分母主项约为

   `sqrt(n) + sqrt(n) = 2sqrt(n)`

4. 极限就是

   `4sqrt(n) / 2sqrt(n) = 2`

### 这一题最该记住什么

- 根式差看到就要想到有理化。
- 很多 `∞ - ∞` 型，真正的技术动作就是把危险减法变成稳定除法。

## 为什么这类题容易错

- 不先重组，直接对每一项各算各的
- 通分后又忘了继续抓主项
- 根式差不会第一时间想到有理化
