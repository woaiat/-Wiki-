# 第七章笔记：树和二叉树

这一章是非线性结构真正展开的一章。前面的线性表、栈、队列，核心都是“一条线”；而树开始进入**层次关系、父子关系、兄弟关系**。

这一章真正要掌握的主线是：

1. 什么是树，什么是非线性结构；
2. 树有哪些基本术语和性质；
3. 树如何存储；
4. 二叉树和一般树有什么本质区别；
5. 二叉树有哪些重要性质；
6. 二叉树的存储、遍历、构造和转换是怎么做的。

这一章内容很多，但逻辑很整齐。你要一直抓住一句话：

**树处理的是“层次关系”，二叉树处理的是“带左右次序的层次关系”。**

---

## 7.1 树的概念

### 7.1.1 树的定义

#### 原理：树到底是什么

课件给了两种定义方式，本质是一回事。

**形式化定义：**

树 `T = {D, R}`，其中：

- `D` 是包含 `n` 个结点的有限集合；
- 若 `n = 0`，则为空树；
- 若 `n > 0`，则有且仅有一个结点没有前驱，这个结点叫根结点；
- 除根结点外，每个结点有且仅有一个前驱；
- 每个结点可以有零个或多个后继。

**递归定义：**

树是由 `n(n>=0)` 个结点组成的有限集合。若 `n=0`，则为空树；若 `n>0`，则存在一个唯一根结点，其余结点被分成 `m(m>=0)` 个互不相交的有限子集 `T1,T2,...,Tm`，每个子集本身又是一棵树。

#### 直觉理解

树和线性表最大的区别在于：

- 线性表是一维顺序关系；
- 树是分支层次关系。

比如中国行政区划：

中国 → 省 → 市 → 区县

这就天然是树。

#### 结论

<span class="kp">树是一种非线性结构，用来表示元素之间的分支和层次关系。</span>

<blockquote>易错：树中除根结点外，每个结点只能有一个前驱，但可以有多个后继。</blockquote>

---

### 7.1.2 树的逻辑表示

课件列了 4 种逻辑表示法。

#### 1. 树形表示法

最直观，直接画出层次结构。

#### 2. 文氏图表示法

用集合包含关系表示树。

#### 3. 凹入表示法

用缩进、层次排列来表示父子关系，比如论文目录、文件目录。

#### 4. 括号表示法

用一个字符串表示树，基本形式：

`根(子树1, 子树2, ..., 子树m)`

例如：

`A(B(E,F), C(G(J)), D(H, I(K,L,M)))`

#### 小结

这四种表示法里，考试最常用的是：

- 树形表示法
- 括号表示法

因为后面很多题都会直接给你括号表示法，让你判断根、叶子、孩子、祖先、树高等。

### 7.1.3 树的基本术语

这一部分一定要熟，因为后面所有题目都在用这些术语。

#### 1. 结点的度与树的度

- 一个结点的**子树个数**，称为该结点的**度**。
- 树中各结点度的最大值，称为**树的度**。
- 度为 `m` 的树，称为 `m` 次树。

#### 2. 分支结点与叶结点

- 度不为 0 的结点，叫**分支结点**（非终端结点）。
- 度为 0 的结点，叫**叶结点**（终端结点）。

#### 3. 路径与路径长度

- 从一个结点到另一个结点所经过的结点序列，叫**路径**。
- 路径长度 = 路径上的分支数 = 经过结点数 - 1。

#### 4. 孩子结点、双亲结点、兄弟结点

- 某结点的后继，叫它的**孩子结点**；
- 某结点的前驱，叫它的**双亲结点**；
- 具有同一双亲的孩子结点互为**兄弟结点**。

#### 5. 子孙结点与祖先结点

- 某结点所有子树中的结点，叫它的**子孙结点**；
- 从根到该结点路径上经过的结点，叫它的**祖先结点**。

#### 6. 结点层次与树高

- 根结点在第 1 层；
- 某结点的层次 = 其双亲结点层次 + 1；
- 树中结点的最大层次，叫树的**高度**（或深度）。

#### 7. 有序树与无序树

- 若各结点的子树从左到右有固定次序，称为**有序树**；
- 否则称为**无序树**。

#### 8. 森林

`m(m>=0)` 棵互不相交的树的集合叫**森林**。

把一棵树的根结点删掉，就得到一个森林。

### 7.1.4 树的性质

这一部分特别重要，很多选择题、填空题、大题都靠它。

#### 性质 1：结点数 = 所有结点度数之和 + 1

也就是：

`n = 度之和 + 1`

为什么？

因为：

- 每一条分支都对应某个结点贡献的一个“度”；
- 树中分支数 = 所有结点度之和；
- 但树中分支数永远等于 `结点数 - 1`。

所以：

`度之和 = n - 1`

于是：

`n = 度之和 + 1`

#### 应用式子

若树的度是 `m`，记：

- `n0`：度为 0 的结点数
- `n1`：度为 1 的结点数
- ...
- `nm`：度为 m 的结点数

则：

- `n = n0 + n1 + ... + nm`
- `n1 + 2n2 + ... + m*nm = n - 1`

这两式是解题基础。

#### 性质 2：度为 m 的树，第 i 层至多有 `m^(i-1)` 个结点

这里根为第 1 层。

- 第 1 层最多 1 个
- 第 2 层最多 `m`
- 第 3 层最多 `m^2`
- ...
- 第 i 层最多 `m^(i-1)`

#### 性质 3：高度为 h 的 m 次树至多有

`(m^h - 1) / (m - 1)`

个结点。

本质就是把每层最多结点数加起来：

`1 + m + m^2 + ... + m^(h-1)`

#### 性质 4：具有 n 个结点的 m 次树的最小高度为

`⌈log_m(n(m-1)+1)⌉`

这个式子用来解决“至少多高/最小高度”问题。

#### 最大高度

如果题目问最大高度，要反着想：

- 让一层尽量只放 1 个结点；
- 直到某一层再分叉。

所以最大高度通常不是公式题，而是构造题。

## 7.2 二叉树的概念和性质

### 7.2.1 二叉树的定义

#### 原理：二叉树不是“度为 2 的树”

<span class="kp">二叉树或者是空树，或者由一个根结点和两棵互不相交的、分别称为左子树和右子树的二叉树组成。</span>

这里有两个关键点：

1. 二叉树的孩子要区分**左、右**；
2. 即使一个结点只有一个孩子，也必须区分它是左孩子还是右孩子。

#### 二叉树和 2 次树的区别

- **2 次树**：结点度最大为 2，但孩子不强制区分左右；
- **二叉树**：每个结点最多两个孩子，而且孩子必须分左右。

这就是课件中特别强调的区别。

#### 二叉树的 5 种基本形态

1. 空树
2. 只有根结点
3. 只有左子树
4. 只有右子树
5. 左右子树都非空

---

### 7.2.2 二叉树性质

#### 性质 1：非空二叉树上叶结点数等于双分支结点数加 1

记：

- `n0`：叶结点数（度为 0）
- `n1`：度为 1 的结点数
- `n2`：度为 2 的结点数

则：

`n0 = n2 + 1`

#### 为什么成立

二叉树中：

- 结点总数 `n = n0 + n1 + n2`
- 度之和 `= n1 + 2n2`
- 度之和 `= n - 1`

所以：

`n1 + 2n2 = n0 + n1 + n2 - 1`

化简得到：

`n0 = n2 + 1`

#### 性质 2：非空二叉树第 i 层至多有 `2^(i-1)` 个结点

#### 性质 3：高度为 h 的二叉树至多有 `2^h - 1` 个结点

这就是性质 2 的累加。

#### 性质 4：完全二叉树的编号关系

对一棵按层序编号（根结点为 1）的完全二叉树：

1. 若 `i <= ⌊n/2⌋`，则编号为 `i` 的结点是分支结点，否则是叶结点。
2. 若结点编号为 `i`，其双亲编号为 `⌊i/2⌋`。
3. 若结点编号为 `i`，其左孩子编号为 `2i`。
4. 若结点编号为 `i`，其右孩子编号为 `2i+1`。

这是完全二叉树题最常用的公式组。

---

### 满二叉树与完全二叉树

#### 满二叉树

一棵二叉树中：

- 所有分支结点都有两个孩子；
- 所有叶结点都在同一层。

若高度为 `h`，则恰有：

`2^h - 1`

个结点。

#### 完全二叉树

一棵二叉树中：

- 最多只有下面两层的结点度数小于 2；
- 最下面一层的叶结点都依次排在最左边位置。

它本质上可以看成：

**从满二叉树中删掉最底层最右边若干结点后得到。**

---

### 树、森林与二叉树之间的转换

#### 森林 / 树 转二叉树

规则就两句：

- **长子关系** 转成 **左孩子关系**；
- **兄弟关系** 转成 **右孩子关系**。

所以森林转二叉树，本质就是：

把同层兄弟一个一个用右指针串起来，再把每棵树的长子作为左孩子挂上去。

#### 二叉树还原为树 / 森林

反过来恢复时：

- 左孩子恢复成长子；
- 右孩子恢复成兄弟。

这部分题目最常考理解，不太考死代码。

#### 高频结论

若一棵二叉树 `B` 由森林 `T` 转换而来，且 `T` 中有 `n` 个非叶结点，则 `B` 中无右孩子的结点数是：

`n + 1`

原因是：

- 每个非叶结点在森林中总会贡献一个“最后一个孩子”，它在二叉树中没有右兄弟，所以没有右孩子；
- 再加上森林中最后一棵树的根，在二叉树里也没有右兄弟。

## 7.3 二叉树的存储结构

### 7.3.1 顺序存储结构

顺序存储最适合：

- 完全二叉树；
- 接近完全二叉树。

因为它可以直接按层序编号存进数组。

#### 优点

- 找双亲容易
- 找左右孩子容易

#### 缺点

对于一般二叉树，尤其退化二叉树：

- 会浪费大量空间；
- 需要补很多空结点。

#### 关键结论

在顺序存储里，编号为 `i` 的结点所在层满足：

`⌈log2(i+1)⌉`

这一点课件里有专门例题。

#### 例题抓手

若一棵高度为 5 且有 10 个结点的二叉树采用顺序存储，至少需要多少存储单元？

思路：

- 最坏情况最后一个结点落在第 5 层最右端；
- 补全后相当于一棵高度 5 的满二叉树；
- 需要 `2^5 - 1 = 31` 个单元。

---

### 7.3.2 链式存储结构（二叉链）

#### 原理

每个结点设置 3 个域：

- 数据域 `data`
- 左孩子指针域 `lchild`
- 右孩子指针域 `rchild`

类型定义：

```cpp
typedef struct node
{
    ElemType data;
    struct node *lchild, *rchild;
} BTNode;
```

#### 特点

- 节省存储空间；
- 找孩子方便；
- 找双亲不方便。

#### 空指针个数

若二叉链有 `n` 个结点：

- 总指针域数 = `2n`
- 非空指针域数 = 分支数 = `n-1`
- 空指针域数 = `2n - (n-1) = n+1`

这是非常经典的结论。

## 7.4 二叉树基本运算及其实现

### 7.4.1 六大基本运算

课件归纳的 6 个常见基本操作：

1. `CreateBTree(*b, *str)`：根据括号表示法字符串生成二叉树。
2. `DestroyBTree(*b)`：销毁二叉树。
3. `FindNode(*b, x)`：查找值为 x 的结点。
4. `LchildNode(p)` / `RchildNode(p)`：求 p 的左孩子 / 右孩子。
5. `BTHeight(*b)`：求二叉树高度。
6. `DispBTree(*b)`：输出二叉树的括号表示。

### 求高度的原理

#### 原理先讲

一个结点的高度 = 它左右子树高度中的较大者 + 1。

空树高度规定为 0。

所以递归模型：

- 若 `b == NULL`，返回 0；
- 否则返回 `max(左子树高度, 右子树高度) + 1`。

#### C++ 代码骨架

```cpp
int BTHeight(BTNode *b)
{
    int lchilddep, rchilddep;
    if (b == NULL) return 0;
    else
    {
        lchilddep = BTHeight(b->lchild);
        rchilddep = BTHeight(b->rchild);
        return (lchilddep > rchilddep) ? (lchilddep + 1) : (rchilddep + 1);
    }
}
```

### 销毁二叉树的原理

销毁二叉树必须后序思想：

- 先销毁左子树
- 再销毁右子树
- 最后释放当前结点

因为只有左右子树都处理完，当前结点才可以安全释放。

### 查找结点的原理

递归模型是：

- 若空树，返回 `NULL`
- 若当前结点值就是 `x`，返回当前结点
- 否则先去左子树找
- 左子树找不到，再去右子树找

这是一种典型“先左后右”的递归搜索。

### 输出二叉树的括号表示

输出的目标不是结构体，而是逻辑表示：

`根(左子树,右子树)`

如果没有孩子，就只输出根；如果有孩子，递归输出左右子树。

## 7.5 二叉树的遍历

### 遍历的定义

<span class="kp">二叉树遍历是指按照一定次序访问树中所有结点，且每个结点只访问一次。</span>

遍历是二叉树最基础的操作，因为很多别的问题，最终都要回到遍历。

### 三种常见遍历

#### 1. 先根遍历

顺序：

**根 → 左子树 → 右子树**

#### 2. 后根遍历

顺序：

**左子树 → 右子树 → 根**

#### 3. 层次遍历

顺序：

**自上而下、自左向右按层访问**

### 本质区别

- 先根 / 后根：都是递归遍历；
- 层次遍历：通常借助队列完成。

## 易错点清单

1. 树是非线性结构，线性表、栈、队列都不是树。
2. 树中每个结点只有一个前驱，但可以有多个后继。
3. 二叉树不是“度为 2 的树”，而是“左右子树有次序”。
4. 完全二叉树和满二叉树不能混。
5. 顺序存储适合完全二叉树，不适合普通退化二叉树。
6. 二叉链中找孩子方便，找双亲不方便。
7. 树转二叉树时：长子→左孩子，兄弟→右孩子。
8. 先根 / 后根是递归，层次遍历不是递归主角而是队列主角。
