# 第六章笔记：数组和广义表

这一章前半部分的主线其实很清楚：

- 先讲数组是什么；
- 再讲数组为什么天然适合顺序存储；
- 再讲二维数组在内存中的定位公式；
- 再讲特殊矩阵为什么要压缩存储；
- 最后引出稀疏矩阵的三元组表示。

所以这章不要只看成“很多公式”，它本质上是在回答一个问题：

**当数据是规则二维结构时，怎样既存得下，又找得快，还尽量不浪费空间。**

---

## 6.1 数组

### 6.1.1 数组的基本概念

<span class="kp">从逻辑结构上看，一维数组 A 是由 n 个相同类型数据元素构成的有限序列。</span>

表示为：

`A = (a1, a2, ..., an)`

其中 `ai (1<=i<=n)` 表示数组 A 的第 i 个元素。

### 多维数组和线性表的关系

一个 `m` 行 `n` 列的二维数组，本质上可以看作是：

- 每个元素仍然是同类型数据；
- 只是这些数据按二维逻辑结构组织；
- 从更高角度看，它仍然可以理解为“线性表的推广”。

所以课件强调：

<span class="kp">多维数组是线性表的推广。</span>

### 本章里的“数组”和 C/C++ 里的数组不要混

课件特别提醒了这一点：

- 本章中的 **数组** 是作为一种数据结构讨论的；
- 而 C/C++ 中的数组是具体的数据类型。

前者是“逻辑结构/存储结构层面的概念”，后者是“语言里的实现工具”。

<blockquote>易错：顺序表可以借助 C 数组来实现，但“顺序表”不等于“数组类型本身”。这一点不能混。</blockquote>

### 数组的特点

以 C/C++ 为例，数组通常有这几个特征：

- 元素个数固定；
- 元素类型相同；
- 每个元素都和唯一的下标对应；
- 具有随机存取特性。

这几个点里最重要的是最后一个：

<span class="kp">数组具有随机存取特性，可以在 O(1) 时间内找到指定下标位置的元素。</span>

### 例题：约瑟夫问题为什么能用数组

课件给了一个数组应用例子：约瑟夫问题。

有 `n` 个人围成一圈，按顺序报数，数到 `m` 的人出列，然后从下一个人继续，直到全部出列。

课件代码的核心思路是：

1. 用一维数组存当前还在圈中的人；
2. 每次根据 `(当前位置 + m - 1) % 当前人数` 找到出列者；
3. 把后面的元素整体前移一位；
4. 当前人数减 1，继续下一轮。

你要理解的不是细枝末节，而是：

<span class="kp">数组适合这种“按位置快速访问、按下标定位”的问题。</span>

但它的代价也很明显：

每次有人出列后，要把后面的元素前移，所以整体效率并不算高。

## 6.1.2 数组的存储结构

### 为什么数组天然适合顺序存储

课件直接给了结论：

<span class="kp">数组特别适合采用顺序存储结构。</span>

原因有两个：

1. 数组最主要的操作是“存”和“取”，即按下标访问；
2. 顺序存储结构最适合根据下标快速定位；
3. 存储密度高，没有链式存储那样的额外指针开销。

所以数组通常不会采用链式存储。不是绝对不能，而是：

<span class="kp">如果主要追求高效按下标访问，那么顺序存储最自然、最高效。</span>

---

### 一维数组的地址计算公式

设一维数组：

`A = (a1, a2, ..., ai, ..., an)`

若已知 `a1` 的存储地址为 `LOC(a1)`，每个元素占 `k` 个存储单元，则：

`LOC(ai) = LOC(a1) + (i-1) * k`

### 这个公式怎么理解

你要找第 `i` 个元素，它前面有多少个元素？

答案是：`i-1` 个。

每个元素占 `k` 个单元，所以前面一共占：

`(i-1) * k`

再加上首元素地址，就得到第 `i` 个元素地址。

所以这个公式本质上就是：

**起点地址 + 偏移量**

这也是数组随机存取成立的根本原因。

---

### 二维数组的存储结构

一个 `m × n` 的二维数组在顺序存储时，通常有两种主序方式：

1. **以行序为主序**（Row-major）
2. **以列序为主序**（Column-major）

课件这里重点是让你会区分这两种存法，以及会写地址公式。

---

### 1. 以行序为主序

按行一行一行存：

- 先存第一行全部元素；
- 再存第二行全部元素；
- ……；
- 最后存第 m 行全部元素。

如果要找元素 `a(i,j)`，它前面有：

- 前 `i-1` 行，每行 `n` 个元素，共 `(i-1)*n` 个；
- 第 `i` 行中，它前面还有 `j-1` 个元素；

所以一共是：

`(i-1)*n + (j-1)` 个元素。

地址公式：

`LOC(a(i,j)) = LOC(a(1,1)) + [(i-1)*n + (j-1)] * k`

### 2. 以列序为主序

按列一列一列存：

- 先存第一列全部元素；
- 再存第二列全部元素；
- ……；
- 最后存第 n 列全部元素。

如果要找元素 `a(i,j)`，它前面有：

- 前 `j-1` 列，每列 `m` 个元素，共 `(j-1)*m` 个；
- 第 `j` 列中，它前面还有 `i-1` 个元素；

所以一共是：

`(j-1)*m + (i-1)` 个元素。

地址公式：

`LOC(a(i,j)) = LOC(a(1,1)) + [(j-1)*m + (i-1)] * k`

<blockquote>易错：行序主序公式里乘的是列数 n，列序主序公式里乘的是行数 m。最容易把这两个写反。</blockquote>

## 6.1.3 特殊矩阵的压缩存储

这一节开始，课件的重点变成：

**既然有些矩阵有大量重复元素或零元素，那就没必要老老实实按普通二维数组全存下来。**

所以会引出几类常见的特殊矩阵：

1. 对称矩阵
2. 上三角矩阵 / 下三角矩阵
3. 对角矩阵

这些矩阵的共同特点是：

- 不是所有位置都需要独立存；
- 有很多元素可以由别的位置推出，或者是固定常量；
- 因此适合压缩存储。

---

### 一、对称矩阵的压缩存储

#### 原理

若 `n` 阶方阵 `A[n][n]` 满足：

`a(i,j) = a(j,i)`

则称为对称矩阵。

这意味着：

- 主对角线两侧的数据是镜像对称的；
- 只存上三角或下三角再加主对角线就够了。

所以只需要存 `n(n+1)/2` 个元素。

### 1. 按下三角 + 主对角线压缩

如果按行序存下三角部分：

- 第 0 行存 1 个元素；
- 第 1 行存 2 个元素；
- ……；
- 第 i 行存 `i+1` 个元素；

所以在 `a(i,j)` 前面共有：

`i(i+1)/2 + j`

个元素（当 `i >= j` 时）。

因此下标公式是：

- 若 `i >= j`：
  `k = i(i+1)/2 + j`
- 若 `i < j`：
  因为 `a(i,j)=a(j,i)`，转去访问对称位置。

### 2. 按上三角 + 主对角线压缩

如果按行序存上三角部分：

- 第 0 行有 `n` 个元素；
- 第 1 行有 `n-1` 个元素；
- ……；
- 第 i 行有 `n-i` 个元素；

课件给出的定位公式是：

- 若 `i <= j`：
  `k = i(2n-i+1)/2 + (j-i)`
- 若 `i > j`：
  转去访问对称位置。

<blockquote>易错：对称矩阵压缩存储时，真正要记的是“只存一半 + 主对角线”，其次再记住你课上采用的是按上三角还是按下三角，以及对应的公式。</blockquote>

---

### 二、三角矩阵的压缩存储

三角矩阵和对称矩阵不一样。对称矩阵是“另一半可镜像推出”；三角矩阵则是“另一半通常全是常量 0 或 c”。

#### 1. 下三角矩阵

对于下三角矩阵：

- 当 `i >= j` 时，是有效元素；
- 当 `i < j` 时，是常量 `c`（通常是 0）。

如果按行序存下三角部分，则：

- 若 `i >= j`：
  `k = i(i+1)/2 + j`
- 若 `i < j`：
  去访问那个专门存常量 `c` 的位置。

#### 2. 上三角矩阵

对于上三角矩阵：

- 当 `i <= j` 时，是有效元素；
- 当 `i > j` 时，是常量 `c`。

课件里按列优先顺序压缩时，给出的关系是：

`k = j(j-1)/2 + i`

这里特别要小心：

- 到底是按行存还是按列存；
- 下标从 0 开始还是从 1 开始；
- 公式里的偏移会因此不同。

所以这类题一定要先看清课件的存储顺序。

### 3. 对角矩阵

课件还提到对角矩阵，以及更一般的带状对角矩阵。

例如半带宽为 `b` 的对角矩阵，只需要存主对角线附近若干条带内的元素，其他位置都为 0。

当 `b = 1` 时，就是三对角矩阵。

这部分你只要先抓住本质：

<span class="kp">对角矩阵压缩的核心，是只存带内有效元素，不存大量固定为 0 的位置。</span>

---

## 6.2 稀疏矩阵

### 稀疏矩阵的定义

一个阶数较大的矩阵中，如果非零元素个数 `s` 相对于矩阵元素总数 `t` 很小，即：

`s << t`

则称该矩阵为稀疏矩阵。

例如一个 `100×100` 的矩阵，如果里面只有 100 个非零元素，就可以称作稀疏矩阵。

### 稀疏矩阵和特殊矩阵的区别

课件特别强调了这一点：

- **特殊矩阵** 的特殊元素分布有规律；
- **稀疏矩阵** 的非零元素分布通常没有规律。

所以：

- 对称矩阵/三角矩阵压缩，是利用“规则”；
- 稀疏矩阵压缩，是利用“非零很少”。

---

### 6.2.1 稀疏矩阵的三元组表示

#### 原理

稀疏矩阵压缩存储的核心思想是：

<span class="kp">只存储非零元素。</span>

每个非零元素由一个三元组唯一确定：

`(i, j, a(i,j))`

也就是：

- 行号
- 列号
- 元素值

所有非零元素放在一起，就形成一个“三元组线性表”。

### 示例

课件里给了一个 `6×7` 的稀疏矩阵，它的非零元素可以表示为：

`((0,2,1), (1,1,2), (2,0,3), (3,3,5), (4,4,6), (5,5,7), (5,6,4))`

这里你要理解：

这已经不是在存整张矩阵，而是在存“所有非零元素的坐标和值清单”。

---

### 稀疏矩阵三元组顺序表

如果把这些三元组再按顺序存进顺序结构里，就得到课件中的三元组顺序表。

类型定义：

```cpp
#define MaxSize 100

typedef struct
{
    int r;       // 行号
    int c;       // 列号
    ElemType d;  // 元素值
} TupNode;

typedef struct
{
    int rows;    // 行数
    int cols;    // 列数
    int nums;    // 非零元素个数
    TupNode data[MaxSize];
} TSMatrix;
```

### 结构含义

- `rows`：矩阵总行数
- `cols`：矩阵总列数
- `nums`：非零元素个数
- `data[]`：按某种顺序（通常按行序主序）保存所有非零三元组

课件里的约定是：

<span class="kp">`data` 中的非零元素通常按行序为主序排列。</span>

也就是先按行号递增排序，同一行内再按列号递增排序。

### 从矩阵创建三元组表

课件的建表算法思路也很清楚：

1. 先按行扫描整个二维矩阵；
2. 遇到非零元素就写入一个三元组；
3. `nums++`。

这本质上就是：

**全表扫描 + 只收集非零项**

### 修改元素时的两种情况

课件还特别举了两个修改例子：

#### 情况 1：把一个非零元素改成另一个非零元素

例如：`A[5][6] = 8`

这时候三元组表中原来的 `(5,6,4)` 只要把值改成 8 即可，结构不变。

#### 情况 2：把一个 0 元素改成非 0 元素

例如：`A[3][5] = 8`

这时候必须：

- 新增一个三元组 `(3,5,8)`；
- 并保持三元组表的有序性。

所以第二种情况麻烦得多，因为结构会变化。

<blockquote>易错：三元组表不是只改值就完了。如果原来是 0 位置改成非 0，就必须新增结点/表项。</blockquote>

## 第六章终极复习总结

### 一句话概括

<span class="kp">第六章讲的是二维数据如何高效存储：普通数组靠顺序存储和地址公式，特殊矩阵靠压缩存储，稀疏矩阵靠三元组表示。</span>

### 必记内容

1. 数组作为数据结构 vs C/C++ 数组类型的区别。
2. 一维数组地址公式：
   `LOC(ai)=LOC(a1)+(i-1)k`
3. 二维数组两种主序：行主序、列主序。
4. 行主序地址公式：
   `LOC(a(i,j)) = LOC(a(1,1)) + [(i-1)n + (j-1)]k`
5. 列主序地址公式：
   `LOC(a(i,j)) = LOC(a(1,1)) + [(j-1)m + (i-1)]k`
6. 特殊矩阵压缩存储：对称矩阵、三角矩阵、对角矩阵。
7. 稀疏矩阵定义：`s << t`。
8. 稀疏矩阵三元组表示：`(i, j, a(i,j))`。
9. 三元组顺序表结构：`rows, cols, nums, data[]`。

---

## 易错点清单

1. 本章讨论的“数组”是数据结构概念，不等于 C 数组类型本身。
2. 行主序公式乘的是列数 `n`，列主序公式乘的是行数 `m`。
3. 地址公式本质都是“起始地址 + 前面元素个数 × 每元素大小”。
4. 对称矩阵压缩时，记得只存一半加主对角线。
5. 三角矩阵要看清楚另一半是常量 `c`，不能硬套对称矩阵思路。
6. 稀疏矩阵和特殊矩阵的区别在于：一个靠“分布稀少”，一个靠“分布有规律”。
7. 三元组表里如果把 0 改成非 0，不是改值那么简单，而是要插入新三元组。
