# 第四章笔记：串

这一章讲的是 **串（String）**。串本质上是字符序列，但课件真正想让你掌握的是：**串的基本概念、顺序/链式存储、基本运算、模式匹配（BF/KMP）**。

本章主线：

1. 串的定义与基本概念；
2. 串的存储结构；
3. 串的基本运算；
4. 模式匹配：BF 与 KMP。

---

## 4.1 串的基本概念

### 4.1.1 串的定义

<span class="kp">串（String）是由零个或多个字符组成的有限序列。</span>

要点只有三个：

- **字符**：串中的元素是字符；
- **有序**：字符顺序不能乱；
- **有限**：字符个数有限，可以为空串。

### 线性表和串的关系

<span class="kp">串可以看成“数据元素类型限定为字符”的线性表。</span>

所以：

- 线性表更一般；
- 串是线性表的特例。

### 串长、空串、串相等、子串

- **串长**：串中字符个数。
- **空串**：不含任何字符的串，用 `\phi` 表示。
- **串相等**：长度相等且对应位置字符都相同。
- **子串**：串中任意连续字符组成的序列。
- **真子串**：不包含串自身的所有子串。

<blockquote>易错：空串 `\phi` 和只含一个空格的串不是一回事；空串没有任何字符。</blockquote>

### 逻辑表示

串常写为：`"a1a2...an"`

其中：

- `a_i (1 <= i <= n)` 表示第 `i` 个字符；
- 双引号只是表示形式，不是串内容。

### 子串举例

`abcde` 的子串包括：`""`、`a`、`ab`、`abc`、`abcd`、`abcde` 等。

## 4.2 串的存储结构

### 4.2.1 顺序存储（顺序串）

#### 类型定义

```cpp
typedef struct
{
    char data[MaxSize];
    int length;
} SqString;
```

#### 结构含义

- `data`：存字符；
- `length`：存串长。

<span class="kp">顺序串的本质就是：字符数组 + 串长。</span>

### 为什么要有 `length`

因为串不一定依赖 C 风格字符串的 `\0` 结束标记，所以课件直接用 `length` 记录有效字符数，更稳也更通用。

### 顺序串的两种形式

#### 非紧缩格式

一个存储单元只存一个字符。

- 直观；
- 但空间利用率低。

#### 紧缩格式

一个存储单元存多个字符。

- 存储密度高；
- 但处理更复杂。

<blockquote>易错：紧缩/非紧缩的区别，不在于是不是“顺序存储”，而在于“一个存储单元存几个字符”。</blockquote>

### 顺序串的特点

- 便于按下标访问；
- 求串长方便；
- 插入、删除、连接通常要移动字符。

### 复杂度直觉

- `StrLength`：O(1)
- `StrEqual` / `StrCmp`：O(n)
- `Concat`：O(m+n)
- `SubStr`：O(len)
- `InsStr / DelStr / RepStr`：通常 O(n)

---

### 4.2.2 链式存储

<span class="kp">链式串就是用链表来存字符串。</span>

特点：

- 不要求一整块连续空间；
- 一个结点可以存多个字符；
- 结点间用指针连接。

#### 结点大小

课件强调过：

- 结点大小为 4：一个结点能存 4 个字符；
- 结点大小为 1：一个结点只存 1 个字符。

#### 结点类型

```cpp
typedef struct snode
{
    char data;
    struct snode *next;
} LinkStrNode;
```

### 顺序串 vs 链串

| 对比点 | 顺序串 | 链串 |
|---|---|---|
| 存储方式 | 连续数组 | 链式结点 |
| 随机访问 | 快 | 慢 |
| 插入/删除 | 需移动字符 | 更灵活 |
| 空间要求 | 需要连续空间 | 不要求连续空间 |

### 本节结论

<span class="kp">顺序串适合按位置快速访问，链串适合动态扩展和灵活操作。</span>

## 4.3 串的基本运算

课件给出的串基本运算很多，但核心就是这几类：

| 运算 | 含义 |
|---|---|
| `StrAssign(&s, cstr)` | 用常量串赋值给 `s` |
| `StrCopy(&s, t)` | 复制串 |
| `StrEqual(s, t)` | 判断是否相等 |
| `StrLength(s)` | 求串长 |
| `Concat(s, t)` | 串连接 |
| `SubStr(s, i, j)` | 求子串 |
| `InsStr(s, i, t)` | 插入串 |
| `DelStr(s, i, j)` | 删除子串 |
| `RepStr(s, i, j, t)` | 替换子串 |
| `DispStr(s)` | 输出串 |

### 字符串比较 `StrCmp`

规则：

1. 先比较公共长度范围内的字符；
2. 第一个不同字符决定大小；
3. 如果前面都相同，再比较长度。

例如：

- `"ab" < "abcd"`
- `"abcd" < "abd"`

<blockquote>易错：字符串比较不是只看长度，也不是只看前几个字符，而是“先逐字符比，前面都相同再比长度”。</blockquote>

### 例子

- `DelStr(A,3,2)`：从第 3 个字符开始删 2 个字符。
  - 若 `A = "abcdefg"`，结果是 `"abefg"`。
- `RepStr(A,3,2,B)`：把从第 3 个字符开始、长度为 2 的子串替换成 `B`。
  - 若 `A = "abcdefg"`，`B = "xx"`，结果是 `"abxxefg"`。

## 4.4 串的模式匹配

这一节是本章真正的算法部分。

### 4.4.1 模式匹配问题

给定：

- 主串 `S`
- 模式串 `T`

要求在 `S` 中找到 `T` 第一次出现的位置。

---

### 4.4.2 BF（暴力匹配）

#### 核心思想

<span class="kp">从主串开始逐位尝试；一旦失配，就把模式串退回起点，主串右移一位再试。</span>

#### 复杂度

最坏情况：`O(mn)`

其中：

- `m` 是主串长度；
- `n` 是模式串长度。

#### 直觉

BF 的本质就是“硬碰硬地一个个比”，简单，但可能重复比较很多次。

---

### 4.4.3 KMP

#### 一、原理：KMP 到底优化了什么

<span class="kp">KMP 的核心优化只有一个：主串指针永远不回退。</span>

暴力匹配（BF）的问题在于：一旦失配，主串要回退到上一次起点的下一位，模式串也回到开头，因此前面已经比过的字符还会被重复比较。

KMP 不这样做。它会利用模式串内部已经匹配成功的前缀信息，在失配时只让模式串跳到一个“还能继续比较”的位置，主串保持不动。

所以 KMP 的本质不是“稍微少比几次”，而是：

<span class="kp">把已经匹配成功的信息保存下来并复用。</span>

#### 二、课本版 `next` 数组（以 `-1` 开头）

这一章按课本写法：

- `next[0] = -1`
- 对于 `j > 0`，`next[j] = k` 表示：当模式串 `T[j]` 这个位置失配时，模式串下一步应该跳到 `T[k]` 继续比较。

这里的 `-1` 很重要：

<span class="kp">如果模式串第一个字符就失配，说明已经退无可退，这时令 `j=-1`，下一步统一执行 `i++ , j++`，本质上就是“主串后移一位，模式串从头重新开始”。</span>

所以课本版 `next` 数组不是直接存“长度”，而是存“失配后模式串应该跳到的下标位置”。

#### 三、`next` 数组怎么求

设模式串：

`T = ababaca`

下标：

`0 1 2 3 4 5 6`

课本版 `next` 的结果是：

`next = [-1, 0, 0, 1, 2, 3, 0]`

推导过程：

1. `next[0] = -1`（定义规定）
2. `next[1] = 0`，因为前缀 `a` 没有可复用的真前后缀
3. `next[2] = 0`，因为 `ab` 没有相等真前后缀
4. `next[3] = 1`，因为 `aba` 的最长相等真前后缀是 `a`
5. `next[4] = 2`，因为 `abab` 的最长相等真前后缀是 `ab`
6. `next[5] = 3`，因为 `ababa` 的最长相等真前后缀是 `aba`
7. `next[6] = 0`，因为 `ababac` 没有相等真前后缀

一句话记忆：

<span class="kp">课本版 `next[j]` 表示失配后模式串该跳到的位置，它由前面已匹配部分的最长相等真前后缀决定。</span>

#### 四、KMP 的应用步骤（匹配过程）

设：

- 主串 `S`
- 模式串 `T`
- 主串指针 `i`
- 模式串指针 `j`

匹配规则只有两条：

1. 如果 `j == -1` 或 `S[i] == T[j]`，则：
   - `i++`
   - `j++`

2. 如果 `S[i] != T[j]`，则：
   - 主串 `i` 不动
   - 模式串按 `j = next[j]` 回退

这就是课本版 KMP 的统一写法。

#### 五、实际例子：KMP 怎么找到结果

主串：

`S = abababacababaca`

模式串：

`T = ababaca`

`next = [-1, 0, 0, 1, 2, 3, 0]`

开始匹配时，前面 `ababa` 都能匹配成功。

接着比较到：

- `S[5] = b`
- `T[5] = c`

此时失配。

如果是 BF，会让主串回退；
但 KMP 不回退主串，而是：

`j = next[5] = 3`

这说明：模式串直接跳回位置 3 继续比较。

为什么能跳回 3？
因为此前已经匹配成功的部分 `ababa` 中，最长相等真前后缀是 `aba`，长度为 3，所以这段已经匹配过的信息可以直接复用。

继续比较：

- `S[5] = b` 与 `T[3] = b`，匹配
- `S[6] = a` 与 `T[4] = a`，匹配
- `S[7] = c` 与 `T[5] = c`，匹配
- `S[8] = a` 与 `T[6] = a`，匹配

当 `j` 增长到模式串长度时，说明匹配成功。

匹配起始位置：

`i - j = 9 - 7 = 2`

所以模式串第一次出现在主串下标 2 的位置。

#### 六、KMP 为什么快

<span class="kp">因为主串只前进不回退，而模式串的回退又不是乱跳，而是沿着 `next` 数组跳到可复用的位置。</span>

所以总时间复杂度可以做到：

**O(m+n)**

其中：

- `m` 是主串长度；
- `n` 是模式串长度。

### BF vs KMP 对比

| 算法 | 思路 | 主串是否回退 | 复杂度 |
|---|---|---|---|
| BF | 逐位硬比 | 会 | O(mn) |
| KMP | 利用前缀信息跳转 | 不回退 | O(m+n) |

<blockquote>易错：KMP 不是“少比较几次”，而是“主串不回退，只让模式串按 next 数组跳转”，这才是本质优化点。</blockquote>

### KMP 的考试抓手

你至少要会说清楚五件事：

1. `next[0] = -1` 的意义；
2. `next[j]` 表示什么；
3. 失配时为什么主串不回退；
4. `next` 数组为什么来自最长相等真前后缀；
5. 为什么 KMP 能把复杂度降到 `O(m+n)`。
