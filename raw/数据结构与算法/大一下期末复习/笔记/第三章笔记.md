# 第三章笔记：栈和队列

这一章讲的是两种**受限线性表**：栈和队列。它们都属于线性结构，但和普通线性表不同，操作位置被严格限制。

本章最重要的不是背几个英文单词，而是搞清楚：

- 栈为什么是**后进先出**；
- 队列为什么是**先进先出**；
- 顺序栈/顺序队列的指针到底指向哪里；
- 为什么顺序队列会出现**假溢出**；
- 为什么循环队列要故意“少用一个位置”；
- 中缀表达式转后缀表达式、后缀表达式求值为什么都要用栈。

---

## Chapter 3: Stack and Queue

### 本章主线判断

这一章是在线性表基础上继续加限制：

- **栈**：只允许在同一端插入、删除；
- **队列**：一端插入，另一端删除。

所以它们本质上不是新的逻辑结构，而是线性表的特殊使用规则。

本章建议按这条线理解：

**定义 → 基本概念 → 基本运算 → 顺序存储实现 → 应用题 → 易错点**

---

## 3.1 栈（Stack）

### 3.1.1 栈的定义

<span class="kp">栈（Stack）是一种只能在一端进行插入或删除操作的线性表。</span>

它最核心的特征是：

<span class="kp">后进先出（LIFO, Last In First Out）</span>

也就是说，最后进栈的元素，最先出栈。

### 直觉理解

课件里用“死胡同”作类比非常好记。

<span class="exp">如果一个死胡同只能容一个人宽，那么后进去的人必须先退出来，前面的人才能退，这就是典型的后进先出结构。</span>

### 栈的几个概念

- **栈顶（top）**：允许插入、删除的一端。
- **栈底（bottom）**：另一端。
- **空栈**：没有任何元素的栈。
- **进栈 / 入栈（Push）**：在栈顶插入元素。
- **出栈 / 退栈（Pop）**：删除栈顶元素。

<blockquote>易错：栈不是“只能插入”或“只能删除”，而是插入和删除都只能在同一端进行。</blockquote>

### 栈的基本运算

课件给出的 6 个基本操作如下：

1. `InitStack(&s)`：初始化栈，构造空栈。
2. `DestroyStack(&s)`：销毁栈，释放空间。
3. `StackEmpty(s)`：判断栈是否为空。
4. `Push(&s, e)`：进栈。
5. `Pop(&s, &e)`：出栈，并返回栈顶元素值。
6. `GetTop(s, &e)`：取栈顶元素，但不删除。

## 3.1.2 栈的顺序存储结构及其基本运算实现

### 栈的两种实现

和线性表一样，栈也可以有两种常见存储方式：

- 顺序栈（底层是顺序表）
- 链栈（底层是链表）

课件重点放在顺序栈上。

### 顺序栈的类型定义

```cpp
typedef struct
{
    ElemType data[MaxSize];
    int top;
} SqStack;
```

#### 结构含义

- `data[MaxSize]`：存放栈元素。
- `top`：栈顶指针，始终指向当前栈顶元素。

### top 指针的约定

课件这里的约定很重要：

- `top` 初值为 `-1`；
- `top == -1` 表示空栈；
- `top == MaxSize - 1` 表示栈满。

### 状态变化怎么理解

假设 `MaxSize = 5`：

- 空栈时：`top = -1`
- 元素 `a` 入栈后：`top = 0`
- 再入 `b, c, d, e` 后：`top = 4`
- 再想进栈就会栈满上溢。

所以顺序栈四要素一定要记：

- 栈空条件：`s->top == -1`
- 栈满条件：`s->top == MaxSize - 1`
- 进栈操作：`top++`，再存放元素
- 出栈操作：先取值，再 `top--`

<blockquote>易错：课件特别强调，进栈是“先 ++，后存放”；出栈是“先取值，后 --”。这两个顺序不能写反。</blockquote>

### 初始化栈 `InitStack`

```cpp
void InitStack(SqStack *&s)
{
    s = (SqStack *)malloc(sizeof(SqStack));
    s->top = -1;
}
```

初始化空栈的重点是：

<span class="kp">给栈分配空间，并把 `top` 设为 `-1`。</span>

### 销毁栈 `DestroyStack`

```cpp
void DestroyStack(SqStack *&s)
{
    free(s);
}
```

### 判断栈空 `StackEmpty`

```cpp
bool StackEmpty(SqStack *s)
{
    return (s->top == -1);
}
```

### 进栈 `Push`

```cpp
bool Push(SqStack *&s, ElemType e)
{
    if (s->top == MaxSize - 1)
        return false;
    s->top++;
    s->data[s->top] = e;
    return true;
}
```

#### 这段代码最关键的点

1. 先判断栈满。
2. 再 `top++`。
3. 最后把 `e` 放到新的栈顶位置。

<blockquote>易错：不能写成 `s->data[top] = e`。因为 `top` 是 `s` 所指结构体中的成员，必须通过 `s->top` 访问。</blockquote>

### 出栈 `Pop`

```cpp
bool Pop(SqStack *&s, ElemType &e)
{
    if (s->top == -1)
        return false;
    e = s->data[s->top];
    s->top--;
    return true;
}
```

#### 本质

先保存当前栈顶元素值，再把栈顶下移一位。

### 取栈顶 `GetTop`

```cpp
bool GetTop(SqStack *s, ElemType &e)
{
    if (s->top == -1)
        return false;
    e = s->data[s->top];
    return true;
}
```

它和 `Pop` 的区别只有一个：

- `GetTop` 只看，不删；
- `Pop` 看完还要删。

## 3.1.3 共享栈

课件提到了共享栈，这是考选择题很常见的点。

### 什么叫共享栈

<span class="kp">两个栈共用一个数组空间，一个从左往右长，一个从右往左长。</span>

这样设计的好处是：

- 节省存储空间；
- 能降低上溢出的发生概率。

因为如果一个栈用得多、另一个栈用得少，它们可以动态共享剩余空间。

### 典型选择题

由两个栈共享一个数组空间的好处是：

**节省存储空间，降低上溢出发生的概率。**

所以答案通常选：**B**。

## 3.1.4 栈的应用

### 一、中缀表达式转后缀表达式

这一块是应用重点。

#### 本质思想

<span class="kp">用一个“运算符栈”管理尚未输出的运算符，根据优先级和括号控制弹栈。</span>

#### 没有括号时

例如：

`1 + 2 + 3`

转成后缀：

`1 2 + 3 +`

#### 有括号时

例如：

`2 * (1 + 3) - 4`

转成后缀：

`2 1 3 + * 4 -`

### 规则总结

- 遇到操作数：直接输出。
- 遇到左括号 `(`：进栈。
- 遇到右括号 `)`：一直弹到 `(`。
- 遇到运算符：
  - 如果当前优先级大于栈顶，直接进栈；
  - 否则先把栈顶运算符弹出，再比较。
- 扫描结束后，把栈中剩余运算符全部弹出。

### 二、后缀表达式求值

规则特别简单：

<span class="kp">遇到数字就进栈，遇到符号就把栈顶两个数字出栈运算，再把结果压回栈中。</span>

课件例子：

后缀表达式：

`9 3 1 - 3 * + 10 2 / +`

运算结果：

`20`

这类题你只要死守规则就行：

1. 数字入栈；
2. 运算符弹出两个数；
3. 先弹出的是右操作数，后弹出的是左操作数；
4. 运算结果重新入栈；
5. 最后栈顶就是最终结果。

<blockquote>易错：后缀表达式求值时，减法和除法不能交换两个操作数顺序。先弹出的数是右边，后弹出的数是左边。</blockquote>

### 三、栈序列判断题

课件给了两个典型选择题：

#### 题型 1：给定入栈序列，哪个出栈序列不可能

例如入栈序列是 `a, b, c, d`。

判断出栈序列是否可能时，核心思路是模拟：

- 能入则入；
- 能出则出；
- 如果某一步要求弹出一个根本不在栈顶的元素，那就不可能。

#### 题型 2：已知 `p1 = 3`，问 `p2` 或 `p3` 可取值个数

这种题本质也是模拟。你要先按题意把前面的出栈行为固定，再分析剩余栈和未入栈元素，问下一个位置还能取哪些值。

这类题不用死记答案，核心是会画栈状态图。

## 3.2 队列（Queue）

### 3.2.1 队列的定义

<span class="kp">队列（Queue）是一种运算受限的线性表。</span>

它的核心特征是：

<span class="kp">先进先出（FIFO, First In First Out）</span>

### 直觉理解

课件用“过独木桥”的例子很好记。

先上桥的人先下桥，后上桥的人必须排后面，这就是队列。

### 队列的几个概念

- **队尾（rear）**：插入元素的一端。
- **队首 / 队头（front）**：删除元素的一端。
- **进队 / 入队（enQueue）**：在队尾插入新元素。
- **出队 / 离队（deQueue）**：从队首删除元素。

### 队列的基本运算

课件给的 5 个基本操作：

1. `InitQueue(&q)`：初始化队列。
2. `DestroyQueue(&q)`：销毁队列。
3. `QueueEmpty(q)`：判断是否为空。
4. `enQueue(&q, e)`：入队。
5. `deQueue(&q, &e)`：出队。

---

## 3.2.2 队列的顺序存储结构及其基本运算实现

### 顺序队列类型定义

```cpp
typedef struct
{
    ElemType data[MaxSize];
    int front, rear;
} SqQueue;
```

因为队列两端都在变化，所以顺序队列必须用两个指针：

- `front`：队头指针
- `rear`：队尾指针

### 课件里的非循环顺序队列约定

这里的约定是：

- 初始时 `front = rear = -1`
- `rear` 指向队尾元素
- `front` 指向当前队头元素的前一个位置

所以四要素是：

- 队空条件：`front == rear`
- 队满条件：`rear == MaxSize - 1`
- 入队：`rear++; data[rear] = e`
- 出队：`front++; e = data[front]`

### 初始化队列 `InitQueue`

```cpp
void InitQueue(SqQueue *&q)
{
    q = (SqQueue *)malloc(sizeof(SqQueue));
    q->front = q->rear = -1;
}
```

### 销毁队列 `DestroyQueue`

```cpp
void DestroyQueue(SqQueue *&q)
{
    free(q);
}
```

### 判空 `QueueEmpty`

```cpp
bool QueueEmpty(SqQueue *q)
{
    return (q->front == q->rear);
}
```

### 入队 `enQueue`

```cpp
bool enQueue(SqQueue *&q, ElemType e)
{
    if (q->rear == MaxSize - 1)
        return false;
    q->rear++;
    q->data[q->rear] = e;
    return true;
}
```

### 出队 `deQueue`

```cpp
bool deQueue(SqQueue *&q, ElemType &e)
{
    if (q->front == q->rear)
        return false;
    q->front++;
    e = q->data[q->front];
    return true;
}
```

### 非循环顺序队列的缺陷：假溢出

课件特别强调：

如果 `rear == MaxSize - 1` 就判满，那么即使前面已经出队腾出了若干空位，后面仍然不能继续入队。

这时并不是真的空间用完了，只是尾指针走到头了。

这种现象叫：

<span class="kp">假溢出</span>

### 为什么是假溢出

因为数组前面明明还有空位，但由于 `rear` 不能回头，逻辑上不能再利用这些空位。

---

## 3.2.3 环形队列（循环队列）

### 解决思路

把数组首尾连起来，逻辑上形成一个环。

也就是说，`rear` 走到 `MaxSize-1` 之后，再往前就回到 0。`front` 也一样。

### 关键更新方式

- `rear = (rear + 1) % MaxSize`
- `front = (front + 1) % MaxSize`

### 为什么要少用一个位置

如果只规定：

- 队空：`rear == front`

那么会出现一个问题：

“初始空队”和“所有元素都出完后的空队”满足这个条件；
但如果队满时也让 `rear == front`，那就无法区分空和满。

所以课件的处理是：

<span class="kp">让 `rear == front` 只表示队空，并额外规定：当 `(rear + 1) % MaxSize == front` 时队满。</span>

也就是说，循环队列要故意空出一个位置不用。

### 环形队列四要素

- 队空条件：`front == rear`
- 队满条件：`(rear + 1) % MaxSize == front`
- 入队操作：`rear = (rear + 1) % MaxSize; data[rear] = e;`
- 出队操作：`front = (front + 1) % MaxSize; e = data[front];`

### 本质结论

<span class="kp">循环队列牺牲一个存储单元，换来了对空队和满队的明确区分。</span>

<blockquote>易错：如果数组长度是 `MaxSize`，采用“牺牲一个位置”的循环队列，最多只能存放 `MaxSize - 1` 个元素。</blockquote>

---

## 3.2.4 已知 front、rear，如何求队中元素个数

这是课件后面专门讲的重点。

### 元素个数公式

已知 `front`、`rear`，队中元素个数：

```cpp
count = (rear - front + MaxSize) % MaxSize
```

### 由 front 和 count 求 rear

```cpp
rear = (front + count) % MaxSize
```

### 由 rear 和 count 求 front

```cpp
front = (rear - count + MaxSize) % MaxSize
```

这个地方你一定要注意，不能直接用 `rear-front`，因为在环形结构里，`rear` 可能已经绕回去了，会出现负数。

所以必须统一用：

`(+ MaxSize) % MaxSize`

来修正。

## 3.2.5 用 count 替代 rear 的循环队列

课件最后还给了一个变体：

不用 `rear` 指针，改成保存：

- `front`
- `count`

### 类型定义

```cpp
typedef struct
{
    ElemType data[MaxSize];
    int front;
    int count;
} QuType;
```

### 四要素

- 队空条件：`count == 0`
- 队满条件：`count == MaxSize`
- 入队：先算 `rear`，再放元素，`count++`
- 出队：`front` 循环加 1，`count--`

### 初始化

```cpp
void InitQueue(QuType *&qu)
{
    qu = (QuType *)malloc(sizeof(QuType));
    qu->front = 0;
    qu->count = 0;
}
```

### 入队

```cpp
bool EnQueue(QuType *&qu, ElemType x)
{
    int rear;
    if (qu->count == MaxSize)
        return false;
    rear = (qu->front + qu->count) % MaxSize;
    rear = (rear + 1) % MaxSize;
    qu->data[rear] = x;
    qu->count++;
    return true;
}
```

### 出队

```cpp
bool DeQueue(QuType *&qu, ElemType &x)
{
    if (qu->count == 0)
        return false;
    qu->front = (qu->front + 1) % MaxSize;
    x = qu->data[qu->front];
    qu->count--;
    return true;
}
```

### 判空

```cpp
bool QueueEmpty(QuType *qu)
{
    return (qu->count == 0);
}
```

### 这个变体的意义

它相当于把“队尾位置”隐藏起来了，通过 `front + count` 动态计算 `rear`。这样做在某些题目里更方便，但你要记住：

<span class="kp">本质没有变，还是在处理环形队列，只是把状态变量从 `rear` 改成了 `count`。</span>

## 第三章终极复习总结

### 一、栈和队列的本质区别

- **栈**：后进先出（LIFO），插入和删除都在同一端。
- **队列**：先进先出（FIFO），一端插入、一端删除。

### 二、顺序栈四要素

- 栈空：`top == -1`
- 栈满：`top == MaxSize - 1`
- 进栈：先 `top++`，后存放
- 出栈：先取值，后 `top--`

### 三、顺序队列四要素（非循环）

- 队空：`front == rear`
- 队满：`rear == MaxSize - 1`
- 入队：`rear++`
- 出队：`front++`

### 四、循环队列四要素

- 队空：`front == rear`
- 队满：`(rear + 1) % MaxSize == front`
- 入队：`rear = (rear + 1) % MaxSize`
- 出队：`front = (front + 1) % MaxSize`

### 五、应用重点

- 栈：括号匹配、中缀转后缀、后缀求值、递归、栈序列判断
- 队列：排队模型、缓冲区、循环队列、元素个数计算

---

## 第三章易错点清单

1. 栈的 `top` 指向的是当前栈顶元素，不是下一个空位。
2. 进栈和出栈的顺序不要写反：
   - 进栈：先 `++` 后存
   - 出栈：先取值后 `--`
3. 队列的 `front` 和 `rear` 指向含义要分清。
4. 非循环顺序队列会有假溢出。
5. 循环队列为了区分空和满，通常故意少用一个存储单元。
6. 后缀表达式求值时，减法和除法的左右操作数顺序不能弄反。
7. `rear-front` 不能直接当元素个数，必须用模运算修正。
8. `count` 版循环队列并不是新结构，只是换了一种状态表示方法。
