## 2.1 线性表及其逻辑结构

### 2.1.1 线性表的定义

<span class="kp">线性表（Linear List）是具有相同特性的数据元素构成的一个有限序列。</span>

这句话很短，但里面藏了三个关键词：

- **一致性**：所有元素属于同一数据类型；
- **有穷性**：元素个数是有限的；
- **序列性**：元素之间有前后顺序，每个元素都有确定的逻辑位序。

也就是说，线性表不是一堆随便堆起来的数据，而是一串排成一条线的数据。

### 线性表的一般表示

线性表常写成：

`(a1, a2, ..., ai, ai+1, ..., an)`

其中：

- `a1` 是表头元素；
- `an` 是表尾元素；
- `ai` 表示第 `i` 个元素；
- `i` 表示的是 **逻辑位序**，不是数组下标。

<blockquote>易错：逻辑位序通常从 1 开始，而数组物理下标通常从 0 开始。后面顺序表里这两个会经常错位，必须提前记住。</blockquote>

### 图形表示与二元组表示

图形上，线性表就是一串依次相连的结点：

`a1 -> a2 -> a3 -> ... -> an`

从抽象数据类型角度，也可以写成：

- 数据对象：`D = {a1, a2, ..., an}`
- 数据关系：`R = {<a1,a2>, <a2,a3>, ..., <a(n-1),an>}`

所以线性表的本质不是“有很多元素”，而是“元素之间形成了一条一对一的线性关系”。

### 直觉理解

课件里用了“小汽车线性表”“小人线性表”这样的图，其实就是在说明：

<span class="exp">线性表是对现实中一切“排成一列、前后有序”的事物的抽象。</span>

比如：

- 一列汽车；
- 一排座位上的人；
- 一个班级按学号排列的学生；
- 一串按时间顺序记录的日志。

这说明：<span class="kp">线性表是一种非常基础、非常通用的抽象模型。</span>

## 2.1.2 线性表的运算

### ADT List 的基本描述

从抽象数据类型角度，线性表一般记为：

```text
ADT List
{
    数据对象：D = { ai | 1 <= i <= n, n >= 0, ai 为 ElemType 类型 }
    数据关系：R = { <ai, ai+1> | ai, ai+1 ∈ D, i = 1, ..., n-1 }
    基本运算：若干
}
```

这个定义的重点不是背公式，而是明白：

<span class="kp">线性表 = 逻辑结构 + 基本运算。</span>

也就是说，程序员真正使用线性表时，不只是“存一串数据”，还必须能对它做各种基本操作。

### 线性表的 9 个基本运算

课件给了 9 个最经典的基本操作。你应该把它们看成“线性表最小工具箱”。

#### 1. 初始化线性表 `InitList(&L)`

构造一个空线性表。

#### 2. 销毁线性表 `DestroyList(&L)`

释放线性表占用的存储空间。

#### 3. 判空 `ListEmpty(L)`

判断线性表是否为空表。

#### 4. 求长度 `ListLength(L)`

返回线性表中元素个数 `n`。

#### 5. 输出线性表 `DispList(L)`

把表中各元素顺序显示出来。

#### 6. 按位置取元素 `GetElem(L, i, &e)`

取出第 `i` 个元素的值，用 `e` 返回。

#### 7. 按值查找位置 `LocateElem(L, e)`

返回第一个值等于 `e` 的元素的逻辑位序；若不存在，通常返回 0。

#### 8. 插入元素 `ListInsert(&L, i, e)`

在第 `i` 个位置前插入新元素 `e`。

#### 9. 删除元素 `ListDelete(&L, i, &e)`

删除第 `i` 个元素，并用 `e` 返回被删元素值。

### 这些基本运算真正说明了什么

<span class="kp">程序员不仅可以把线性表当成一个“装数据的容器”，还可以直接利用这些基本运算去完成更复杂的任务。</span>

比如：

- 用 `GetElem` 和 `LocateElem` 做查询；
- 用 `Insert` 和 `Delete` 做编辑；
- 用 `InitList` 和 `DestroyList` 管理生命周期；
- 用这些操作继续组合成更复杂的算法。

所以课件里那张“应用程序 → 基本运算 → 数据”的图，本质上想告诉你：

**数据结构不是数据本身，而是“数据 + 对数据的操作方式”。**

## 2.2 线性表的顺序存储结构

这一节开始，线性表第一次真正“落地”。

### 2.2.1 什么叫顺序存储 —— 顺序表

<span class="kp">线性表的顺序存储结构，就是把线性表中的所有元素按照逻辑顺序，依次存放到存储器中一片连续的存储空间里。</span>

这个定义非常关键，里面有两个词必须抓住：

- **逻辑顺序**：元素在概念上谁在前谁在后；
- **连续存储空间**：这些元素在内存里是一块连续区域，不是东一块西一块。

### 顺序表的结构图怎么理解

课件图里上面是逻辑结构：

`(a1, a2, ..., ai, ..., an)`

下面是存储结构：

- `data[0] = a1`
- `data[1] = a2`
- ...
- `data[i-1] = ai`
- ...
- `data[n-1] = an`

右边还有一个 `length = n`。

这图的核心意思就是：

<span class="kp">顺序表用数组 `data[]` 存元素，用 `length` 记录当前实际长度。</span>

### 最重要的提醒：逻辑位序 vs 物理位序

这节最容易出错的地方，就是课件反复强调的：

<blockquote>逻辑位序和物理位序相差 1。</blockquote>

- 第 `i` 个元素的逻辑位序是 `i`；
- 它在数组里的物理下标是 `i-1`。

比如：

- 第 1 个元素在 `data[0]`
- 第 2 个元素在 `data[1]`
- 第 i 个元素在 `data[i-1]`

### 顺序表类型定义

```cpp
typedef struct
{
    ElemType data[MaxSize];
    int length;
} SqList;
```

#### 怎么理解这个结构体

- `data[MaxSize]`：一段预留好的连续存储区，用来装线性表元素；
- `length`：不是容量，而是**当前实际有多少个有效元素**。

<blockquote>易错：`MaxSize` 表示最多能放多少个元素；`length` 表示现在已经放了多少个元素。两者不能混。</blockquote>

### 一个整数顺序表例子

如果线性表是：

`(1, 3, 1, 4, 2)`

那么顺序表里可以表示成：

- `data[0] = 1`
- `data[1] = 3`
- `data[2] = 1`
- `data[3] = 4`
- `data[4] = 2`
- `length = 5`

你只要记一句话：

<span class="kp">数组里不一定所有空间都有效，真正属于当前线性表的部分只到 `length-1` 为止。</span>

## 2.2.2 顺序表运算的实现

这一节就是把前面的 9 个基本运算真正写成代码。

### 一、建立顺序表 `CreateList`

课件里给的是整体建表法：

```cpp
void CreateList(SqList *&L, ElemType a[], int n)
{
    int i = 0, k = 0;
    L = (SqList *)malloc(sizeof(SqList));
    while (i < n)
    {
        L->data[k] = a[i];
        k++;
        i++;
    }
    L->length = k;
}
```

### 这个算法到底在做什么

它做了三件事：

1. 给顺序表 `L` 分配一块空间；
2. 把数组 `a[0..n-1]` 逐个复制到 `L->data[]` 中；
3. 把 `length` 设置为 `n`。

### 为什么形参写成 `SqList *&L`

这一点很重要。

<span class="kp">`L` 是顺序表指针，使用引用参数 `*&L`，是为了把函数内部新申请到的顺序表地址回传给实参。</span>

如果你不用引用，只写：

```cpp
void CreateList(SqList *L, ElemType a[], int n)
```

那么函数里即使 `malloc` 了新空间，外面的那个指针也接不到，最后主函数里的指针还是垃圾值。

<blockquote>易错：这不是“语法细节”，而是“地址能不能回传”的本质问题。凡是函数内部要新建结构体并交给外部使用，引用或二级指针都必须考虑。</blockquote>

### 初始化线性表 `InitList`

```cpp
void InitList(SqList *&L)
{
    L = (SqList *)malloc(sizeof(SqList));
    L->length = 0;
}
```

初始化空表的重点不是把数组全清零，而是：

<span class="kp">申请空间，并把 `length` 设为 0。</span>

这就表示：表存在，但现在没有任何有效元素。

### 销毁线性表 `DestroyList`

```cpp
void DestroyList(SqList *&L)
{
    free(L);
}
```

作用就是释放顺序表占用的空间。

### 判空 `ListEmpty`

```cpp
bool ListEmpty(SqList *L)
{
    return (L->length == 0);
}
```

### 求长度 `ListLength`

```cpp
int ListLength(SqList *L)
{
    return L->length;
}
```

### 输出线性表 `DispList`

```cpp
void DispList(SqList *L)
{
    int i;
    if (ListEmpty(L)) return;
    for (i = 0; i < L->length; i++)
        printf("%c", L->data[i]);
    printf("\n");
}
```

这里要注意：循环上界不是 `MaxSize`，而是 `length`。因为只有前 `length` 个位置才有效。

## 二、按位置取值与按值查找

### `GetElem(L, i, e)` —— 按位置取值

```cpp
bool GetElem(SqList *L, int i, ElemType &e)
{
    if (i < 1 || i > L->length) return false;
    e = L->data[i - 1];
    return true;
}
```

### 为什么它快

因为顺序表是连续存储的，知道第 `i` 个元素，就能直接定位到 `data[i-1]`。

所以：

<span class="kp">按逻辑位序取元素，是顺序表最大的优势之一。</span>

时间复杂度为：

**O(1)**

这体现了顺序表的**随机存取特性**。

### `LocateElem(L, e)` —— 按值查位置

```cpp
int LocateElem(SqList *L, ElemType e)
{
    int i = 0;
    while (i < L->length && L->data[i] != e)
        i++;
    if (i >= L->length) return 0;
    else return i + 1;
}
```

这个操作就没那么快了。因为值 `e` 在哪里并不知道，只能从前往后顺着找。

所以：

- 找到则返回第一个匹配元素的逻辑位序；
- 找不到返回 0；
- 时间复杂度是 **O(n)**。

<blockquote>易错：`GetElem` 和 `LocateElem` 名字像，但一个是“按位置取值”，一个是“按值找位置”，时间复杂度完全不同。</blockquote>

## 三、插入操作 `ListInsert`

### 基本定义

在线性表 `L` 的第 `i` 个位置前插入新元素 `e`。

### 算法实现

```cpp
bool ListInsert(SqList *&L, int i, ElemType e)
{
    int j;
    if (i < 1 || i > L->length + 1)
        return false;
    i--;
    for (j = L->length; j > i; j--)
        L->data[j] = L->data[j - 1];
    L->data[i] = e;
    L->length++;
    return true;
}
```

### 插入的逻辑怎么理解

插入并不是“把元素塞进去就完了”，而是分三步：

1. 检查位置是否合法；
2. 从后往前，把插入位置及其后面的元素全部后移一位；
3. 把新元素放进空出来的位置。

### 为什么要从后往前移

如果你从前往后移，会把原来的数据覆盖掉。

比如要在中间插入一个元素，后面的元素都要往后挪。如果从前往后搬，前一个值会直接把后一个值冲掉；从后往前搬，就不会覆盖未搬走的数据。

### 时间复杂度分析

- 若插入位置是表尾，也就是 `i = n+1`，不用移动元素，最好情况是 **O(1)**；
- 若插入位置是表头，也就是 `i = 1`，要移动 `n` 个元素，最坏情况是 **O(n)**；
- 平均下来，移动元素次数约为 `n/2`，所以平均时间复杂度仍然是 **O(n)**。

### 本质结论

<span class="kp">顺序表插入慢，不是因为找不到位置，而是因为要移动大量元素。</span>

这就是顺序表的代价。

## 四、删除操作 `ListDelete`

### 基本定义

删除顺序表 `L` 的第 `i` 个元素，并用 `e` 返回它的值。

### 算法实现

```cpp
bool ListDelete(SqList *&L, int i, ElemType &e)
{
    int j;
    if (i < 1 || i > L->length)
        return false;
    i--;
    e = L->data[i];
    for (j = i; j < L->length - 1; j++)
        L->data[j] = L->data[j + 1];
    L->length--;
    return true;
}
```

### 删除的逻辑怎么理解

删除是插入的镜像操作。

1. 先检查位置是否合法；
2. 记住被删元素值；
3. 把它后面的所有元素整体前移一位；
4. 把 `length` 减 1。

### 时间复杂度分析

- 若删的是最后一个元素，不必移动，最好情况是 **O(1)**；
- 若删的是第一个元素，要前移 `n-1` 个元素，最坏情况是 **O(n)**；
- 平均移动次数约为 `(n-1)/2`，所以平均时间复杂度仍是 **O(n)**。

### 本质结论

<span class="kp">顺序表删除慢，根本原因和插入一样：需要批量移动元素。</span>

## 五、顺序表的应用：删除所有值等于 x 的元素

这是课件里最有价值的应用题，因为它开始进入“顺序表不只是背函数，而是拿来设计算法”的阶段。

### 题目

已知长度为 `n` 的线性表 `L` 采用顺序存储结构，设计一个：

- 时间复杂度为 `O(n)`；
- 空间复杂度为 `O(1)`；

的算法，删除线性表中所有值为 `x` 的元素。

---

### 解法一：整体建表法

#### 思路

扫描原顺序表，只保留不等于 `x` 的元素，重建一个结果表。

#### 代码

```cpp
void delnode1(SqList *&L, ElemType x)
{
    int k = 0, i;
    for (i = 0; i < L->length; i++)
        if (L->data[i] != x)
        {
            L->data[k] = L->data[i];
            k++;
        }
    L->length = k;
}
```

#### 怎么理解

`k` 始终表示：当前已经保留下来的“不等于 x 的元素个数”。

扫描到一个元素：

- 如果它不等于 `x`，就把它放到前面的保留区；
- 如果它等于 `x`，就跳过。

最后把 `length` 改成 `k` 即可。

#### 本质

这其实是一种“筛选 + 重写”的思路。

### 解法二：前移法

#### 思路

用 `k` 记录已经遇到多少个值等于 `x` 的元素。

当扫描到一个不等于 `x` 的元素时，就把它前移 `k` 个位置。

#### 代码

```cpp
void delnode2(SqList *&L, ElemType x)
{
    int k = 0, i = 0;
    while (i < L->length)
    {
        if (L->data[i] == x)
            k++;
        else
            L->data[i - k] = L->data[i];
        i++;
    }
    L->length -= k;
}
```

#### 怎么理解

如果前面删掉了 3 个 `x`，那后面遇到一个合法元素，就应该往前补 3 个位置。

这个思路比整体建表法更像“在原地压缩数组”。

### 解法三：区间划分法

课件还给了区间划分法，本质上是维护两个区间：

- 左边是“不为 x 的区间”；
- 右边是“尚未处理的区间”；

当遇到不等于 `x` 的元素，就扩展左边区间；遇到等于 `x` 的元素，就略过不扩展。

它和前移法本质上很近，只是解释方式更偏“区间维护”。

## 2.5 有序表

有序表是线性表中的特殊情况。

<span class="kp">有序表（Ordered List）本质上还是线性表，只不过表中元素按关键字有序排列。</span>

它的价值在于：

- 查找时更高效；
- 可以利用顺序性设计算法；
- 是很多更复杂结构和算法的基础。

<blockquote>易错：有序表不是另一种“完全不同”的结构，它仍然是线性表，只是多了“元素有序”这一约束。</blockquote>

---

## 第二章终极复习总结

这一章真正要掌握的不是零散代码，而是以下主线：

1. **线性表是最基本的线性逻辑结构**：元素同类型、有限、有序。
2. **线性表 ADT 有 9 个基本操作**：初始化、销毁、判空、求长度、输出、按位置取值、按值查找、插入、删除。
3. **顺序表是线性表的顺序存储实现**：元素按逻辑顺序存放在一段连续空间中，用 `data[] + length` 表示。
4. **逻辑位序与物理下标相差 1**：第 `i` 个元素在 `data[i-1]`。
5. **顺序表的优点**：支持随机访问，`GetElem` 时间复杂度 O(1)。
6. **顺序表的缺点**：插入、删除时需要大量移动元素，平均时间复杂度 O(n)。
7. **顺序表可以直接用来设计算法**：比如删除所有值为 `x` 的元素。
8. **链表存在的意义**：弥补顺序表在插删操作上的不足。
9. **有序表是特殊线性表**：关键字有序，便于设计算法。

---

## 第二章易错点清单

1. 逻辑位序从 1 开始，数组下标从 0 开始。
2. `length` 表示当前有效长度，不表示容量。
3. `GetElem` 和 `LocateElem` 的意义不同、复杂度也不同。
4. 插入元素时必须从后往前移动。
5. 删除元素时必须从前往后补位。
6. 顺序表插删慢，不是因为找位置难，而是因为元素移动成本高。
7. `SqList *&L` 的引用参数是为了把新地址带回实参。
8. 有序表不是新结构，而是加了有序约束的线性表。
