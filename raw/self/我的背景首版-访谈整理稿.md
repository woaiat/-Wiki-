# 我的背景首版（访谈整理稿）

## 说明

这份材料来自我和 AI 的引导式聊天整理，目的是作为个人背景的原始输入。
它不是最终版，也不是稳定结论页。
其中有些内容是客观经历，有些内容是我当前的自我评价，后续还需要继续补充和修正。

## 一、基础事实

- 我是湖南人。
- 高中就读于长沙南雅中学。
- 高考 `599` 分。
- 最终被海南大学录取。
- 就读专业是计算机科学学院的软件工程（`NIIT`）。
- `NIIT` 专业采用和印度合作办学的模式，带有一定中外合作办学色彩。
- 这也是我正式踏上计算机学习之旅的起点。

## 二、专业选择时的初始心态

- 我对计算机这个学科本身是有兴趣的，因为它是一门我以前没有深度接触过、但又不让我觉得枯燥的理科。
- 如果只看兴趣，我高中阶段最喜欢的学科其实是数学。
- 但我当时也考虑到纯数学专业比较难读，而且就业现实不一定理想，所以最后对软件工程这个选择整体是比较满意的。
- 这说明我在专业选择上，既看兴趣，也会考虑现实路径。

## 三、高考后暑假：第一次提前接触编程学习

- 高考后的暑假，我报过一个网课。
- 我现在已经不太记得最初是怎么接触到它的，但报名的直接原因是：我想提前学习。
- 我当时对自己的自学能力、自律能力和认知能力是比较自信的。
- 我希望通过主动学习和持续投入，让自己比普通同龄人更强，也不断丰富自己。

### 当时学了什么

- Python 入门和加深部分
- 前端三件套：`HTML / CSS / JavaScript`
- Python 的基础部分大体学完了
- 面向对象没有学完
- 前端实际只做过一个静态登录页面

### 当时是怎么学的

- 学习态度非常认真
- 每天在平板上手写代码
- 课后会在电脑上用 PyCharm 做老师布置的算法题

### 现在回看

- 这段经历让我真正入了 Python 的门
- 但当时的方法存在明显低效问题：
  - 手写代码后续复习价值不高
  - 实际代码输出量还是太少
  - 学过的前端内容现在大多已经遗忘
- 我后来开始意识到：认真不等于高效，输入和输出的组织方式很重要

## 四、大一上：数学学习流在大学里跑通

- 进入大学后，我很快发现很多老师讲课对我帮助不大。
- 于是我基本转向了完全自学模式。
- 这套自学模式最先仍然是从我最擅长的数学开始。

### 高中带来的旧方法

我高中时已经形成过一套比较完整的数学学习逻辑：

1. 先建立完整知识体系
2. 再通过大量输出和刷题完成巩固
3. 最后通过持续训练达到掌握

到了大学之后，我基本是把这套方法迁移到了高数上。

### 大一上高数的具体做法

- 输入：
  - B 站孔祥仁老师的高数课
- 输出：
  - 同济版高数教材练习
  - 宋浩老师编写的高数 750 题
- 日常方式：
  - 上高数课时坐后排
  - 听自己的网课
  - 用平板记笔记
  - 学完一个章节就开始输出刷题训练

### 结果

- 期中考试高数 `100`
- 期末考试高数 `96`

### 当前判断

- 这套方法在高数上被成绩和实际体验证明是可行的
- 它之所以能成功，也和我自己的自律程度有关
- 对我来说，数学线目前没有遇到明显瓶颈

## 五、大一上：编程学习开始暴露方法失配

- 和高数不同，编程学习没有那么顺利地套进原来的学习流。
- 我在大一上就已经隐约感觉到：编程不能完全照搬数学那套“体系 + 刷题”的方法。

### 当时的情况

- 输入方面，我试过不少老师的课程，也听过 B 站黑马程序员的课
- 但我感觉它们和我的学习方式不太匹配
- 输出方面，我一开始主要是在洛谷刷题
- 但刷着刷着，我就觉得自己学得不够系统

### 具体困惑

- 我没有像刷高数题那样获得“完全掌握知识点”的感觉
- 我不清楚代码学习该怎么记笔记
- 暑假阶段的平板手写代码笔记已经让我隐约感觉不合理
- 但我当时也没有形成清晰的电子代码笔记方案

### 当时的结论

- 大一上时，编程学习流并没有被我真正完美构建出来
- 不过因为当时 C++ 只学到指针和结构体，难度还没有完全爆发
- 所以问题已经出现了，但还没彻底把我逼到必须重构学习流的地步

## 六、2025 年 11 月：认识 B，认知开始被打开

### 事情的起点

- 大概在 `2025 年 11 月`，也就是大一上过了一半多的时候
- 我通过隔壁班同专业同学关系，认识了一个朋友的朋友，这里记为 `B`
- 起因是另一个朋友 `A` 在群里发积分题问我
- 我连续给出几道积分题的思路之后，A 告诉我这些题其实是 B 发来的
- B 因此对我很好奇，于是我加上了他的 QQ

### 初步印象

- 我和 B 很快相见如故，聊得非常投机
- 我感觉他也是一个认知水平较高、在主动搭建自己学习工作流的人
- 他也非常热爱数学
- 但这个阶段还只是“遇到了同类”，真正的转折还没完全发生

## 七、真正的转折：外部世界和工具链被打开

我认为大一上的一个重要转折点，是 B 教会了我如何翻墙。

### 对我影响最大的部分

- 对我影响最大的，不是他持续手把手带我做很多事，而是他帮我打开了一扇门。
- 这扇门后面最关键的东西就是：
  - 翻墙能力
  - Obsidian
  - Markdown
  - 国外的一线 AI 工具
- 如果没有别人点破，我主观上感觉自己很难那么快走出原有的信息环境，也很难自己摸索出这一整套工具链。

### 这个转折带来的东西

- 我学会了如何使用 `Clash Verge`
- 开始了解梯子、机场和外网资料获取
- 我开始意识到：如果想真正学计算机，只局限在原有信息环境里是远远不够的

### 更关键的是

我第一次真正大规模接触到国外的一线 AI 工具和学习基础设施：

- `Gemini / AI Studio`
- `Claude`
- `ChatGPT`
- `Obsidian`
- `Markdown`

### 当时的认知冲击

- 在这之前，我主要只接触过国内的豆包和 DeepSeek
- 我明显感觉到了国内外 AI 工具在能力上的差距
- 我开始第一次意识到：
  学习不仅仅是听课、刷题、记笔记，还可以建立一整套更强的工具链和工作流

## 八、大一上期末：AI 学习流第一次成功落地

### 1. Linux 课程案例

- 大一上有一门专业课叫 Linux
- 但不是操作系统层面那种非常底层的 Linux，只学了 pipe、shell 编程、vim 等基础内容
- 到期末考试前，我其实几乎一节课都没有认真听过
- 我当时是在很大压力下，用新的学习方式去救火

### 具体怎么学

- 我不再自己硬啃很厚的专业书
- 我先找到老师讲完每一章后发的 PDF 笔记
- 然后我把这些笔记输入 `AI Studio / Gemini`
- 再让 AI 按照“讲一个知识点 -> 立刻出题检测我是否搞明白”的方式带我学习
- 每学完一个章节，我就把这部分内容整理成 Markdown，记录进 Obsidian

### 结果

- 我用了两天左右速通这门课
- 最后 Linux 拿到了 `A`
- 也拿到了满绩点

### 这件事的意义

这不是单纯“我用了一次 AI”，而是我第一次把下面这条链条跑通了：

`结构化输入 -> AI 讲解 -> 即时检测 -> Markdown 沉淀`

这件事让我意识到，这套学习流是有实战价值的。

### 2. 思政课程案例

- 期末另一门课是思政
- 我也复制了类似的方法
- 并且最终在 Obsidian 里形成了现在能看到的思政笔记
- 那两天我基本上把这些内容全背下来了

### 结果与反思

- 最后考试只拿到了 `B`
- 我主观上觉得自己大题写得还可以，基本也是按背下来的知识点来的
- 所以我当前的判断是：
  - 这套方法是有应用价值的
  - 但它不是万能的
  - 它更适合速成、救火、压力很大、没有别的办法的时候使用
  - 平常长期学习，不建议完全这么学

## 九、科研线：从军训入组到开始真正改方法

### 起点：军训时期进入科研环境

- 科研这条线最开始其实很早，在军训时期就已经进入我的生活了。
- 当时软件工程专业开了一次座谈会，内容大多是就业、成长之类的话题。
- 其中有一个优秀学长上台分享，我现在不太记得他具体讲了什么，但我记得他最后留下了自己的微信号。
- 我主动加了他的微信，简单介绍了自己，也和他聊了一下。
- 他问我有没有兴趣做科研。
- 后来他让我在一个周日去农科楼面试。
- 面试我的是我现在的学业导师。
- 我和导师简单聊了一下之后，就被问要不要加入他们团队，我答应了。
- 从这里开始，我正式走上了科研这条路。

### 第一阶段：高强度读论文和读代码

- 刚进组之后，导师先和我聊天，说学长很喜欢我，希望我跟着他好好干。
- 导师也提到学长已经发过好几篇论文，很厉害。
- 然后学长开始给我分配任务。
- 他说他手上有一篇正在写的论文，要我先借这个过程学习怎么配置 Anaconda 环境。
- 同时，他也给了我几篇网安特征选择方向的论文，让我先去读。

### 第一次真正的硬仗：FSNID

- 大概在那之后的一个周日，我花了七八个小时读了 `FSNID` 这篇顶会论文。
- 我是从论文到核心代码一行一行认真看的。
- 不懂的地方，我就截图问 AI，再去学背后的知识点。
- 在这个过程中，我第一次系统接触到了很多：
  - PyTorch 相关知识
  - 机器学习知识
  - 深度学习知识
- 那天我在校外自习室一路读到晚上十二点。
- 最后我把论文和核心源码读完了，做好了批注，然后发给学长。

### 学长的反馈

- 学长当晚已经睡了，没有及时回复我。
- 第二天早上八点多，他回复我说他看了我的批注，觉得我大概是真的读懂了。
- 他还说，目前我是他认识的本科生里，为数不多有能力做这个事情的人。
- 这对我来说是一次很强的认可。
- 后来他和我说，我大概可以开始读他正在写的论文了，读懂之后也可以逐步开始改。
- 但当时已经接近期末考试，所以他又提醒我：期末和绩点还是优先，因为保研首先看这些硬指标。

### 期末之后：正式进入执行层

- 期末考试结束之后，我先放松玩了一周多。
- 后来学长把我和其他一些人拉进了一个群，群名叫 `Feature selection`。
- 从这时开始，他开始给我们每个人分配更具体的任务。
- 他先让我负责跑实验，并自己写了一个 Excel 表格，让我把实验数据填进去。
- 从那之后，我就开始每天跑实验、填表、给学长汇报结果。

### 这时我第一次接触到 agent

- 也是在这个阶段，我第一次接触到了 `agent` 这种工具。
- 这和我前面接触到的 `Gemini / ChatGPT / Claude` 这种对话式 AI 不太一样。
- 我当时最早接触到的 agent 是字节旗下的 `Trae`。
- 现在回头看，Trae 并不好用：
  - 上下文很短
  - 幻觉比较高
- 但不管怎么说，它第一次让我接触到了那种权限更高、自主性更强的 AI。

### 第一次真正有“我在做科研”的感觉

- 真正让我感觉自己已经在做科研，不再只是读论文或跑别人安排好的实验，是学长开始让我自己尝试改代码的时候。
- 学长看了我跑出来的几个数据集结果之后，告诉我他目前的方法还不够完善，打不过其他 baseline。
- 于是他让我自己试试能不能改代码、改方法。
- 从这时开始，我的角色发生了变化：
  - 不再只是执行实验
  - 而是开始参与方法改进

### 那段时间的状态

- 我每天一边自己了解深度学习知识
- 一边让 Trae 给我提供一些改代码和改方法的灵感
- 跑实验、填表、对结果、继续改
- 到后面，群里基本上就只剩下我和学长还在频繁说话
- 再往后，基本就变成我和学长私聊推进了

### 一作预期带来的冲击

- 后来学长告诉我，如果这篇论文最终投出去，我大概率会是一作，他自己不要这个一作。
- 当时我还是很兴奋的。
- 因为对一个大一学生来说，如果真能做出一篇自己的一作，而且还是有机会投一区的论文，这种刺激是非常强的。

### 方法改进的实际过程

- 我第一次改动，其实只是一些细枝末节的小修小补。
- 跑完实验之后发现没什么变化。
- 后面改着改着甚至还改乱了，`retain` 变得非常小，结果几乎全部崩掉。
- 再之后，我进行了第二次更大的改动。
- 这一次已经不再是小修小补，而是开始重写 `SCL_CMIE` 方法本身。
- 其中也包括对 `BACLoss` 原来的双向锚点思想进行重构，改成别的办法。
- 目前这条线还在写初稿。

## 十、寒假：编程学习流第一次系统化重构

### 为什么会开始重构

- 寒假开始之后，我开始更明确地意识到：
  我大一上几乎没有留下什么像样的编程笔记。
- 这就意味着，我必须开始构建一套真正适用于编程学习的学习流。
- 同时，我也知道大一下会学一门很关键的课：数据结构与算法。
- 这门课本身也是计算机专业四大件之一，所以我决定提前自学。

### 寒假时的输入与输出

- 我先在 GitHub 上找教程。
- 后来找到了两个非常经典的教程：
  - `hello-algo`
  - `labuladong` 的算法笔记
- 寒假期间，我主要就是跟着这两个网页学习。

### 具体学习方式

- 输入：
  - `hello-algo`
  - `labuladong`
- 输出：
  - 跟着对应章节去 `LeetCode` 刷对应知识点的题目
- 也就是说，我第一次在编程学习里形成了比较稳定的：
  - 系统输入
  - 对应输出

### 为什么它们比我大一上的方式更适合我

- 这些项目都是 GitHub 上很多 star 的经典项目，口碑很好。
- 它们本身就非常系统。
- 也非常符合我的思维方式。
- 输入非常稳定。
- 输出也会推荐对应知识点的 LeetCode 题目。
- 所以它们当然比我大一上那种在洛谷乱刷题更好。

### 当时为什么还没有建立笔记层

- 寒假这一阶段，我还没有真正开始记自己的算法笔记。
- 因为我当时觉得 `labuladong` 本身整理得已经非常完善了。
- 所以我主观上觉得，暂时没有必要自己再重新造一套重复的笔记。
- 但我已经开始意识到，以后还是应该想办法构建自己的算法笔记系统。

### 这段经历的额外意义

- 也是从寒假开始，我开始慢慢把 GitHub 当成一个真正的开源知识库来使用。
- 这也是我编程学习方式变化的一部分。

### 当前状态

- 截止 `2026-04-25`，我在算法学习上仍然主要在沿用这一套方法。
- 到目前为止，我还没有对这条线做出下一次更大的升级。

## 十一、当前对学习流的阶段性认识

到目前为止，我已经形成了几个比较明确的判断：

- 高数线：
  - 原有数学学习流是被验证过的
- 编程线：
  - 不能简单照搬高数那套
  - 大一上时还没有构建完整
  - 到寒假开始，已经形成了“系统输入 + 对应输出”的编程学习流雏形
  - 但我现在觉得自己后来大概已经构建出来了，只是这里还没有继续展开
- AI 辅助线：
  - 速成和救火场景下非常强
  - 但也有明显边界
- 科研线：
  - 我很早就进入了科研环境
  - 而且并不只是打杂，而是很快进入了读论文、跑实验、改方法的状态

## 十二、长期目标（当前版本）

### 核心目标

- 我不打算未来只停留在当前这所 211
- 我希望未来能够保研到一所至少中上水平的 985

### 这个目标从什么时候开始

- 我从大一一开始就在为这个目标奋斗
- 大一上拼命学高数，本身也是为了这个目标服务

### 当前抓手

- 高优秀率
- 科研
- 学习流和认知系统的持续升级

### 当前环境变化

- 学校改革后，不再主要看传统绩点，而更看优秀率
- 例如期末总分 `85` 分以上就算 `A`
- 学校说这是为了降低内卷，让大家更能享受大学生活
- 但这对我这种原本能把高数冲到接近满分的人来说，并不完全友好
- 因为这意味着我原来在分数上的优势，有一部分被制度压平了

### 当前感受

- 这在一定程度上减轻了整体压力
- 但也让我更在意：我接下来到底还能通过什么方式继续拉开差距

### 这个目标背后的补充动机

- 对我来说，保研到更好的学校本身就是一个很重要的外部目标。
- 除了发展路径上的考虑之外，这里面也带有一种“证明自己”的动机。
- 我希望向父母、亲戚、童年里关系好的朋友，以及一些熟悉我的叔叔阿姨证明自己。

## 十三、当前能看出来的个人特征（初步）

### 客观能看到的倾向

- 我会主动建立自己的学习系统，而不是完全跟着老师走
- 我愿意长期投入和高强度执行
- 我会复盘自己的方法，而不只是机械努力
- 我会主动寻找更强的工具、更强的平台和更强的路径

### 我的自我评价

- 我认为自己的认知水平至少高于我认识的大部分同学
- 我认为自己不是普通意义上随波逐流的人
- 我相信自己会持续迭代和进化自己的认知与学习流
- 我对自己未来的要求明显高于“顺利毕业、找份普通工作”这种标准路径

### 核心内在驱动力（补充）

- 我非常享受自己慢慢进步的过程。
- 我喜欢用更加强大的大脑和更丰富的不同领域技能不断包裹自己。
- 对我来说，学习和完善自我是推动我持续前进的一大核心动力。

### 低效或受挫时的恢复模式（补充）

- 当我效率低或者有些受挫时，我一般会先休息一下。
- 常见的恢复方式是打会游戏、刷会抖音，或者弹一会钢琴。
- 休息过后，我通常还是会回来继续学习。
- 不过这里也有一个边界问题：有时候我会不小心花掉太多时间。
