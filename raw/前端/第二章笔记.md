**1. 什么是 CSS**
CSS 全称是 `Cascading Style Sheets`，中文一般叫“层叠样式表”。

它的作用是：

* 改变 HTML 元素的外观
* 控制页面布局
* 让整个网站的风格保持一致
* 把“内容”和“表现”分开

文字化理解：

* HTML 负责“内容和结构”
* CSS 负责“样式和排版”

你可以把它理解成：

* HTML 是毛坯房结构
* CSS 是装修方案

**2. CSS 的基本语法**
CSS 的基本格式是：

```
selector {
    property: value;
}
```

解释：

* `selector`：选择器，表示“你想改谁”
* `property`：属性，表示“改哪一项”
* `value`：值，表示“改成什么样”

例子：

```
h1 { color: red; font-style: italic; }
h2 { font-weight: bold; }
```

解释：

* 所有 `h1` 变成红色斜体
* 所有 `h2` 变成加粗

例题：

* `p { color: blue; }` 的意思是什么？
* 答：把所有 `p` 段落文字变成蓝色

**3. 为什么要用 CSS**
原理上，CSS 的意义有 3 个：

* 更好控制布局
* 保持页面显示一致
* 把内容和样式分离，方便维护

文字化理解：
如果不用 CSS，你每个标签都单独写样式，会特别乱。
如果用了 CSS，就像先定一套统一规则，网页里的很多元素会自动按这套规则显示。

**4. CSS 三种写法**
第二章重点之一就是这个。

### 4.1 行内样式 `inline style`

直接写在标签内部，用 `style` 属性。

```
<P style="font-size:24pt; color:red;">Hotel booking from the comfort of your room.</P>
```

解释：

* 只对当前这个元素生效
* 优先级最高

### 4.2 内部样式表 `internal / embedded`

写在 `<head>` 里的 `<style>` 标签中。

```
<STYLE>
  p { color:red; font-size:20pt; font-style:italic; }
</STYLE>
```

解释：

* 只影响当前这个页面
* 适合单个页面统一样式

### 4.3 外部样式表 `external`

写在单独的 `.css` 文件里，然后通过 `<link>` 引入。

```
<LINK type="text/css" rel="stylesheet" href="externalstyle.css">
```

`externalstyle.css`：

```
p { color:red; font-size:20pt; }
h1 { color:blue; font-weight:bold; }
```

解释：

* 最适合多页面网站
* 最常用、最好维护

**5. CSS 优先级**
PDF 里给出的优先级从高到低是：

1. 行内样式
2. 内部样式表
3. 外部样式表
4. 浏览器默认样式

解释：
如果同一个元素、同一个属性在多个地方都被设置了，优先级高的生效。

例题：
假设：

```
<p style="color: red;">Hello</p>
```

同时内部样式里写了：

```
p { color: blue; }
```

问：最后是什么颜色？
答：红色，因为行内样式优先级更高。

**6. 选择器：CSS 到底选谁**
这一章重点讲了 `ID` 和 `class`，还补了组合选择器。

### 6.1 ID 选择器 `#`

用于选中唯一元素。

```
#pname { color:green; font-weight:bold; }
```

```
<P ID="pname">Welcome to BookYourHotel Website.</P>
```

解释：

* `#` 表示 ID
* 一个页面里一个 ID 通常对应一个唯一元素

### 6.2 class 选择器 `.`

用于给多个元素套同一套样式。

```
.first { font-size:20px; color:red; font-weight:bold; }
```

```
<H1 class="first">Welcome</H1>
<P class="first">This site gives info.</P>
```

解释：

* `.` 表示类
* 多个不同标签都可以共用同一个 class

例题：

* 如果你想让 10 个地方都用同一套红色加粗样式，应该用 `id` 还是 `class`？
* 答：`class`，因为它适合复用

**7. 常用 CSS 属性**
这一章把属性分成几类。

### 7.1 字体属性

* `font-family`
* `font-size`
* `font-style`
* `font-variant`
* `font-weight`

例子：

```
p { font-family: "Helvetica"; font-size:20px; }
```

### 7.2 文本属性

* `text-align`
* `text-indent`
* `line-height`
* `color`
* `text-decoration`
* `text-transform`
* `letter-spacing`

例子：

```
p {
  text-align: center;
  color: red;
  text-decoration: underline;
}
```

解释：

* `text-align`：对齐方式
* `color`：文字颜色
* `text-decoration`：下划线、删除线等
* `text-transform`：大小写转换

### 7.3 列表属性

* `list-style-type`
* `list-style-position`
* `list-style-image`

例子：

```
ul { list-style-type:square; list-style-position:inside; }
```

### 7.4 背景属性

```
body { background-color: lavender; }
div { background-image: url('img.gif'); }
```

解释：

* `background-color`：背景色
* `background-image`：背景图

**8. 组合选择器和嵌套选择器**

### 8.1 分组选择器

多个元素共用同一套样式，用逗号分开。

```
h1, p { color: red; }
```

解释：

* 所有 `h1` 和 `p` 都变红

### 8.2 后代选择器

```
div p
```

解释：

* 选中所有在 `div` 里面的 `p`

### 8.3 子代选择器

```
div > p
```

解释：

* 只选中父元素是 `div` 的直接子元素 `p`

### 8.4 相邻兄弟选择器

```
div + p
```

解释：

* 选中紧跟在 `div` 后面的那个 `p`

### 8.5 通用兄弟选择器

```
div ~ p
```

解释：

* 选中在 `div` 后面的所有同级 `p`

例子：

```
li a { color: red; text-decoration: none; }
```

解释：

* 选中所有 `li` 里面的链接 `a`

**9. `display` 和 `visibility`**
这是非常容易考区别的点。

### 9.1 `display`

```
display: none;
display: block;
display: inline;
```

解释：

* `none`：隐藏，而且不占位置
* `block`：块级显示，独占一行
* `inline`：行内显示，只占需要的宽度

例子：

```
li { display: inline; list-style-type:none; }
```

解释：

* 让列表横着排，常用于横向菜单

### 9.2 `visibility`

```
visibility: hidden;
visibility: visible;
```

解释：

* `hidden`：隐藏，但原来的空间还在
* `visible`：正常显示

例题：

* 问：如果一个元素要“看不见并且不占地方”，用哪个？
* 答：`display: none`
* 问：如果一个元素要“看不见但位置保留”，用哪个？
* 答：`visibility: hidden`

**10. 定位 `position`**
这是第二章后半段核心。

### 10.1 `static`

默认值，正常文档流。

解释：

* 元素按正常顺序排列
* `top`、`left` 这些通常不起作用

### 10.2 `relative`

相对自己原来的位置移动。

解释：

* 原来的位置还保留
* 只是视觉上偏移了

### 10.3 `absolute`

绝对定位，相对最近的已定位祖先元素定位。

解释：

* 元素脱离正常文档流
* 不再占原来的位置

### 10.4 `fixed`

相对浏览器窗口定位。

解释：

* 页面滚动时它还固定在原处
* 常见于“回到顶部按钮”或固定导航栏

例子：

```
h3 { position: absolute; top:0px; }
```

补充：
`top`、`bottom`、`left`、`right`、`z-index` 通常配合非 `static` 使用。

例题：

* 问：页面滚动时还停在屏幕顶端的导航条，最适合哪个定位？
* 答：`fixed`

**11. `float` 和 `clear`**

### 11.1 `float`

```
float: left;
float: right;
float: none;
```

解释：

* 让元素浮到左边或右边
* 周围文字会环绕它

### 11.2 `clear`

```
clear: both;
clear: left;
clear: right;
```

解释：

* 清除浮动影响
* 常用于“不要再围着浮动元素排版了，另起一行”

例子：

```
img { float: left; }
.special { clear: both; }
```

文字化理解：

* `float` 像把图片推到左边，正文绕着它流动
* `clear` 像告诉后面的元素：“别绕了，从下面开始”

**12. 第二章最小例子**

```
<!DOCTYPE html>
<html>
<head>
  <title>CSS Demo</title>
  <style>
    h1 { color: red; }
    .note { font-size: 20px; }
    #tip { display: inline; color: blue; }
  </style>
</head>
<body>
  <h1>Welcome</h1>
  <p class="note">This is a paragraph.</p>
  <span id="tip">Important tip</span>
</body>
</html>
```

这个例子里你要能看懂：

* `h1` 是元素选择器
* `.note` 是类选择器
* `#tip` 是 ID 选择器
* 样式写在 `<style>` 里，属于内部样式表

**第二章小结**

* CSS 是控制样式和布局的规则系统。
* 三种写法必须记住：行内、内部、外部。
* 优先级要记住：行内 > 内部 > 外部 > 默认。
* 选择器重点记 `id` 和 `class`，再理解组合选择器。
* `display:none` 和 `visibility:hidden` 的区别一定会考。
* `position`、`float`、`clear` 是布局基础。

最简单地说，这一章就是在学：**怎么让 HTML 页面按你想要的样子显示出来。**
