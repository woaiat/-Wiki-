## 1. 什么是 jQuery

### 定义 / 原理

jQuery 是一个  **轻量级 JavaScript 库** 。

它的作用是：

* 简化 HTML 操作
* 简化事件处理
* 简化动画效果
* 屏蔽不同浏览器之间的一些差异

### 文字化解释

你可以把 jQuery 理解成：

**把原来比较麻烦的 JavaScript 操作，压缩成更短、更好写的代码。**

所以它最经典的一句话就是：

**Write less, do more.**

---

## 2. 怎么把 jQuery 放进网页

### 原理

要先把 jQuery 文件引入页面，后面才能写 jQuery 代码。

### 例子

```
<script src="jquery-1.8.3.js"></script>
```

### 解释

这和第四章引入外部 JavaScript 文件一样。
区别是：这里引入的是  **jQuery 库本身** 。

## 3. `$(document).ready()` 是什么

### 定义 / 原理

```
$(document).ready(function(){
  // jQuery code
});
```

它的作用是：

**等页面里的 HTML 元素都加载完，再执行 jQuery 代码。**

### 文字化解释

为什么要这样做？

因为如果你的代码先执行，但页面元素还没出现，代码就可能找不到这些元素，导致报错。

所以它本质上是在说：

**“先等页面准备好，再动手。”**

### 例子

```
$(document).ready(function(){
  $("h1").hide();
});
```

### 解释

页面加载完成后，把所有 `h1` 隐藏。

---

## 4. jQuery 的基本语法

### 定义 / 原理

jQuery 最核心的格式是：

```
$(selector).action()
```

### 解释

* `$()`：jQuery 的入口
* `selector`：你想选谁
* `action()`：你想对它做什么

### 例子

```
$("h1").hide();
```

意思就是：

* 选中所有 `h1`
* 然后隐藏它们

---

## 5. jQuery 选择器

这一章重点之一就是选择器。
它和 CSS 选择器很像。

### 5.1 按标签名选

```
$("h1")
```

表示选中所有 `h1`

### 5.2 按 id 选

```
$("#header")
```

表示选中 `id="header"` 的元素

### 5.3 按 class 选

```
$(".product")
```

表示选中所有 `class="product"` 的元素

### 5.4 组合选择

```
$("h1#main")
$("div.product")
```

解释：

* `h1#main`：`h1` 并且 `id="main"`
* `div.product`：`div` 并且 `class="product"`

### 5.5 属性选择

```
$("[src]")
$("[src='movie.jpg']")
```

解释：

* 第一个：选中所有有 `src` 属性的元素
* 第二个：选中 `src="movie.jpg"` 的元素

### 5.6 层级选择

```
$("#menu ul")
$("#menu li a")
```

解释：

* `#menu ul`：`#menu` 里面所有 `ul`
* `#menu li a`：`#menu` 里面 `li` 中的 `a`

### 例子

```
$('#menu ul').hide();
```

意思：
把 `#menu` 里面所有子菜单先隐藏。

## 6. 操作内容

这一章讲了几个常见方法。

### 6.1 `html(content)`

设置或获取 HTML 内容

### 6.2 `append(content)`

在元素最后面追加内容

### 6.3 `prepend(content)`

在元素最前面插入内容

### 6.4 `after(content)`

在元素后面插入内容

### 6.5 `remove()`

删除元素本身和它的子元素

### 6.6 `empty()`

只删除子元素，保留当前元素本身

### 例子

```
$("#para").prepend("<b>jQuery</b> ");
$("#para").append(" <b>append() function</b>");
$("#newhead").remove();
```

### 解释

* `prepend()`：前面加内容
* `append()`：后面加内容
* `remove()`：整个删掉

### 例题理解

如果你想给段落末尾补一句话，最合适的是哪个？
答：`append()`

## 7. 事件处理

### 定义 / 原理

事件就是“用户做了某个动作后，网页触发响应”。

jQuery 用方法来绑定事件。

### 常见事件

* `click()`：点击
* `dblclick()`：双击
* `mouseenter()`：鼠标移入
* `mouseleave()`：鼠标移出
* `keydown()`：按键按下
* `submit()`：表单提交
* `focus()` / `blur()`：获得焦点 / 失去焦点

### 例子

```
$("button").click(function(){
  $("h1").hide();
});
```

### 解释

* 用户点击按钮
* 所有 `h1` 被隐藏

这和第四章的事件思想是一样的，只是 jQuery 写起来更短。

## 8. 视觉效果

这是第五章最核心的一块。

---

### 8.1 `hide()` 和 `show()`

#### 原理

* `hide()`：隐藏
* `show()`：显示

#### 例子

```
$("h1").hide("slow");
$("h1").show(2000);
```

#### 解释

* `"slow"`：慢速隐藏
* `2000`：2000 毫秒，也就是 2 秒

---

### 8.2 `toggle()`

#### 原理

`toggle()` 表示：

**如果当前是显示，就隐藏；如果当前是隐藏，就显示。**

#### 例子

```
$("p").toggle("fast");
```

#### 解释

这是一种“来回切换”的效果。

---

### 8.3 `slideDown()` / `slideUp()` / `slideToggle()`

#### 定义

* `slideDown()`：向下滑出
* `slideUp()`：向上收起
* `slideToggle()`：在收起和展开之间切换

#### 例子

```
$(".flipbut").click(function(){
  $(".thought").slideToggle();
});
```

#### 解释

点击按钮后，`.thought` 这个元素如果原来隐藏就滑下来，如果原来显示就滑上去。

这是考试很喜欢出的点。

---

### 8.4 `fadeOut()` / `fadeIn()`

#### 定义

* `fadeOut()`：淡出
* `fadeIn()`：淡入

#### 例子

```
$("div").fadeOut(1200);
$("button").click(function(){
  $("div").fadeIn(1200);
});
```

#### 解释

* `1200` 表示 1.2 秒
* 元素不是突然消失，而是慢慢透明掉

---

### 8.5 `animate()`

#### 定义 / 原理

`animate()` 用来做自定义动画。

#### 例子

```
$("div").animate({
  left: '250px',
  opacity: '0.5',
  height: '250px',
  width: '250px'
}, 1000);
```

#### 解释

这段代码的意思是：

* 元素向右移动
* 透明度变成 0.5
* 高和宽都变化
* 整个过程持续 1000 毫秒

#### 语法

```
animate({params}, speed, callback)
```

#### 你只要记住

`animate()` 本质上就是：

**平滑地修改 CSS 属性。**

## 9. 真实例子：滑动菜单

### 例子

```
$(document).ready(function(){
  $("#menu ul").hide();
  $("#menu li a").click(function(){
    $(this).next().slideToggle('slow');
  });
});
```

### 解释

这段代码的逻辑是：

1. 页面加载后，先把菜单下面的子菜单隐藏
2. 点击某个菜单项
3. 它后面的子菜单就展开或收起

### 为什么重要

因为这段代码把第五章几个核心点串起来了：

* `ready`
* 选择器
* `click()`
* `hide()`
* `slideToggle()`
* `this`
* `next()`

## 10. 插件：`colorbox`

### 定义 / 原理

jQuery 插件是对 jQuery 功能的扩展。
`colorbox` 是一个常见的图片灯箱插件。

它的作用是：

**点击图片或链接时，用弹出层的方式显示大图或相册。**

### 安装思路

课程里给出的步骤是：

* 引入 `colorbox.css`
* 引入 `jquery.colorbox.js`
* 调用 `$("a").colorbox();`

### 最小例子

```
<link rel="stylesheet" href="css/colorbox.css">
<script src="jquery-1.8.3.js"></script>
<script src="jquery.colorbox.js"></script>
<script>
  $(document).ready(function(){
    $("a").colorbox();
  });
</script>
<a href="product.png">View product</a>
```

### 解释

点击链接后，不是直接跳转，而是弹出图片展示层。

---

## 11. `colorbox` 的自定义设置

### 例子

```
$("a").colorbox({
  transition: "fade",
  height: "250",
  width: "220"
});
```

### 解释

* `transition: "fade"`：淡入淡出切换
* `height` / `width`：控制弹窗尺寸

---

## 12. 图片组与轮播

### 例子

```
<a rel="gallery" href="img1.jpg">Image 1</a>
<a rel="gallery" href="img2.jpg"></a>
<a rel="gallery" href="img3.jpg"></a>
```

### 原理

多个图片使用相同的 `rel="gallery"`，就会被当作一组。

### 解释

这样打开一张图后，就能切换上一张 / 下一张。

### 幻灯片模式

```
$("a").colorbox({slideshow: true, current: false});
```

### 解释

* `slideshow: true`：开启幻灯片播放
* `current: false`：隐藏当前图片编号等信息

## 13. `galleria` 插件

### 定义

`galleria` 也是一个图片插件。

### 和 `colorbox` 的区别

* `colorbox`：更像弹出的灯箱效果
* `galleria`：更像页面内部的缩略图库

### 解释

课程里这块你只需要记住对比关系，不需要抠太深实现细节。
