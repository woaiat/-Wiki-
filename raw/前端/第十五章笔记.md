 **第 15 章：Rendering, Transition & Animation** 。
这一章的主线很清楚：

* `v-if / v-else / v-show`：控制“显不显示”
* `v-for`：控制“列表怎么渲染”
* `transition / animation`：控制“显示和隐藏时怎么动”

你可以把这章理解成：

**Vue 怎么控制页面出现什么，以及这些内容出现/消失时怎么过渡。**

---

**1. `v-if`：条件渲染**
`v-if` 的定义是： **条件为真才渲染这个元素** 。
如果条件是 `false`，这个元素会被 **直接从 DOM 里删掉** 。

例子核心代码：

```
<button @click="showdata">Click Me</button>
<h1 v-if="show">This is h1 tag</h1>
<h2>This is h2 tag (always visible)</h2>
```

```
data() {
  return { show: true }
},
methods: {
  showdata() {
    this.show = !this.show;
  }
}
```

解释：

* 初始时 `show = true`，所以 `h1` 显示
* 点击按钮后，`show` 变成 `false`
* `h1` 不只是“隐藏”，而是**整块从 DOM 中移除**

这题最该记住的点：

* `v-if` = 真则渲染，假则删除
* 它影响的是 **DOM 是否存在**

---

**2. `v-if` 和 `v-else`：二选一切换**
`v-else` 的定义是： **当前面的 `v-if` 为假时显示** 。
并且它必须**紧跟在** `v-if` 或 `v-else-if` 后面。

例子核心代码：

```
<h1 v-if="show">This is h1 tag</h1>
<h2 v-else>This is h2 tag</h2>
```

解释：

* `show = true` 时，显示 `h1`
* `show = false` 时，显示 `h2`
* 两个不会同时显示

这个例子想说明的就是：
**Vue 可以根据同一个布尔值，在两个内容之间切换。**

你该记住：

* `v-if` / `v-else` 经常成对出现
* `v-else` 必须紧跟 `v-if`

---

**3. `v-show`：只改显示，不删 DOM**
这是本章最容易和 `v-if` 混的点。

`v-show` 的定义是：**元素始终在 DOM 中，只是通过 CSS 的 `display` 控制是否可见。**

例子核心代码：

```
<h1 v-if="show">This is h1 tag (v-if)</h1>
<h2 v-else>This is h2 tag (v-else)</h2>

<div v-show="show">
  <b>V-Show:</b>
  <img src="..." />
</div>
```

解释：

* `v-if` 那块：条件假了就删掉
* `v-show` 那块：条件假了不删，只是 `display: none`

这章最核心的比较就是：

* `v-if`：**真时创建，假时删除**
* `v-show`：**一直存在，只是显示/隐藏**

怎么记：

* 如果是“偶尔显示，切换不频繁”，更像 `v-if`
* 如果是“经常切换显示状态”，更像 `v-show`

考试里你只要先死记这个本质区别就行。

---

**4. `v-for`：列表渲染**
`v-for` 的定义是：**根据数组，把一组数据循环渲染成页面元素。**

例子核心代码：

```
<input @keyup.enter="showinputvalue" placeholder="Enter Fruits Names" />
<h1 v-if="items.length > 0">Display Fruits Name</h1>
<ul>
  <li v-for="(a, index) in items" :key="index">{{ a }}</li>
</ul>
```

```
data() {
  return {
    items: []
  }
},
methods: {
  showinputvalue(event) {
    if (event.target.value.trim()) {
      this.items.push(event.target.value.trim());
      event.target.value = "";
    }
  }
}
```

解释这段代码怎么工作：

1. 你在输入框里输入水果名
2. 按 Enter
3. `showinputvalue()` 被触发
4. 输入内容被 `push` 到 `items` 数组
5. `v-for` 自动把数组内容循环成多个 `<li>`

这里最关键的一句是：

```
<li v-for="(a, index) in items" :key="index">{{ a }}</li>
```

含义：

* `a`：当前这一项
* `index`：当前项下标
* `:key`：给每项一个唯一标识，方便 Vue 跟踪更新

你该记住：

* `v-for` 是列表渲染
* 语法常见是 `item in items`
* Vue 3 很强调 `:key`

---

**5. Fade Transition：淡入淡出**
这一节开始进入“过渡动画”。

Vue 用 `<transition>` 包住元素，再通过 CSS 类控制进入和离开的动画。

例子核心代码：

```
<button @click="show = !show">Click Here</button>

<transition name="fade">
  <p v-show="show">This is a Fade Transition Example</p>
</transition>
```

```
.fade-enter-active,
.fade-leave-active {
  transition: opacity 3s;
}

.fade-enter,
.fade-leave-to {
  opacity: 0;
}
```

解释：

* `name="fade"` 决定类名前缀是 `fade-*`
* 元素进入时，透明度从 `0 -> 1`
* 元素离开时，透明度从 `1 -> 0`
* 整个过程持续 3 秒

这个例子想证明：
**Vue 过渡 = `<transition>` + 对应 CSS 类。**

---

**6. ShiftX Transition：横向滑动**
这一节把动画从“透明度变化”升级到“位置变化”。

例子核心代码：

```
<transition name="shiftx">
  <div v-show="show">
    <img src="..." />
  </div>
</transition>
```

```
.shiftx-enter-active,
.shiftx-leave-active {
  transition: all 2s ease-in-out;
}

.shiftx-enter,
.shiftx-leave-to {
  transform: translateX(100px);
  opacity: 0;
}
```

解释：

* 元素进入前，先在右边 `100px`
* 同时透明度是 0
* 进入时滑回原位并显示出来
* 离开时再滑向右边并淡出

这个例子想说明：
**过渡不只可以改透明度，也可以改位置。**

---

**7. Rotate Animation：关键帧旋转**
这一节不再只是 `transition`，而是用了 `@keyframes`。

例子核心代码：

```
<transition name="shiftx">
  <div v-show="show">
    <img src="..." />
  </div>
</transition>
```

```
.shiftx-enter-active {
  animation: shift-in 2s;
}

.shiftx-leave-active {
  animation: shift-in 2s reverse;
}

@keyframes shift-in {
  0%   { transform: rotateX(0deg); opacity: 0; }
  25%  { transform: rotateX(90deg); opacity: 0.25; }
  50%  { transform: rotateX(120deg); opacity: 0.5; }
  75%  { transform: rotateX(180deg); opacity: 0.75; }
  100% { transform: rotateX(360deg); opacity: 1; }
}
```

解释：

* 进入时：按关键帧从 `0°` 转到 `360°`
* 离开时：同一套动画反向执行
* 所以看起来像 3D 翻转

这个例子想证明：
**复杂动画可以用 CSS `@keyframes`，Vue 负责触发时机。**

---

**8. Custom Transition Classes：接第三方动画库**
这一节是在说：
**Vue 不一定要你自己写所有动画类，它也能接外部动画库，比如 Animate.css。**

例子核心代码：

```
<transition
  enter-active-class="animate__animated animate__swing"
  leave-active-class="animate__animated animate__bounceOut"
>
  <p v-if="show" class="animation-text">
    See the animation effect
  </p>
</transition>
```

解释：

* 元素进入时，用 `animate__swing`
* 元素离开时，用 `animate__bounceOut`
* 不需要自己写复杂动画 CSS

这节最关键的思想是：
**Vue 的 `<transition>` 不只是用默认前缀类，也能显式指定自定义类。**

---

**9. 这一章最核心的区别题**
你之后做题最容易考的就是下面这三个区分：

1. `v-if` vs `v-show`
   * `v-if`：控制是否存在于 DOM
   * `v-show`：控制是否显示，DOM 一直在
2. `v-if` / `v-else`
   * 是条件二选一切换
3. `transition` vs `animation`
   * `transition`：两个状态之间平滑变化
   * `animation`：可以用关键帧做多阶段复杂动画

---

**10. 本章你必须记住的最小结论**

* `v-if`：条件渲染，假时删 DOM
* `v-else`：配合 `v-if` 做切换
* `v-show`：只改 `display`
* `v-for`：循环渲染列表，记得 `:key`
* `<transition>`：给元素进入/离开加过渡
* `name="fade"` 这种会生成对应前缀类
* `@keyframes`：做更复杂动画
* `enter-active-class / leave-active-class`：接第三方动画库

最简单总结一句：

**第 15 章是在学：Vue 怎么决定页面显示什么，以及这些内容出现和消失时怎么动起来。**
