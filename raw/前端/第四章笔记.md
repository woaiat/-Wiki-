好，这次我们正式过  **第四章** 。
这一章对应 PDF 里的 `Creating Dynamic Web Pages`，核心是：

**让网页接收用户输入，并用 JavaScript 处理这些输入。**

你可以把这一章分成两半：

* 前半：表单和各种输入控件
* 后半：JavaScript 让页面“动起来”

**1. 什么是表单 `form`**
`<form>` 是网页中专门用来收集用户输入的区域。

比如：

* 输入姓名
* 输入电话
* 选酒店
* 填意见
* 点击提交

最基本结构：

```
<form name="OrderFoodOnline" method="post" action="process.html">
  ...
</form>
```

常见属性：

* `name`：表单名字
* `id`：唯一标识
* `action`：提交到哪里
* `method`：提交方式，`get` 或 `post`
* `autocomplete`：自动补全开关
* `novalidate`：关闭浏览器默认验证
* `target`：结果显示位置

重点：

* `get`：数据拼到 URL 上，可见，长度有限
* `post`：数据不直接显示在 URL 上，更适合提交敏感或较多内容

例子：
登录密码更适合 `post`，不适合 `get`。

**2. `input` 是最重要的输入控件**
`<input>` 的功能由 `type` 决定。

常见类型：

```html
<input type="text" name="fname" placeholder="First name">
<input type="password" name="pwd">
<input type="email" name="email">
<input type="tel" name="phone">
<input type="url" name="website">
<input type="number" min="0" max="50">
```

解释：

* `text`：普通文本框
* `password`：密码框
* `email`：邮箱，浏览器会做基础验证
* `tel`：电话
* `url`：网址
* `number`：数字输入

例子：
如果要用户填邮箱，优先用 `type="email"`，不要只用 `text`。

**3. 单选、多选、日期、范围**
单选和多选：

```
<input type="radio" name="food" value="veg" checked> Vegetarian
<input type="radio" name="food" value="nonveg"> Non-vegetarian
<input type="checkbox" name="cuisine1" value="Continental"> Continental
```

解释：

* `radio`：单选
* `checkbox`：多选

日期、时间、滑动条：

```
<input type="date" name="bday">
<input type="time" name="usr_time">
<input type="range" min="10" max="50" step="5" value="10">
```

例题理解：

* 性别二选一：用 `radio`
* 兴趣爱好多选：用 `checkbox`

**4. `input` 常见属性**
这一章常考这些：

* `name`
* `id`
* `value`
* `placeholder`
* `required`
* `autofocus`
* `pattern`
* `autocomplete`
* `disabled`
* `readonly`
* `maxlength`
* `size`

重点区分：

* `required`：必填
* `placeholder`：提示文字
* `disabled`：禁用
* `readonly`：只读

例子：

```
<input type="text" placeholder="Enter your name" required>
```

意思是：有提示文字，而且不填不能提交。

**5. 下拉框 `select`**
如果用户要从多个选项中选择，可以用下拉框。

```
<select name="hotels" size="1" multiple>
  <option value="h1" selected>Taj</option>
  <option value="h2">Oberoi</option>
</select>
```

解释：

* `select`：下拉框本体
* `option`：每个选项
* `selected`：默认选中
* `multiple`：允许多选
* `size > 1`：显示成列表框

分组选项：

```
<select>
  <optgroup label="Italian">
    <option value="pasta">Pasta</option>
    <option value="fish">Fish</option>
  </optgroup>
  <optgroup label="Chinese">
    <option value="chow">Chowmein</option>
  </optgroup>
</select>
```

这里 `optgroup` 的作用就是分组。

**6. `label`、`fieldset`、`legend`**
`label` 用来给输入框加说明，而且点击文字也能聚焦到输入框。

```
<label for="name">Name:</label>
<input type="text" id="name">
```

`fieldset` 和 `legend` 用来把相关表单项分成一组。

```
<fieldset>
  <legend>Food preferences</legend>
</fieldset>
```

解释：

* `fieldset`：分组框
* `legend`：这组的标题

**7. 其他表单元素**
多行文本框：

```
<textarea rows="3" cols="16">Enter address</textarea>
```

自动提示：

```
<input list="states">
<datalist id="states">
  <option value="Alabama">
  <option value="California">
</datalist>
```

输出结果：

```
<form oninput="res.value=parseInt(a.value)+parseInt(b.value)">
  <input type="number" id="a"> + <input type="number" id="b">
  = <output name="res" for="a b"></output>
</form>
```

按钮：

```
<button type="submit">Send</button>
<button type="reset">Reset</button>
```

解释：

* `textarea`：多行输入
* `datalist`：输入建议
* `output`：显示计算结果
* `button`：按钮

**8. 什么是 JavaScript**
JavaScript 是运行在浏览器中的脚本语言。
它能做三件事：

* 操作页面元素
* 响应用户行为
* 验证表单

你可以把它理解成网页的“行为层”。

写法有两种：

内部脚本：

```
<script>
  alert('Hello, world!');
</script>
```

外部脚本：

```
<script src="myscript.js"></script>
```

**9. 变量、运算符、函数**
变量：

```
let message = "Hello";
var name = "John";
const PI = 3.14;
```

解释：

* `let`：现代常用
* `var`：旧写法，要认识
* `const`：常量

运算符只要会认：

* 算术：`+ - * / %`
* 赋值：`= += -=`
* 比较：`< > <= >= == != ===`
* 逻辑：`&& || !`

函数：

```
function showMessage(from, text) {
  alert(from + ': ' + text);
}
showMessage('Ann', 'Hello');
```

带返回值的函数：

```
function sum(a, b) {
  return a + b;
}
let result = sum(5, 3);
```

重点：

* `function` 定义函数
* `return` 返回结果
* 参数写在定义里，实参写在调用里

**10. 表单对象和验证**
这一章最重要的 JavaScript 知识点就是：

**用 `document.getElementById()` 取到输入框，再用 `.value` 取值。**

例子：

```
let nameField = document.getElementById("username");
let nameValue = nameField.value;
```

也可以先拿表单再拿元素：

```
let myForm = document.getElementById("orderForm");
let emailField = myForm.elements["email"];
```

但这章明确推荐你优先记：
`document.getElementById("fieldId")`

**11. 表单验证例子**

```
<script>
function validateForm() {
  let fname = document.getElementById("fname").value;
  if (fname == "") {
    alert("Name must be filled out");
    return false;
  }
  return true;
}
</script>

<form name="myForm" onsubmit="return validateForm()">
  Name: <input type="text" id="fname" name="fname">
  <input type="submit" value="Submit">
</form>
```

解释流程：

* 用户点提交
* 触发 `onsubmit`
* 调用 `validateForm()`
* 如果输入框为空，弹提示
* `return false` 阻止提交
* `return true` 允许提交

这段代码是这一章最值得会的例子。

**12. 本章最小工作例子**

```
<!DOCTYPE html>
<html>
<head>
  <title>Form Demo</title>
  <script>
    function validateForm() {
      let name = document.getElementById("fname").value;
      if (name == "") {
        alert("Name must be filled out");
        return false;
      }
      return true;
    }
  </script>
</head>
<body>
  <form onsubmit="return validateForm()">
    <label for="fname">Name:</label>
    <input type="text" id="fname" placeholder="Enter your name">
    <button type="submit">Submit</button>
  </form>
</body>
</html>
```

这个小例子把本章主线都串起来了：

* `form`
* `input`
* `label`
* `button`
* `JavaScript`
* `getElementById`
* `onsubmit`
* 表单验证

**本章小结**
第四章最核心的一句话是：

**表单负责收集输入，JavaScript 负责读取输入并检查输入是否合理。**

你现在最该记住的点：

* `form` 是表单容器
* `input` 的 `type` 决定控件种类
* `radio` 单选，`checkbox` 多选
* `select/option/optgroup` 是下拉选择
* `label/fieldset/legend` 是结构和可用性增强
* `textarea` 是多行输入
* `output` 可显示计算结果
* `document.getElementById(...).value` 是核心取值方式
* `onsubmit + return false` 是基础验证逻辑
