**第一章主线**

**1. HTML 页面基本结构**

* 一个标准 HTML 页面有固定骨架：`<!DOCTYPE HTML>`、`<HTML>`、`<HEAD>`、`<BODY>`。
* ```<!DOCTYPE HTML>````：声明这是 HTML5 文档，而且必须写在最前面。
* `<HTML>`：根标签，整个网页都包在里面。
* `<HEAD>`：放页面信息，比如标题、编码、样式、脚本。
* `<BODY>`：放用户真正看到的内容，比如文字、图片、链接。

例子：

```
<!DOCTYPE HTML>
<HTML>
  <HEAD>
    <TITLE>Home Page of Book Your Hotel</TITLE>
  </HEAD>
  <BODY>
    Book your favorite hotel.
  </BODY>
</HTML>
```

解释：

* 浏览器先看 `DOCTYPE`，知道按 HTML5 规则解析。
* 再进入 `HTML`。
* `HEAD` 像“说明书”，`BODY` 像“展示区”。

例题：

* 问：网页正文“Book your favorite hotel.” 应该写在哪？
* 答：写在 `<BODY>` 里，因为这是用户可见内容。

**2. 容器标签和空标签**

* 容器标签：成对出现，有开始也有结束，比如 `<HTML>...</HTML>`。
* 空标签：没有内容，不需要配对结束，比如 `<!DOCTYPE HTML>`、`<BR>`。

解释：

* 容器标签像盒子，可以装内容。
* 空标签像一个单独动作，比如“换行”。

**3. `<HEAD>` 里到底放什么**

* `<TITLE>`：浏览器标签页标题。
* `<META>`：元数据，比如描述、关键词、作者、自动刷新。
* `<LINK>`：引入外部资源，最常见是 CSS。
* `<SCRIPT>`：写或引入 JavaScript。
* `<BASE>`：给相对路径设置基准地址。
* `<NOSCRIPT>`：脚本不可用时显示的内容。

例子：

```
<META name="description" content="Best hotel booking in US">
<META name="keywords" content="hotel, online booking, rooms">
<META name="author" content="Harry Anem">
<META http-equiv="refresh" content="30">
```

解释：

* `description` 给搜索引擎一个页面简介。
* `keywords` 提供关键词。
* `author` 说明作者。
* `refresh` 表示每 30 秒自动刷新。

例题：

* 问：`<TITLE>` 和正文标题是一回事吗？
* 答：不是。`<TITLE>` 显示在标签页；正文标题通常写在 `<H1>` 里，显示在页面内部。

**4. `<BODY>` 里的常用内容标签**

* 标题：`<H1>` 到 `<H6>`，从大到小。
* 文本格式：`<P>`、`<B>`、`<I>`、`<U>`、`<BR>`、`<HR>`。
* 列表：`<OL>`、`<UL>`、`<LI>`。
* 解释：
* `OL` 是有序列表，适合步骤、排名。
* `UL` 是无序列表，适合普通项目。

例子：

```
<OL>
  <LI>Ranked 1st in hospitality</LI>
  <LI>Ranked 2nd in infrastructure</LI>
</OL>
```

```
<UL>
  <LI>Deluxe rooms</LI>
  <LI>Free breakfast</LI>
</UL>
```

例题：

* 问：酒店排名应该用 `OL` 还是 `UL`？
* 答：用 `OL`，因为排名有先后顺序。

**5. `DIV` 和 `SPAN` 的区别**

* `<DIV>`：块级元素，会另起一行，通常占一整块区域。
* `<SPAN>`：行内元素，不换行，只包住一小段内容。

解释：

* `DIV` 常用来分大区域、做布局。
* `SPAN` 常用来给一句话里某几个字单独加样式。

例子：

```
<DIV>This is a DIV block.</DIV>
Just before <SPAN>this SPAN</SPAN> stays inline.
```

例题：

* 问：想给一整块内容分区，用哪个？
* 答：`DIV`。
* 问：只想高亮一句话中的一个词，用哪个？
* 答：`SPAN`。

**6. `DETAILS` 和 `SUMMARY`**

* 这是可折叠内容组件。
* `SUMMARY` 是用户看到并点击的标题。
* 点击后，`DETAILS` 里面隐藏的内容展开或收起。

例子：

```
<DETAILS>
  <SUMMARY>Categories of Rooms:</SUMMARY>
  <P>Standard, deluxe, suite ...</P>
</DETAILS>
```

解释：

* 这个组件的重点是： **不用 JavaScript 也能实现展开/收起** 。

**7. 图片、音频、视频**

* 图片：`<IMG>`，常见格式有 `GIF`、`JPEG`、`PNG`。
* 音频：`<AUDIO>`。
* 视频：`<VIDEO>`。
* 常见属性：`autoplay`、`controls`、`loop`、`muted`、`poster`。

例子：

```
<IMG src="Room.jpg" alt="Deluxe Room" width="304" height="228">
<AUDIO controls src="Audio1.mp3"></AUDIO>
<VIDEO width="320" height="240" controls autoplay src="video.mp4"></VIDEO>
```

解释：

* `controls`：显示播放控制条。
* `autoplay`：自动播放。
* `loop`：播完循环。
* `muted`：静音。
* `poster`：视频加载前显示的封面图。

**8. `METER` 和 `PROGRESS` 的区别**

* `<METER>`：表示某个范围内的“测量值”，比如电量、磁盘使用率、评分。
* `<PROGRESS>`：表示任务完成进度，比如下载进度。

例子：

```
<METER value="4" min="0" max="10"></METER>
<PROGRESS value="12" max="100">12%</PROGRESS>
```

解释：

* `METER` 重点是“当前值在区间中的位置”。
* `PROGRESS` 重点是“任务完成了多少”。

例题：

* 问：下载文件到 12% 应该用哪个？
* 答：`PROGRESS`。
* 问：磁盘用了 40% 应该用哪个？
* 答：`METER`。

**9. 语义化标签**

* `<ARTICLE>`：独立内容，比如文章、新闻。
* `<ASIDE>`：补充信息、侧栏、提示。
* `<HEADER>`：开头区域。
* `<FOOTER>`：页脚。
* `<NAV>`：导航链接。
* `<FIGURE>` + `<FIGCAPTION>`：图片和图片说明。

解释：

* 语义化标签的核心不是“能不能显示”，而是“代码本身能不能说明这部分内容的意义”。

例子：

```
<FIGURE>
  <FIGCAPTION>Deluxe Room</FIGCAPTION>
  <IMG src="Room.jpg" alt="deluxe" width="200">
</FIGURE>
```

例题：

* 问：放“网页导航菜单”应该优先用哪个标签？
* 答：`<NAV>`。
* 问：放“文章旁边的促销提示”更像哪个标签？
* 答：`<ASIDE>`。

**10. 链接、网页类型、编辑器**

* `<A href="homepage.html" target="_blank">BookYourHotel</A>`
* `href`：目标地址。
* `target="_blank"`：在新窗口或新标签页打开。

网页类型：

* 静态网页：内容固定。
* 动态网页：内容实时生成，比如新闻站、视频网站。

编辑器：

* 文本编辑器：Notepad、VS Code。
* 图形化编辑器：Dreamweaver。

补充概念：

* `Internet` 是互联网络本身。
* `WWW` 是建立在 Internet 上的一组网页系统。
