## 1. 为什么要用表格 `table`

### 定义 / 原理

表格的作用是： **把复杂数据按“行和列”的方式组织起来** ，让信息更清楚、更容易读。

### 文字化解释

如果一堆数据直接一行行写出来，会很乱。
但如果把它放进表格里，人的眼睛可以很快看到：

* 每一列是什么
* 每一行是什么
* 各个数据之间怎么对应

所以表格最适合做： **结构化数据展示** 。

### 例子

比如课程里举的这类内容：

* `Char(M)` 固定长度 `0-255`
* `Varchar(M)` 可变长度 `0-255`

如果直接写成几行文字，不直观；
如果做成表格，就能一眼看出“名字 - 类型 - 范围”的对应关系。

## 2. 表格的基本结构

### 定义 / 原理

HTML 表格最基本的标签是：

* `<TABLE>`：整个表格
* `<TR>`：一行
* `<TD>`：一个普通单元格
* `<TH>`：表头单元格
* `<CAPTION>`：表格标题
* `<THEAD>`：表头区域
* `<TBODY>`：表格主体
* `<TFOOT>`：表格底部

### 文字化解释

你可以这样理解：

* `TABLE` 是整张表
* `TR` 是横向一整行
* `TD` 是某一行里的一个格子
* `TH` 是标题格子
* `CAPTION` 是表名
* `THEAD/TBODY/TFOOT` 是给表格按功能分区

### 最小例子

```
<TABLE border="1">
  <CAPTION>Student Data</CAPTION>
  <TR>
    <TH>Name</TH>
    <TH>Marks</TH>
  </TR>
  <TR>
    <TD>Joseph</TD>
    <TD>90</TD>
  </TR>
</TABLE>
```

### 解释

这段代码表示：

* 表格标题是 `Student Data`
* 第一行是表头：`Name`、`Marks`
* 第二行是数据：`Joseph`、`90`

### 例题

问：如果想表示一张完整表格，最外层应该用哪个标签？
答：`<TABLE>`

问：如果想写表头“Name”“Marks”，应该用 `TD` 还是 `TH`？
答：`TH`

## 3. `colspan` 和 `rowspan`

这一块是第三章最重要、也最容易考的地方。

### 3.1 `colspan` 的定义

`colspan` 表示： **跨列合并单元格** 。

### 文字化解释

如果一个单元格横向占了多个格子，就用 `colspan`。

### 例子

```
<TR><TD colspan="3">Top Three Performers</TD></TR>
```

### 解释

这个单元格本来只该占一列，
但现在 `colspan="3"`，表示它横向占 3 列。

---

### 3.2 `rowspan` 的定义

`rowspan` 表示： **跨行合并单元格** 。

### 文字化解释

如果一个单元格纵向占了多行，就用 `rowspan`。

### 例子

```
<TR><TD rowspan="3">Top Three</TD><TD>Joseph</TD></TR>
```

### 解释

这里左边那个 `Top Three` 单元格，会竖着占 3 行。

---

### 3.3 最关键的区别

* `colspan`：横着合并，跨列
* `rowspan`：竖着合并，跨行

### 例题

问：如果一个标题要横向覆盖 4 个成绩栏，应该用哪个？
答：`colspan`

问：如果“班级名称”要竖着覆盖下面 3 个学生记录，应该用哪个？
答：`rowspan`

### 记忆方法

* `col` = column = 列
* `row` = 行

所以：

* `colspan` → 跨列
* `rowspan` → 跨行

## 4. 用 CSS 美化表格

这一章也讲了表格样式，也就是“表格不是只要能显示，还要更好看、更清楚”。

### 常见作用

CSS 可以改善表格的：

* 边框
* 对齐
* 间距
* 背景色
* 可读性

### 常见属性

通常会看到这些：

* `border`
* `padding`
* `text-align`
* `background-color`
* `border-collapse`

### 文字化解释

如果不加样式，表格只是“有格子”。
加了 CSS 之后，表格会更像我们平时看到的正式表格。

### 例子

```
table { border-collapse: collapse; }
td, th { border: 1px solid black; padding: 8px; text-align: center; }
```

### 解释

* `border-collapse: collapse`：把相邻边框合并，看起来更整洁
* `padding`：让文字和边框之间有空隙
* `text-align: center`：文字居中

## 5. 什么是 `IFRAME`

### 定义 / 原理

`<IFRAME>` 是  **inline frame，内联框架** 。
它的作用是： **在当前网页里嵌入另一个网页或一段内容** 。

### 文字化解释

你可以把 `iframe` 理解成“网页中的一个小窗口”。
这个窗口里可以显示：

* 另一个 HTML 页面
* 另一个导航页面
* 一段直接写进去的 HTML 内容

---

## 6. `IFRAME` 常见属性

课程里这块很重要，主要认识这些：

* `src`：嵌入的网页地址
* `name`：框架名字
* `width`：宽度
* `height`：高度
* `target`：配合链接使用，决定内容显示到哪个 frame
* `srcdoc`：直接写一段 HTML 作为 frame 内容
* `seamless`：无缝显示相关概念（现在你先认识名字就够）

### 例子

```
<IFRAME name="HeaderFrame" width="91%" height="100" srcdoc="<h1>Learn MySQL</h1>">
</IFRAME>

<IFRAME src="nav.html" name="NavigationFrame" width="25%" height="500"></IFRAME>

<IFRAME name="ContentFrame" width="65%" height="500"></IFRAME>
```

### 解释

这段代码的意思是：

* 上面一个框架直接显示标题内容
* 左边一个框架显示导航页 `nav.html`
* 右边一个框架留作主要内容区

这其实就是“多框架页面布局”的思路。

## 7. `iframe` 和超链接 `target` 的关系

### 原理

如果链接的 `target` 指向某个 `iframe` 的 `name`，
那么点击链接后，内容可以在那个指定的 `iframe` 中打开。

### 文字化解释

这很像：

* 左边点菜单
* 右边内容区更新

这也是早期网页常见的一种结构。

### 例题

问：如果想让某个链接点开后显示在名为 `ContentFrame` 的框架中，应该改哪个属性？
答：改链接的 `target="ContentFrame"`
