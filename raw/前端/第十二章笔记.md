 **`Chapter 12 - Introduction to VueJS`**

这一章本质上是在回答两个问题：

* **Vue 是什么**
* **为什么很多前端项目要用 Vue，而不是只写原生 HTML/CSS/JS**

你可以先把 Vue 理解成一句话：

**Vue 是一个用来开发交互式网页界面的 JavaScript 框架。**

---

## 1. 什么是 VueJS

### 定义 / 原理

VueJS（读作 “view”）是一个  **开源、渐进式 JavaScript 框架** ，主要用于开发交互式网页界面。

### 文字化解释

“渐进式”这个词很重要。

它的意思不是“慢慢学”，而是：

* 你可以只用它的一小部分功能
* 也可以把它扩展成完整的大项目

所以 Vue 不是那种“必须整套全上”的工具。
它可以小用，也可以大用。

### PDF 里给出的几个特点

* `Progressive`：可以从小项目开始，再逐步扩展
* `Approachable`：如果你会 HTML、CSS、JavaScript，就能开始学 Vue
* `Versatile`：能嵌入到已有网页里，也能做完整项目
* `Lightweight`：比较轻量
* `Perfect for SPAs`：适合做单页应用

### 核心点

Vue  **只专注于 view layer（视图层）** 。

### 解释

就是它主要管“页面怎么显示、怎么更新”，
不像某些大而全的方案一下子把所有东西全包了。

---

## 2. 为什么要学 Vue

这一章其实在暗示一个现实问题：

只用原生 JavaScript 写小页面没问题，
但页面一复杂，就会越来越难维护。

Vue 的作用就是：

* 更容易组织页面逻辑
* 更容易更新界面
* 更适合做交互复杂的前端页面

最简单理解：

**原生 JS 能做，但 Vue 能让你做得更清楚、更省力。**

---

## 3. Vue 的核心特性

这一章列了几个 Vue 的核心特性，你不用一下全精通，但要先建立印象。

### 3.1 Virtual DOM

### 定义

Virtual DOM 是真实 DOM 的一个“轻量副本”。

### 解释

Vue 不会每次数据一变就整页重新操作真实 DOM，
它会先在内存里生成一个“虚拟版本”，比较前后变化，再只更新真正变了的那一小部分。

这个过程的关键词你先记住：

* 新旧 Virtual DOM 比较
* `diffing`
* 生成 `patch`
* 更新真实 DOM

### 例子

假设页面原来是：

```
<div id="app">
  <h1>Hello Vue!</h1>
  <p>This is Vue.js</p>
</div>
```

如果你只把 `p` 的内容改成：

```
this.message = 'Virtual DOM is awesome!'
```

Vue 不会把整个页面全部重画一遍，
而是只更新那一段 `p` 的文本。

### 这有什么用

* 性能更好
* DOM 操作更少
* 页面更新更快

### 最简单总结

**Vue 的 Virtual DOM 就像一个“中间草稿层”，先比较，再精确修改。**

---

### 3.2 Data Binding

### 定义

数据绑定就是：**数据变了，页面跟着变；页面输入变了，数据也能更新。**

### 解释

这是 Vue 很核心的思想。
你不需要每次都手动去找 DOM 改文字，很多时候 Vue 会帮你同步。

### 例子

后面你会经常看到：

* `v-bind`
* `v-model`

你现在先知道：

* `v-bind` 常用来绑定属性
* `v-model` 常用来做表单双向绑定

---

### 3.3 Components 组件

### 定义

组件就是  **可复用的页面小模块** 。

### 解释

比如一个按钮块、一个卡片、一个导航栏，如果你会重复用它，就可以写成组件。

### 最简单理解

组件 = 把一块界面打包起来，重复使用。

---

### 3.4 Event Handling

### 定义

事件处理就是：用户点击、输入、悬停时，Vue 能响应这些动作。

### 解释

Vue 里常见写法会用：

* `v-on`
* 简写 `@`

比如：

```
<button @click="count++">Click</button>
```

意思是：点击按钮时，执行对应逻辑。

---

### 3.5 Animation / Transition

Vue 支持过渡和动画。

### 解释

比如：

* 元素出现时淡入
* 消失时滑出
* 切换时做动画

这一部分你后面章节会真正展开学，这里先知道 Vue 支持它。

---

### 3.6 Computed Properties

### 定义

计算属性是根据已有数据自动计算出来的结果。

### 解释

比如：

* 姓 + 名 = 全名
* 商品数量 × 单价 = 总价

你不用每次手动重新算，Vue 可以帮你维护。

---

### 3.7 Templates

Vue 用 HTML 风格的模板来描述界面。

### 解释

所以它看起来对前端初学者比较友好，因为不是纯 JavaScript 在硬拼 DOM，而是更接近“写页面”的方式。

---

### 3.8 Directives 指令

### 定义

指令是 Vue 提供的特殊属性，用来直接控制页面行为。

### 这一章提到的典型例子

* `v-if`
* `v-for`
* `v-model`

### 解释

你可以把它们理解成：

* `v-if`：要不要显示
* `v-for`：循环渲染
* `v-model`：输入值和数据绑定

---

### 3.9 Vue CLI

CLI 是命令行工具，用来创建和管理 Vue 项目。

### 解释

就是不用你手搓整个项目结构，Vue 帮你快速生成一个标准项目。

---

## 4. DOM 和 Virtual DOM

这一章专门讲了这块，所以你一定要理解个大概。

### 4.1 什么是 DOM

DOM 是 Document Object Model，也就是文档对象模型。

### 解释

浏览器会把 HTML 页面看成一棵树，
每个标签、每段文字、每个结构都像树上的节点。

所以 JavaScript 才能去：

* 改文字
* 改样式
* 增删元素

---

### 4.2 传统 DOM 的问题

当页面越来越大、越来越复杂时：

* 节点越来越多
* 脚本越来越多
* 查找和更新 DOM 会越来越慢

### 解释

也就是说，直接频繁操作真实 DOM，性能成本会比较高。

---

### 4.3 Virtual DOM 的工作流程

这一章给了一个比较完整的流程，你掌握思想就行：

1. Vue 根据模板先生成 Virtual DOM
2. 页面显示到真实 DOM
3. 数据变化后，Vue 生成新的 Virtual DOM
4. 新旧 Virtual DOM 做比较（diff）
5. 找出真正变化的地方
6. 只把必要修改打到真实 DOM 上

### 例子

原来：

```
<p>This is Vue.js</p>
```

后来变成：

```
<p>Virtual DOM is awesome!</p>
```

Vue 只更新这一个 `p`，而不是整块都重来。

### 这章的核心结论

**Vue 通过 Virtual DOM 减少了不必要的真实 DOM 操作。**

## 5. Vue 的安装与环境准备

这一章后半段开始讲安装和项目搭建。

### 前提

先装：

* Node.js
* npm

### 验证命令

```
node -v
npm -v
```

### 安装 Vue CLI

```
npm install -g @vue/cli
```

### 验证 Vue CLI

```
vue --version
```

### 创建项目

```
vue create my-vue-project
```

### 启动项目

```
cd my-vue-project
npm run serve
```

### 另一种更快方式

这一章也提到：

```
npm create vue@latest my-project
cd my-project
npm install
npm run dev
```

### 解释

你现在不用死记所有命令细节，但要知道这一套逻辑：

1. 先装 Node / npm
2. 再装 Vue CLI
3. 再创建项目
4. 再启动开发服务器

## 6. Vue 项目结构

这一章还讲了 Vue CLI 创建出来的项目目录。

### 典型结构

* `node_modules/`：依赖包
* `public/`：静态资源
* `src/`：主要源码
* `src/assets/`：图片、CSS
* `src/components/`：组件
* `src/router/`：路由
* `src/store/`：状态管理
* `src/views/`：页面级组件
* `App.vue`：根组件
* `main.js`：入口文件
* `package.json`：依赖和脚本

### 最重要的理解

你现在先记这几个最关键的：

* `src/`：主要写代码的地方
* `components/`：可复用组件
* `App.vue`：根组件
* `main.js`：入口

## 7. `.vue` 文件结构

Vue 单文件组件通常长这样：

```
<template>
  <div>HTML / UI part</div>
</template>

<script>
export default {
  name: 'ComponentName',
  data() { return { ... } },
  methods: { ... }
}
</script>

<style scoped>
/* CSS styles */
</style>
```

### 解释

* `<template>`：界面结构
* `<script>`：逻辑
* `<style>`：样式

### 这很重要

因为 Vue 很多代码都围绕这个结构展开。

你可以把它理解成：

**一个 `.vue` 文件 = HTML + JS + CSS 打包在一起。**

## 9. 本章最小例子

这一章偏“入门和概念”，所以最小例子主要是看结构：

```
<template>
  <div>
    <h1>{{ title }}</h1>
    <p>{{ message }}</p>
  </div>
</template>

<script>
export default {
  name: "MyComponent",
  data() {
    return {
      title: "Hello Vue!",
      message: "This is Vue.js"
    };
  }
};
</script>

<style scoped>
h1 {
  color: blue;
}
</style>
```

### 解释

* 页面显示由 `template` 决定
* 数据写在 `data()` 里
* 样式写在 `style` 里
* 这就是 Vue 单文件组件的基本感觉

这一章最核心的一句话是：

**Vue 是一个帮助我们更高效开发交互式界面的前端框架。**

你现在最该记住的点：

* Vue 是渐进式 JavaScript 框架
* 它主要关注视图层
* 它支持：
  * Virtual DOM
  * 数据绑定
  * 组件
  * 事件处理
  * 指令
  * 过渡动画
* Virtual DOM 的核心思想是：
  * 先比较
  * 再只更新变化部分

  * `template`
  * `script`
  * `style`

最简单总结一句：
