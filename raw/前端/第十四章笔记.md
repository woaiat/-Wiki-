 **第 14 章：VueJS Events** 。
这一章是一个非常标准的“事件专题”，核心就是一句话：

**Vue 怎么响应用户操作。**

这一章的 6 个重点例子分别是：

1. 基础点击事件
2. `.once` 修饰符
3. `.prevent` 修饰符
4. 键盘修饰符
5. 自定义事件 $emit
6. 鼠标事件 `@mouseover / @mouseout`

我这章也继续按同样标准来：
**每个例子都讲它想证明什么、代码怎么工作、你该记什么。**

---

# 第 14 章总主线

先记住这章最核心的一条：

在 Vue 里，事件通常通过：

* `v-on:事件名="方法名"`
* 简写 `@事件名="方法名"`

来监听用户行为。

例如：

```
<button v-on:click="methodName">Click Me</button>
<button @click="methodName">Click Me</button>
```

这两句是等价的。

---

## 1. 例子一：Basic Click Event

### 这个例子想证明什么

它想证明：

**Vue 最基本的事件写法，就是点击后调用方法。**

### 核心代码

模板里：

```
<button @click="displayNumbers" class="btn-primary">
    Click Me to Add No.
</button>
<h2>Add Number 100 + 200 = {{ total }}</h2>
```

脚本里：

```
data() {
    return {
        num1: 50,
        num2: 100,
        total: ""
    };
},
methods: {
    displayNumbers(event) {
        console.log(event);
        this.total = this.num1 + this.num2;
    }
}
```

---

### 这段代码怎么理解

#### 模板部分

* `@click="displayNumbers"`：点按钮时调用 `displayNumbers`
* `{{ total }}`：把 `total` 的值显示到页面上

#### 数据部分

* `num1 = 50`
* `num2 = 100`
* `total = ""`

也就是说，一开始结果为空。

#### 方法部分

```
displayNumbers(event) {
    console.log(event);
    this.total = this.num1 + this.num2;
}
```

这段意思是：

1. 点击按钮
2. 得到原生 DOM 事件对象 `event`
3. 把 `num1 + num2` 的结果放进 `total`

所以点击后页面就会显示：
`150`

---

### 这里有个小细节

PDF 里的文字写的是：
`Add Number 100 + 200 = ...`
但代码里实际上是：

* `50`
* `100`

所以真实运行结果应该是 `150`。

这就是一个你要注意的地方：
**考试以代码本身为准，不要被说明文字带偏。**

---

### 这个例子你该记什么

* 基本点击事件写法：`@click="方法名"`
* 事件触发后，方法可以改 `data` 中的数据
* 改完数据，页面会自动更新
* 方法还可以接收 `event` 参数

---

## 2. 例子二：`.once` Event Modifier

### 这个例子想证明什么

它想证明：

**有些事件你希望它只执行一次，就可以加 `.once`。**

### 核心代码

```
<button @click.once="buttonClickedOnce" :style="styleobj">
    Just once clickable
</button>
<p>Output: {{ clickNum }}</p>

<button @click="buttonClicked" :style="styleobj">
    Click Me anytime
</button>
<p>Output: {{ clickNum1 }}</p>
```

脚本中：

```
data() {
    return {
        clickNum: 0,
        clickNum1: 0,
        styleobj: { ... }
    };
},
methods: {
    buttonClickedOnce() {
        this.clickNum++;
    },
    buttonClicked() {
        this.clickNum1++;
    }
}
```

---

### 这段代码怎么理解

#### 第一个按钮

```
@click.once="buttonClickedOnce"
```

表示：

* 只能触发一次
* 第一次点，`clickNum` 加 1
* 后面再点，不会再加

#### 第二个按钮

```
@click="buttonClicked"
```

表示：

* 普通点击事件
* 每点一次都加 1

---

### 这个例子的对比意义

它不是只教你 `.once`，
而是通过两个按钮对比，让你明确看出：

* `.once`：一次后失效
* 普通 `@click`：每次都执行

---

### 你该记什么

* `.once` 是事件修饰符
* 写法：`@click.once="方法名"`
* 作用：事件只触发一次

---

## 3. 例子三：`.prevent` Event Modifier

### 这个例子想证明什么

它想证明：

**有时你想响应点击，但不想让浏览器执行默认行为。**

### 核心代码

```
<a href="http://www.google.com" @click.prevent="clickMe" target="_blank" :style="styleobj">
    Click Me (With .prevent)
</a>

<a href="http://www.google.com" @click="clickMeWithoutPrevent" target="_blank" :style="styleobj">
    Click Me (Without .prevent)
</a>
```

方法：

```
methods: {
    clickMe() {
        alert("Anchor tag is clicked! Navigation PREVENTED!");
    },
    clickMeWithoutPrevent() {
        alert("This will navigate to Google after this alert");
    }
}
```

---

### 这段代码怎么理解

#### 第一个链接

```
@click.prevent="clickMe"
```

含义：

* 点击后执行 `clickMe`
* 但是阻止链接默认跳转行为

所以结果是：

* 只弹框
* 不会真的去 Google

#### 第二个链接

```
@click="clickMeWithoutPrevent"
```

含义：

* 点击后执行方法
* 但不阻止默认行为

所以结果是：

* 先弹框
* 再跳到 Google

---

### `.prevent` 本质是什么

它相当于 Vue 帮你自动做了：

```
event.preventDefault()
```

---

### 你该记什么

* `.prevent` 用来阻止默认行为
* 常见场景：
  * 阻止链接跳转
  * 阻止表单默认提交
* 写法：`@click.prevent="方法名"`

---

## 4. 例子四：Key Modifiers

### 这个例子想证明什么

它想证明：

**Vue 可以只在按下某个特定键时才触发事件。**

### 核心代码

第一个输入框：

```
<input
  type="text"
  @keyup.enter="showInputValue"
  :style="styleobj"
  placeholder="Type your name here and press Enter"
  v-model="tempName"
/>
<h3>Your name: {{ name }}</h3>
```

第二个输入框：

```
<input
  type="text"
  @keyup.ctrl.enter="showInputValueCtrl"
  :style="styleobj"
  placeholder="Type something and press Ctrl+Enter"
  v-model="tempMessage"
/>
<h3>Message: {{ message }}</h3>
```

方法：

```
methods: {
    showInputValue(event) {
        this.name = event.target.value;
    },
    showInputValueCtrl(event) {
        this.message = event.target.value;
    }
}
```

---

### 这段代码怎么理解

#### 第一个输入框

```
@keyup.enter="showInputValue"
```

意思是：

* 你正常打字不会立即生效
* 只有按下 Enter 键，才执行方法

#### 第二个输入框

```
@keyup.ctrl.enter="showInputValueCtrl"
```

意思是：

* 要按 `Ctrl + Enter`
* 才执行方法

---

### 这个例子的意义

它想告诉你：

Vue 事件不只是“有没有触发”，
还可以精确到“按了哪个键才触发”。

---

### 这一节提到的常见键修饰符

* `.enter`
* `.tab`
* `.delete`
* `.esc`
* `.space`
* `.up`
* `.down`
* `.left`
* `.right`

---

### 你该记什么

* `@keyup.enter`：按 Enter 才触发
* `@keyup.ctrl.enter`：按 Ctrl + Enter 才触发
* 键盘修饰符能精准控制输入行为

---

## 5. 例子五：Custom Events

### 这个例子想证明什么

它想证明：

**子组件如何把信息传给父组件。**

这也是 Vue 里非常重要的思想。

---

### 核心理论

子组件通过：

```
this.$emit('event-name', data)
```

把事件和数据发出去。

父组件通过：

```
@event-name="handlerMethod"
```

接住它。

---

### 子组件代码：`LanguageButton.vue`

```
<button @click="displayLanguage" class="language-btn">
    <span style="font-size:25px;">{{ item }}</span>
</button>
```

脚本里：

```
props: ["item"],
methods: {
    displayLanguage() {
        this.$emit('showLanguage', this.item);
    }
}
```

---

### 这段代码什么意思

* 子组件收到一个 `item`
* 点击按钮时
* 把 `showLanguage` 这个自定义事件发给父组件
* 同时把 `item` 作为数据一起传出去

---

### 父组件代码：`CustomEventsDemo.vue`

```
<LanguageButton
  v-for="(item, index) in languages"
  :key="index"
  :item="item"
  @showLanguage="languageDisp"
/>
```

方法：

```
methods: {
    languageDisp(language) {
        this.languageClicked = language;
    }
}
```

---

### 这段代码怎么理解

* 父组件循环生成很多语言按钮
* 每个按钮都收到不同的 `item`
* 子组件点击时，触发 `showLanguage`
* 父组件监听到这个事件后，调用 `languageDisp`
* 然后把点击的语言显示出来

---

### 这个例子的核心意义

这就是 Vue 中经典的：

**子传父：$emit**

---

### 你该记什么

* 子组件向父组件传数据，用 $emit
* 父组件用 `@事件名="方法"` 接收
* 这是标准的 child → parent 通信方式

---

## 6. 例子六：Mouse Events

这一例子和第 13 章最后那个鼠标组件有点像，但现在它被放在“事件专题”里重新强调。

### 这个例子想证明什么

它想证明：

**Vue 可以很自然地处理鼠标进入、移出等事件。**

### 核心模板

```
<div class="interactive-card" @mouseover="handleMouseOver" @mouseout="handleMouseOut">
```

### 这句的意思

* 鼠标移入：执行 `handleMouseOver`
* 鼠标移出：执行 `handleMouseOut`

---

### 数据部分

```
return {
    cityName: "Shanghai",
    isHovered: false,
    textColor: "blue"
};
```

### 事件方法

```
handleMouseOver() {
    this.cityName = "Guizhou";
    this.isHovered = true;
    this.textColor = "red";
},
handleMouseOut() {
    this.cityName = "Shanghai";
    this.isHovered = false;
    this.textColor = "blue";
}
```

---

### 页面怎么跟着变

模板里有两处关键绑定：

#### 第一处

```
<span :style="{ color: textColor }">{{ cityName }}</span>
```

表示：

* 文字颜色跟着 `textColor` 变
* 文字内容跟着 `cityName` 变

#### 第二处

```
<p v-if="isHovered" class="message">
    Mouse is over me! City changed to {{ cityName }}
</p>
```

表示：

* 只有 `isHovered = true` 时，提示才显示

---

### 这个例子的最终效果

* 鼠标移入卡片
  * 城市名从 `Shanghai` 变成 `Guizhou`
  * 颜色从蓝变红
  * 提示出现
* 鼠标移出卡片
  * 城市名变回 `Shanghai`
  * 颜色变回蓝
  * 提示消失

---

### 这个例子为什么重要

因为它把事件、条件渲染、样式绑定、组件独立性全串起来了。
