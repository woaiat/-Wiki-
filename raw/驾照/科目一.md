# 科目一

## 科目一精华知识点系统整理

> 这部分按主题集中整理，口诀只用于快速回忆，遇到超员、超速题仍要同时核对车型、道路和比例。

### 记分速查口诀

#### 扣1分：禁、灯、掉、会、安、检、改

1. 禁：违反禁令标志、禁止标线指示。
2. 灯：普通行驶过程中不按规定使用灯光；注意发生故障或者事故停车后不按规定用灯或设置警告标志，记3分。
3. 掉：在高速公路、城市快速路以外的道路上不按规定倒车、掉头。
4. 会：不按规定会车。
5. 安：未按规定系安全带。
6. 检：驾驶公路客运汽车、旅游客运汽车、危险物品运输车辆以外的机动车，未按规定进行安全技术检验。
7. 改：驾驶擅自改变已登记结构、构造或者特征的载货汽车上道路行驶。

#### 扣3分：让、道、超、装、电、警、低

1. 让：不按规定避让校车、行人或者应当让行的车辆。
2. 道：穿插变道、占用对向车道，或者在高速公路、城市快速路上不按规定车道行驶；普通道路逆行记3分，高速公路、城市快速路逆行记12分。
3. 超：不按规定借道超车，或者穿插等候车辆。
4. 装：不按规定安装机动车号牌，例如少装号牌螺丝。
5. 电：拨打、接听手持电话妨碍安全驾驶。
6. 警：车辆发生故障或者事故停车后，不按规定使用灯光或者设置警告标志。
7. 低：驾驶机动车在高速公路上低于规定最低时速行驶。

#### 扣6分：占、扣、轻、信、危

1. 占：违法占用应急车道。
2. 扣：机动车驾驶证被暂扣期间驾驶机动车。
3. 轻：造成致人轻微伤或者财产损失的交通事故后逃逸，尚不构成犯罪。
4. 信：驾驶机动车不按交通信号灯指示通行。
5. 危：载运爆炸物品等危险物品时，未按规定悬挂警示标志并采取必要安全措施。

#### 扣9分：停车、不符、没号牌、无校资

1. 停车：在高速公路、城市快速路违法停车，或者连续驾驶中型以上载客汽车、危险物品运输车辆超过4小时未停车休息或停车休息少于20分钟。
2. 不符：驾驶与准驾车型不符的机动车。
3. 没号牌：未悬挂机动车号牌，或者故意遮挡、污损机动车号牌。
4. 无校资：未取得校车驾驶资格驾驶校车。

#### 扣12分：酒、伪、亡、重、反

1. 酒：饮酒后或者醉酒驾驶机动车。
2. 伪：使用伪造、变造的机动车号牌、行驶证、驾驶证，或者使用其他机动车号牌、行驶证。
3. 亡：造成致人轻伤以上或者死亡的交通事故后逃逸，尚不构成犯罪。
4. 重：校车、公路客运汽车、旅游客运汽车严重超员，或者普通机动车在高速公路、城市快速路严重超速等行为；具体比例见下方对照。
5. 反：在高速公路、城市快速路上倒车、逆行、穿越中央分隔带掉头，或者反方向行驶。

### 超载、超员、超速

#### 货车超载：1、3、6

1. 载货汽车载物超过最大允许总质量未达到30%的，记1分。
2. 载货汽车载物超过最大允许总质量30%以上、未达到50%的，记3分。
3. 载货汽车载物超过最大允许总质量50%以上的，记6分。

#### 载客汽车超员：7座以上以外3/6，7座以上6/9

1. 7座以上载客汽车以外的其他载客汽车（通常为6座及以下）超员20%以上、未达到50%的，记3分。
2. 7座以上载客汽车以外的其他载客汽车（通常为6座及以下）超员50%以上、未达到100%的，记6分。
3. 7座以上载客汽车超员20%以上、未达到50%的，记6分。
4. 7座以上载客汽车超员50%以上、未达到100%的，记9分。
5. 校车、公路客运汽车、旅游客运汽车超员未达到20%的，记6分；超员20%以上的，记12分。

#### 普通机动车超速：普通路3/6，高快速6/12

1. 普通机动车在普通公路上超速20%以上、未达到50%的，记3分。
2. 普通机动车在普通公路上超速50%以上的，记6分。
3. 普通机动车在高速公路、城市快速路上超速20%以上、未达到50%的，记6分。
4. 普通机动车在高速公路、城市快速路上超速50%以上的，记12分。

#### 特殊车辆超速：普通路1/6/9，高快速6/12

这里的“特殊车辆”是为了方便记忆使用的简称，具体包括：

1. 校车。
2. 中型以上载客汽车，即中型、大型载客汽车。
3. 中型以上载货汽车，即中型、重型载货汽车。
4. 危险物品运输车辆。

在高速公路、城市快速路以外的普通道路上：

1. 超速10%以上、未达到20%的，记1分。
2. 超速20%以上、未达到50%的，记6分。
3. 超速50%以上的，记9分。
4. 超速未达到10%的，不在本组记分条款规定的范围内；仍属于超速行为，是否处罚另按有关规定判断。

在高速公路、城市快速路上：

1. 只要超速但未达到20%，记6分。
2. 超速20%以上，记12分。

比例边界：正好达到20%时进入“20%以上”一档；正好达到50%时进入“50%以上”一档。

### 号牌记分

1. 不按规定安装号牌，例如没挂好、少装螺丝，记3分。
2. 未悬挂号牌，或者故意遮挡、污损号牌，记9分。
3. 使用伪造、变造号牌，或者使用其他机动车号牌，记12分。

### 申领、吊销、撤销限制

1. 假一：提供虚假材料申领驾驶证的，1年内不得申领，并处500元以下罚款。
2. 吊二：驾驶证被吊销的，通常2年内不得报考。
3. 撤三：驾驶证被撤销的，3年内不得报考。
4. 骗三：以欺骗、贿赂等不正当手段取得驾驶证，被撤销驾驶许可的，处2000元以下罚款，3年内不得重新申请。
5. 毒三：3年内有吸食、注射毒品行为的，不得申请机动车驾驶证。
6. 醉五：醉酒驾驶被吊销驾驶证的，5年内不得报考。
7. 竞五：驾车追逐竞驶构成犯罪，被依法吊销驾驶证未满5年的，不得申请机动车驾驶证。
8. 逃终生：造成交通事故后逃逸构成犯罪的，终生不得重新取得驾驶证。

### 罚款速查

#### 200元以下罚款

1. 机动车所有权转让后，现机动车所有人30日内未办理转让登记。
2. 改变车身颜色、设置车身广告后未按规定办理相关手续。
3. 未按规定进行安全技术检验。
4. 重型、中型载货汽车及其挂车车身后部未按规定喷涂放大的号牌号码，或者放大的号牌号码不清晰，处警告或者200元以下罚款。

#### 20元以上、200元以下罚款

1. 补领新驾驶证后继续使用原驾驶证。
2. 实习期内单独驾驶机动车上高速公路。
3. 实习期内驾驶机动车牵引挂车。
4. 驾驶人信息变化后30日内未备案。

#### 200元以上、500元以下罚款

1. 驾驶证逾期仍驾驶、隐瞒有关情况、补领后继续使用旧证。
2. 身体条件不适合驾驶机动车仍驾驶。
3. 公路客运汽车载客超过额定乘员但未达到20%；超过20%的一般罚500元以上、2000元以下。

#### 200元以上、2000元以下罚款

1. 驾驶拼装机动车、报废机动车，或者超速50%以上。
2. 将机动车交给未取得驾驶证或者驾驶证被吊销、暂扣的人驾驶。
3. 非法安装警报器、标志灯具。
4. 驾驶拼装车、报废车上道路行驶的，可以并处吊销驾驶证。
5. 故意损毁、移动、涂改交通设施，造成危害后果但尚不构成犯罪。

#### 500元、2000元以下罚款

1. 提供虚假材料申领驾驶证的，1年内不得申领，并处500元以下罚款。
2. 驾驶证考试中有贿赂、舞弊行为的，处2000元以下罚款，1年内不得再次申领。

#### 代替记分罚款

1. 驾驶人请他人代为接受交通违法行为处罚和记分，并支付经济利益的，处所支付经济利益3倍以下罚款，但最高不超过5万元；原交通违法行为仍依法处罚。

### 酒驾、醉驾处罚

1. 饮酒后驾驶机动车：暂扣驾驶证6个月，记12分，罚1000元以上、2000元以下。
2. 再次饮酒后驾驶机动车：吊销驾驶证，处10日以下拘留，罚1000元以上、2000元以下。
3. 醉酒驾驶机动车：约束至酒醒，吊销驾驶证，5年内不得重新取得驾驶证。
4. 饮酒驾驶的酒精含量标准：20mg/100mL至80mg/100mL。
5. 醉酒驾驶的酒精含量标准：大于等于80mg/100mL。
6. 饮酒后驾驶营运机动车：罚5000元，吊销驾驶证，处15日以下拘留，5年内不得重新取得驾驶证。
7. 醉酒驾驶营运机动车：约束至酒醒，吊销驾驶证，10年内不得重新取得驾驶证，依法追究刑事责任；重新取得驾驶证后，终生不得驾驶营运机动车。

### 交通肇事罪与危险驾驶罪

1. 交通肇事罪刑期对照：发生重大事故并构成交通肇事罪，未逃逸的，处3年以下有期徒刑或者拘役；肇事后逃逸或者有其他特别恶劣情节的，包括致人死亡后逃逸，即“先死后逃”，处3年以上、7年以下有期徒刑；因逃逸致人死亡，即“先逃后死”，处7年以上有期徒刑。
2. 危险驾驶罪处罚：醉酒驾驶机动车，或者在道路上追逐竞驶且情节恶劣的，处拘役，并处罚金。
3. 交通肇事罪认定：交通肇事致一人以上重伤，负事故全部或者主要责任，并具有下列情形之一的，以交通肇事罪定罪处罚：酒后、吸食毒品后驾驶；无驾驶资格驾驶；明知车辆安全装置不全或者安全机件失灵仍驾驶；明知是无牌证或者已报废车辆仍驾驶；严重超载驾驶；为逃避法律追究逃离事故现场。

### 距离、能见度、标线、限速

1. 口五站三：题目中有“口”的选50米，有“站”的选30米，其他一般选150米；没有150米时选最大。
2. 高速能见度口诀261、145、520：能见度200米，车速不超过60km/h，车距不少于100米。
3. 高速能见度100米：车速不超过40km/h，车距不少于50米。
4. 高速能见度50米：车速不超过20km/h，并尽快驶离高速公路。
5. 没有道路中心线：城市道路最高30km/h，公路最高40km/h。
6. 同方向只有一条机动车道：城市道路最高50km/h，公路最高70km/h。
7. 特殊情形限速30km/h：进出非机动车道，通过铁路道口、急弯路、窄路、窄桥，掉头、转弯、下陡坡；遇雾、雨、雪、沙尘、冰雹且能见度在50米以内；在冰雪、泥泞道路上行驶；牵引发生故障的机动车。
8. 50米内不得停车：交叉路口、铁路道口、急弯路、宽度不足4米的窄路、桥梁、陡坡、隧道，以及距离上述地点50米以内的路段。
9. 第7点与第8点并不完全相同：铁路道口、急弯路、符合条件的窄路和桥梁、陡坡存在重合；进出非机动车道、掉头、转弯、冰雪和泥泞道路等不属于50米禁停清单，而交叉路口、隧道属于50米禁停清单。
10. 高速公路车道最低时速：高速公路整体最低车速为60km/h；同方向有2条车道时，左侧车道最低100km/h；同方向有3条以上车道时，最左侧车道最低110km/h，中间车道最低90km/h。
11. 高速公路最高时速不得超过120km/h；道路限速标志与一般规定不一致时，按照限速标志行驶。红圈白底数字通常表示最高速度，蓝底数字通常表示最低速度。
12. 标线口诀：虚线可以跨越，实线不可以跨越。

### 扣车相关

1. 未带“两证两标一号牌”可以扣车：驾驶证、行驶证、保险标志、检验合格标志、机动车号牌。
2. 驾驶拼装车、报废车，或者车辆超载，可以依法扣车。
3. 未投保交强险，或者需要调查取证时，可以依法扣车。
4. 题目说“扣驾驶证”或者“扣身份证”的，一般是错的；常见正确说法是依法扣留机动车。

### 驾驶证申请、考试与管理

#### 考试与学习驾驶证明

1. 学习驾驶证明的有效期为3年。
2. 在学习驾驶证明有效期内，科目二和科目三道路驾驶技能考试的预约次数分别最多5次，不能预约第6次；第五次仍不合格，已经合格的其他科目成绩作废。

#### 申请年龄

1. 申请小型汽车准驾车型驾驶证，年龄为18周岁以上，无年龄上限。
2. 自2025年1月1日起，申请大型货车、中型客车驾驶证，年龄为20周岁以上、63周岁以下。
3. 准驾年龄常见起点分为18周岁、20周岁、22周岁，具体仍要结合准驾车型判断。

#### 实习期

1. 初次取得汽车类准驾车型驾驶证，实习期为12个月。
2. 由摩托车类准驾车型增加汽车类准驾车型，实习期为12个月。
3. 实习期驾驶人不能单独驾驶机动车上高速公路；上高速时，应当由持有相应或者包含其准驾车型驾驶证3年以上的驾驶人陪同。
4. 增驾后的实习期内驾驶原准驾车型，不受上述高速公路陪同限制。

#### 审验与体检

1. 持有C1驾驶证的驾驶人，在有效期满换证时接受审验，不实行每个记分周期审验。
2. 因服兵役、出国（境）等原因无法审验，可以申请延期，最长不超过3年。
3. 70周岁以上的驾驶人，每年进行一次身体检查并提交身体条件证明。

#### 驾驶证有效期与办理地点

1. 驾驶证有效期为6年、10年、长期。
2. 驾驶证记载信息发生变化，30日内申请换证；有效期满前90日内申请换证。
3. 车辆相关业务找登记地：机动车号牌灭失、丢失或者损毁，向登记地车辆管理所申请补领、换领。
4. 驾驶人相关业务找驾驶证核发地或者核发地以外车辆管理所；户籍迁出原管辖区，向迁入地车辆管理所申请换证。

#### 常见准驾车型

1. C1可以驾驶C2、C3、C4准驾车型。
2. C2为小型自动挡汽车，只能驾驶自动挡汽车。
3. C6为轻型牵引挂车，申请年龄不得超过70周岁。
4. A2为重型牵引挂车。
5. B1为中型客车，可以驾驶C1、C2、C3、C4准驾车型。
6. 客车、牵引车类的部分准驾车型不得初次申领，需要通过增驾取得。

### 记分处理、满分教育与学法减分

1. 同一辆机动车存在多起交通违法行为时，可以一次性处理，记分分值累积计算。
2. 驾驶人在一个记分周期内累积记满12分，只需参加道路交通安全法律、法规和相关知识考试，即科目一；不需要参加科目二、科目三考试。
3. 满分教育是累积记满12分后必须接受的强制纠正措施；学法减分是给予符合条件驾驶人的优惠，一个记分周期内累计最高扣减6分。
4. 驾驶证处于实习期内，不能申请学法减分。
5. 本记分周期或者上一个记分周期内有两次以上满分教育记录，或者最近3个记分周期内因饮酒后驾驶机动车受到处罚的，不予受理学法减分申请。
