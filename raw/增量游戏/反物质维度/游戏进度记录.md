可以。你现在这个阶段，Glyph 我建议按“**词条优先，不是稀有度优先**”来配。  
前中期一个**白/绿但词条对路**的 Glyph，往往比一个**蓝/紫但词条跑偏**的更有用。社区前期攻略和源码两边都很一致：**真正决定价值的是效果类型，其次才是等级和稀有度。**

**先记结论**

- 日常推进最有帮助的类型，通常是：`Time`、`Dilation`、`Replication`
- `Power` 是很稳的通用补强
- `Infinity` 多数时候是工具人，不是主力

**每种 Glyph 最值得留的词条**

- `Time`
    - `EP gain`：前中期最关键的词条之一，拿到基本都值得留
    - `TD power`：后面越来越强，通用性很好
    - `Game speed`：也很实用
    - `Eternity gain`：有用，但优先级通常低于 `EP gain`
- `Dilation`
    - `DT gain`：非常强，能直接推 Dilation、Glyph level、RM
    - `TG threshold`：也很强，能更容易多拿 Tachyon Galaxies
    - `TT generation`：偏功能/QoL，能用但不是最强推进词条
    - `AD power while Dilated`：前中期基本算最弱词条之一
- `Replication`
    - `Glyph level factor`：长期最值钱的词条之一，专门让你以后掉更好的 Glyph
    - `Replication speed`：很实用，很多构筑都爱要
    - `DT per Replicanti`：Dilation 后不错
    - `Replicanti mult power`：前期一般，后面才越来越强
- `Power`
    - `AD power`：很稳，几乎全程都能吃到
    - `Dimboost mult`：很好用，泛用性高
    - `Buy 10 bonus`：不错
    - `AD multipliers ×X`：特别早期很好，后面会慢慢掉队
- `Infinity`
    - `Infinity gain`：做 `EC4`、刷 banked infinities、做特定升级时很好
    - `IP gain`：前半段 Reality 很顺手
    - `ID power`：能用，但通常不如 Power/Time 主力
    - `Infinity power conversion rate`：前中期偏弱

**按用途怎么配**

- 通用日常推进：
    - `Time(EP gain)` + `Dilation(DT gain)` + `Power(AD power)` + `Replication(rep speed 或 glyph level)`
- 想更快提高以后 Glyph 质量：
    - `Replication(glyph level)` + `Replication speed` + `Dilation(DT gain)` + `Time(EP gain)`
- 想推长跑 / 推 RM：
    - `Dilation(DT gain)` + `Dilation(TG threshold)` + `Time(TD power 或 EP gain)` + `Replication(rep speed / glyph level)`
- 需要做工具型目标时再临时换：
    - `Infinity(Infinity gain / IP gain)`

**最值得你优先追的组合**

- `Time`：`EP gain + TD power`
- `Dilation`：`DT gain + TG threshold`
- `Replication`：`glyph level + replication speed`
- `Power`：`AD power + dimboost`
- `Infinity`：`Infinity gain + IP gain`

**你这个阶段最实用的优先级**

- `Time 的 EP gain`
- `Dilation 的 DT gain / TG threshold`
- `Replication 的 glyph level / rep speed`
- `Power 的 AD power / dimboost`
- `Infinity` 只在有明确用途时上

一句话版就是：  
**你现在别太执着“哪种颜色高级”，先找 `Time 的 EP`、`Dilation 的 DT/TG`、`Replication 的 glyph level` 这几类真核心词条。**
