1. Forms – accepting user input

  <FORM>       Forms are interactive elements that collect data from users. Example: OrderFoodOnline form.




    Scenario: FoodExpress.com / BookYourHotel – customers fill details like name, contact, preferences.




    Basic form structure


   <FORM name="OrderFoodOnline" method="post" action="process.html">
       ... form elements ...
   </FORM>




       Important form attributes


       ATTRIBUTE                                              DESCRIPTION


  name                    unique name for the form (used in scripts)


  id                      unique identifier for CSS/JavaScript


  action                  URL where form data is sent


  method                  "get" (appends data to URL, visible, limited) or "post" (secure, no size limit)


  autocomplete            "on" / "off" – browser autofill


  novalidate              disable browser validation


  target                  where to show response (_blank, _self, _parent, _top, frame_name)

        Text / Password / Email / Tel / URL / Number

  tel               <INPUT type="tel" name="phone">


  url               <INPUT type="url" name="website">


  number            <INPUT type="number" min="0" max="50">

        <INPUT type="checkbox" name="cuisine1" value="Continental"> Continental




        Date / Time / Range


        <INPUT type="date" name="bday">
        <INPUT type="time" name="usr_time">
        <INPUT type="range" min="10" max="50" step="5" value="10">




         Image as submit button


        <INPUT type="image" src="submit.gif" alt="submit" width="48" height="48">

7. Functions – reusable blocks

   function showMessage(from, text) {
       alert(from + ': ' + text);
   }
   showMessage('Ann', 'Hello');
Functions can return values:



     function sum(a, b) {
          return a + b;
     }
     let result = sum(5, 3); // 8




      Parameters vs arguments: Parameters are declared in the function; arguments are passed when
      called.




8. Form objects & validation

JavaScript represents each form and its elements as objects you can access. The recommended modern way to
access individual fields is using   document.getElementById() .




     Accessing form fields with getElementById


     // Access by unique ID (recommended)
     let nameField = document.getElementById("username");
     let nameValue = nameField.value;


     // For forms, you can also get the form then its elements
     let myForm = document.getElementById("orderForm");
     let emailField = myForm.elements["email"]; // or use getElementById on each field




         Best practice: assign an   id   to each input field and access it directly with
          document.getElementById("fieldId") . This is cleaner and more reliable than navigating
      through forms array.




     Simple validation example using getElementById


     <SCRIPT>
     function validateForm() {
          let fname = document.getElementById("fname").value;
          if (fname == "") {
            alert("Name must be filled out");
            return false;
        }
        return true;
   }
   </SCRIPT>
   <FORM name="myForm" onsubmit="return validateForm()">
        Name: <INPUT type="text" id="fname" name="fname">
        <INPUT type="submit" value="Submit">
   </FORM>
