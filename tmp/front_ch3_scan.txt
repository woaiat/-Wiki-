1. Forms – accepting user input

  <FORM>       Forms are interactive elements that collect data from users. Example: OrderFoodOnline form.




    Scenario: FoodExpress.com / BookYourHotel – customers fill details like name, contact, preferences.




    Basic form structure


   <FORM name="OrderFoodOnline" method="post" action="process.html">
       ... form elements ...
   </FORM>




       Important form attributes


       ATTRIBUTE                                              DESCRIPTION


  name                    unique name for the form (used in scripts)


  id                      unique identifier for CSS/JavaScript


  action                  URL where form data is sent


  method                  "get" (appends data to URL, visible, limited) or "post" (secure, no size limit)


  autocomplete            "on" / "off" – browser autofill


  novalidate              disable browser validation


  target                  where to show response (_blank, _self, _parent, _top, frame_name)

8. Form objects & validation

JavaScript represents each form and its elements as objects you can access. The recommended modern way to
access individual fields is using   document.getElementById() .




     Accessing form fields with getElementById


     // Access by unique ID (recommended)
     let nameField = document.getElementById("username");
     let nameValue = nameField.value;


     // For forms, you can also get the form then its elements
     let myForm = document.getElementById("orderForm");
     let emailField = myForm.elements["email"]; // or use getElementById on each field




         Best practice: assign an   id   to each input field and access it directly with
          document.getElementById("fieldId") . This is cleaner and more reliable than navigating
      through forms array.




     Simple validation example using getElementById


     <SCRIPT>
     function validateForm() {
          let fname = document.getElementById("fname").value;
          if (fname == "") {
            alert("Name must be filled out");
            return false;
        }
        return true;
   }
   </SCRIPT>
   <FORM name="myForm" onsubmit="return validateForm()">
        Name: <INPUT type="text" id="fname" name="fname">
        <INPUT type="submit" value="Submit">
   </FORM>

1. What is jQuery?

   lightweight JS library      jQuery is an open‑source, cross‑browser JavaScript library that simplifies HTML
manipulation, event handling, and animation. It wraps complex JavaScript into one‑line methods.




     Why jQuery? Write less, do more. Abstracts browser inconsistencies, provides powerful selectors, and
     built‑in effects.




     Including jQuery in a Web Page


     <SCRIPT src="jquery-1.8.3.js"></SCRIPT>



You can download the library or use a CDN. The code must be placed after the jQuery file.



     document.ready() – ensure page is loaded


     $(document).ready(function(){
       // jQuery code executes after DOM is fully loaded
     });




           Prevents errors if script runs before elements exist




2. jQuery selectors
jQuery uses CSS‑like selectors to target elements. Basic syntax:   $(selector).action()




       By element name, ID, class


     $("h1")              // all <h1> elements
     $("#header")           // element with id="header"
     $(".product")          // all elements with class="product"
     $("h1#main")           // <h1> with id="main"
     $("div.product")       // <div> with class="product"




     By attribute


     $("[src]")                       // elements with src attribute
     $("[src='movie.jpg']")           // specific attribute value




     Nesting / hierarchy


     $("#menu ul")        // all <ul> inside element with id="menu"
     $("#menu li a")      // links inside list items inside menu




     Example: Hide all submenus on button click –     $('#menu ul').hide();

6. Real‑world example – sliding product menu

ShopForYou.com: product categories (Computers, Entertainment, Cameras) with sub‑items that slide toggle on
click.



     $(document).ready(function(){
          $("#menu ul").hide();       // initially hide submenus
          $("#menu li a").click(function(){
             $(this).next().slideToggle('slow');
          });
     });




            Click on "Laptops" → submenu slides down, click again → slides up




  7. Image gallery using colorbox plugin

jQuery plugins extend functionality. Colorbox is a lightweight lightbox plugin for image galleries and slideshows.
    Setup steps (summary)

   Download colorbox.zip and extract.
   Include    colorbox.css     and    jquery.colorbox.js .

   Call    $("a").colorbox();




    Basic usage – single image


    <LINK rel="stylesheet" href="css/colorbox.css">
    <SCRIPT src="jquery-1.8.3.js"></SCRIPT>
    <SCRIPT src="jquery.colorbox.js"></SCRIPT>
    <SCRIPT>
      $(document).ready(function(){
           $("a").colorbox();
      });
    </SCRIPT>
    <A href="product.png">View product</A>




     Customizing colorbox (transition, size)


    $("a").colorbox({
      transition: "fade",
      height: "250",
      width: "220"
    });




     Group of images (gallery with prev/next)


    <A rel="gallery" href="img1.jpg">Image 1</A>
    <A rel="gallery" href="img2.jpg"></A>
    <A rel="gallery" href="img3.jpg"></A>



Use same     rel   value to group images. Navigation arrows appear automatically.
