1. Introduction to CSS

   cascading style sheets      CSS is a collection of styles that allows you to change the appearance
of HTML elements on Web pages. It defines standard rules for layout and appearance, ensuring
consistent design across a website.




        Why CSS? Better control over page layout, enforce consistent display, separate content
     from presentation.




     Syntax of a CSS rule


    selector {
        property: value;
        /* multiple declarations */
    }



Example: make all <h1> red and italic, all <h2> bold.



    h1 { color: red; font-style: italic; }
    h2 { font-weight: bold; }

          result
                            Subheading




2. Types of style sheets
Three ways to apply CSS: inline, internal (embedded), external.



    ✏ Inline style
Applied directly to an element using the     style   attribute. Highest priority.



    <P style="font-size:24pt; color:red;">Hotel booking from the comfort of your room.
    </P>




       Hotel booking from the comfort of your room.




     Internal (embedded) style sheet
Defined inside    <STYLE>   in the    <HEAD> . Affects that page only.



    <STYLE>
      p { color:red; font-size:20pt; font-style:italic; }
    </STYLE>




     External style sheet
Separate   .css    file linked via   <LINK> . Best for multi‑page consistency.



    <LINK type="text/css" rel="stylesheet" href="externalstyle.css">



externalstyle.css content:



    p { color:red; font-size:20pt; }
    h1 { color:blue; font-weight:bold; }




    ⚖ Priority of style sheets (descending)

1. Inline style (highest)
2. Internal style sheet
3. External style sheet
4. Browser default
     If same selector appears in multiple sheets, the most specific (highest priority) wins.




3. CSS selectors – ID and class


     ID selector (#)
Used to style one unique element.



    #pname { color:green; font-weight:bold; }




    <P ID="pname">Welcome to BookYourHotel Website.</P>




       Welcome to BookYourHotel Website.




     Class selector (.)
Apply same style to multiple elements, possibly of different types.



    .first { font-size:20px; color:red; font-weight:bold; }




    <H1 class="first">Welcome</H1>
    <P class="first">This site gives info.</P>

5. Grouping and nesting styles


     Grouping selectors
Apply same style to multiple selectors using comma.



    h1, p { color: red; }




     Nesting selectors (contextual)


           SELECTOR                     EXAMPLE                      MEANING


 element1 element2                   div p             all <p> inside <div>


 element1 > element2                 div > p           <p> where parent is <div>


 element1 + element2                 div + p           <p> immediately after <div>


 element1 ~ element2                 div ~ p           <p> preceded by <div>




    li a { color: red; text-decoration: none; }       /* links inside list items */
  6. Controlling visibility


    Display property


    display: none;     /* hidden, no space */
    display: block;    /* takes full width, line break */
    display: inline;   /* only necessary width, no line break */



Example: horizontal menu with    display: inline



    li { display: inline; list-style-type:none; }




    Visibility property


    visibility: hidden;   /* hidden but space remains */
    visibility: visible; /* default */

7. Positioning HTML elements


    Position property


   VALUE                                         DESCRIPTION


 static       default, normal flow, no effect of top/left etc.
  relative          relative to its normal position; space preserved


  absolute          removed from flow; positioned relative to nearest positioned ancestor


  fixed             relative to viewport; stays when scrolling




      h3 { position: absolute; top:0px; }



Use     top, bottom, left, right, z-index            with non‑static.



       Float & clear


      float: left | right | none;
      clear: both | left | right;



Float moves element to side, text wraps. Clear turns off float effect.



      img { float: left; }
      .special { clear: both; }

1. Why tables? Structured information

Tables present complex data in rows and columns, making it readable. Example: LearnMySQL data types shown
as table vs. plain text.

      Char(M) Fixed 0-255
      Varchar(M) Variable 0-255




                    NAME                                   LENGTH                           RANGE

  Char(M)                                     Fixed                              0-255

  Varchar(M)                                  Variable                           0-255


   core tag        Tables are created with   <TABLE> . Use    border    attribute to show borders.




2. Basic structure of a table

A table can be split into header (<THEAD>), body (<TBODY>), and footer (<TFOOT>). Caption gives a title.



      Minimal table with rows & columns


     <TABLE border="1">
        <TR><TD>Name</TD><TD>Login ID</TD></TR>
        <TR><TD>Steve</TD><TD>01234</TD></TR>
     </TABLE>




     Name                                          Login ID

     Steve                                         01234


         simple table
   Using <THEAD>, <TBODY>, <TFOOT> (order: THEAD, TFOOT,
  then TBODY)


  <TABLE border="1">
       <CAPTION>Test Results</CAPTION>
       <THEAD>
        <TR><TH>Name</TH><TH>Marks</TH></TR>
       </THEAD>
       <TFOOT>
        <TR><TD colspan="2">Total: 3 students</TD></TR>
       </TFOOT>
       <TBODY>
        <TR><TD>Joseph</TD><TD>98</TD></TR>
        <TR><TD>Steve</TD><TD>92</TD></TR>
       </TBODY>
  </TABLE>




   <TH> vs <TD>
<TH>    creates header cells (bold, centered),   <TD>   standard data cells.

4. Styling tables with CSS

CSS properties to improve table appearance:



        PROPERTY                              EFFECT                        EXAMPLE


    border                    sets border width/style/color        border: 1px solid brown;


    border-collapse           collapse/separate borders            border-collapse: collapse;

  5. Frames – displaying multiple pages

A frame is a rectangular region in a browser window that displays a separate Web page. In modern HTML we use
  <IFRAME>     (inline frame).
Example: LearnMySQL site with header, navigation, content frames.



     <IFRAME> basic attributes


           ATTRIBUTE                                                  PURPOSE


    src                           URL of the page to embed


    name                          target name for links


    height / width                size of the iframe


    seamless                      boolean – frame appears part of page (no borders/scrollbars)


    srcdoc                        inline HTML to display (overrides    src )




     Creating three frames (home.html)


     <IFRAME name="HeaderFrame" width="91%" height="100" srcdoc="<h1>Learn MySQL</h1>">
     </IFRAME>
     <IFRAME src="nav.html" name="NavigationFrame" width="25%" height="500"></IFRAME>
     <IFRAME name="ContentFrame" width="65%" height="500"></IFRAME>




     Targeting a frame (anchor target)
Make links open inside a specific iframe using   target="frameName" .



     <A href="courses.html" target="ContentFrame">Courses</A>




          ↪ Click → opens in "ContentFrame"
6. Styling frames with CSS

    PROPERTY                                                   EFFECT


   margin               space outside the iframe


   padding              space between border and content


   border               border thickness, style, color


   scrolling            yes/no/auto (not CSS, but an attribute; can be styled via overflow in CSS)




    iframe {
        border: 5px solid black;
        margin-left: 1px;
        padding: 2px;
    }
