        Better Performance
        Minimal DOM operations
        Faster UI updates
        More efficient




       Summary: Vue uses Virtual DOM as an intermediary layer. When data changes, it updates the

      necessary changes to the Real DOM.

 2. Data as a Function – Independent State Isolation


⚠ Critical Concept: In Vue components, data must be a function that returns a fresh object. If it were a plain
object, all instances would share the same reference, causing mutations to affect every component. This
pattern guarantees each instance has its own private reactive scope.

data() { return { count: 0 } } → correct.
data: { count: 0 } → wrong (Vue 3 throws warning).

Local Registration means a component is available only inside the component where it is registered (via

It's the recommended way for most components.

 4. Global Registration – One-Time, Use Everywhere


 Global Components are registered using app.component('name', Component) in main.js. After registration, they
can be used in any component template without importing. Best for high-frequency UI pieces (alerts, modals,
buttons). Vue 3 migrated from Vue.component to app.component.



//   main.js
import { createApp } from "vue";
import App from "./App.vue";
import GlobalAlert from "./components/GlobalAlert.vue";


const app = createApp(App);
app.component("GlobalAlert", GlobalAlert);   //   GLOBAL REGISTRATION
app.mount("#app");


//   src/components/GlobalAlert.vue
<template>
  <div class="alert-box" v-if="isVisible">

      <p>{{ message }}</p>
     </div>
     <button class="close-btn" @click="closeAlert">✖</button>
  </div>
</template>


<script>
export default {
  name: "GlobalAlert",

 Explanation: After app.component(), the GlobalAlert component becomes globally available. You never need to import it in

 1. v-if Directive – Conditional Rendering


 Theory: The v-if directive is used to conditionally render a block. The element with v-if will only be
produced if the directive's expression returns a true value. If the expression produces an invalid result (null,
0, empty string, false), the element is deleted from the DOM.

v-if – Renders element only if condition is true
v-else – Renders element when v-if is false (must immediately follow v-if)
v-else-if – Chains multiple conditions




//    Vue 3 Component - VIfDemo.vue
<template>
  <div id="databinding">
      <button @click="showdata" :style="styleobj">Click Me</button>
      <span style="font-size:25px;"><b>{{ show }}</b></span>
      <h1 v-if="show">This is h1 tag</h1>
      <h2>This is h2 tag (always visible)</h2>
  </div>
</template>


<script>
export default {
  name: "VIfDemo",
  data() {
      return {
          show: true,
          styleobj: {
              backgroundColor: "#2196F3",
              cursor: "pointer",
              padding: "8px 16px",
              verticalAlign: "middle",
              border: "none",
              borderRadius: "4px",
              color: "white"
          }
      };
  },
  methods: {
      showdata() {
          this.show = !this.show;
      }
  }
};
</script>




 Explanation: When show is true, the h1 tag is displayed. Clicking the button toggles show to false, and Vue removes the h1
tag from the DOM entirely. The h2 tag is always visible because it has no directive.
⚡ Live Demo: v-if Directive


       Click the button — the h1 tag disappears completely from the DOM when show becomes false.

      3. v-show Directive – CSS Display Toggle


Theory: v-show behaves similarly to v-if but with a key difference: v-if removes/adds the element from the
DOM, while v-show only toggles the element's display CSS property (display: none when false). The element
always remains in the DOM.



//    Vue 3 Component - VShowDemo.vue

      <span style="font-size:25px;"><b>{{ show }}</b></span>
      <h1 v-if="show">This is h1 tag (v-if)</h1>
      <h2 v-else>This is h2 tag (v-else)</h2>
      <div v-show="show">
          <b>V-Show:</b>
          <img src="https://picsum.photos/id/10/100/100" width="100" height="100" />
      </div>
  </div>
</template>


<script>
export default {

              cursor: "pointer",
              padding: "8px 16px",
              verticalAlign: "middle",
              border: "none",
              borderRadius: "4px",
              color: "white"
          }
      };
  },
  methods: {
      showdata() {
          this.show = !this.show;
      }
  }
};
</script>




 Explanation: The image inside v-show is always in the DOM. When show is false, it's hidden with display: none. When true,

 4. v-for Directive – List Rendering
 Theory: The v-for directive renders a list of items based on an array. The syntax is item in items where items
is the source array and item is the alias for each element. Note: Vue 3 requires a :key attribute for each
rendered item.



//    Vue 3 Component - VForDemo.vue
<template>
  <div id="databinding">
      <input
          type="text"
          @keyup.enter="showinputvalue"
          :style="styleobj"
          placeholder="Enter Fruits Names"
      />
      <h1 v-if="items.length > 0">Display Fruits Name</h1>
      <ul>
          <li v-for="(a, index) in items" :key="index">{{ a }}</li>
      </ul>
  </div>
</template>


<script>
export default {
  name: "VForDemo",
  data() {
      return {
          items: [],
          styleobj: {
              width: "30%",
              padding: "12px 20px",
              margin: "8px 0",
              boxSizing: "border-box",
              border: "2px solid #ccc",
              borderRadius: "4px",
              fontSize: "16px"
          }
      };
  },
  methods: {
      showinputvalue(event) {
          if (event.target.value.trim()) {
              this.items.push(event.target.value.trim());
              event.target.value = "";
          }
      }
  }
};
</script>




 Explanation: The input field captures fruit names. When Enter is pressed, the value is added to the items array. v-for
iterates over the array and displays each item as a list item. The :key="index" helps Vue track each item uniquely.




⚡ Live Demo: v-for Directive


       Type a fruit name and press Enter — it gets added to the list. Each new item appears automatically!




 5. Fade Transition – Smooth Opacity Change
Theory: Vue provides a <transition> wrapper component to apply animations when elements are inserted,
updated, or removed. The name attribute defines the prefix for transition classes. For fade transition, Vue
applies .fade-enter-active, .fade-leave-active, etc.




//      Vue 3 Component - FadeTransitionDemo.vue
<template>
    <div id="databinding">
        <p>Click at the below button to see transition effect.</p>
        <button @click="show = !show" class="btn-primary">Click Here</button>


        <transition name="fade">
         <p v-show="show" :style="styleobj">This is a Fade Transition Example</p>
        </transition>
    </div>
</template>


<script>
export default {
    name: "FadeTransitionDemo",
    data() {
        return {
         show: true,
         styleobj: {
             fontSize: "30px",
             color: "red"
         }
        };
    }
};
</script>


<style scoped>
.fade-enter-active,
.fade-leave-active {
    transition: opacity 3s;
}


.fade-enter,
.fade-leave-to {
    opacity: 0;
}
</style>




Explanation: The <transition name="fade"> wraps the element. CSS classes define a 3-second opacity transition. When
element enters, it fades in from opacity 0 to 1. When leaving, it fades out from 1 to 0.

        Click the button — the text fades out over 3 seconds. Click again — it fades back in over 3 seconds.

 8. Custom Transition Classes – Animate.css Integration


Theory: Vue allows custom transition classes like enter-active-class and leave-active-class to integrate with
external CSS animation libraries (e.g., Animate.css). This eliminates the need to write custom CSS
animations.

Custom class attributes: enter-class · enter-active-class · enter-to-class · leave-class · leave-active-class ·
leave-to-class




//      Vue 3 Component - CustomTransitionDemo.vue

        <button @click="show = !show" class="btn-primary">
            <span style="font-size:25px;">Click Here</span>

        <transition
            enter-active-class="animate__animated animate__swing"
            leave-active-class="animate__animated animate__bounceOut"
        >
            <p v-if="show" class="animation-text">
             <span style="font-size:25px;">See the animation effect</span>
            </p>
        </transition>
    </div>
</template>


<script>
export default {
    name: "CustomTransitionDemo",
    data() {
        return {
            show: true
        };
    }
};
</script>


<style scoped>

    display: inline-block;

    border-radius: 15px;
    color: white;

}
</style>




Explanation: Instead of writing custom CSS animations, we use Animate.css classes. enter-active-class="animate__animated

 Transition Classes Reference


Standard Classes (prefixed with transition name):

v-enter – Starting state before element is added
   v-enter-active – Active state during entering (defines delay, duration, easing)
   v-enter-to – Ending state for entering (Vue 2.1.8+)
   v-leave – Starting state for leaving transition
   v-leave-active – Active state during leaving (defines delay, duration, easing)
   v-leave-to – Ending state for leaving (Vue 2.1.8+)

   Custom Class Attributes:

   enter-class – Custom class for entering start state
   enter-active-class – Custom class for entering active state
   enter-to-class – Custom class for entering end state
   leave-class – Custom class for leaving start state
   leave-active-class – Custom class for leaving active state
   leave-to-class – Custom class for leaving end state
