1. Basic structure of an HTML page

 structural tags     Every HTML document follows a fixed skeleton.




   Minimal HTML5 template


   <!DOCTYPE HTML>
   <HTML>
     <HEAD>
       <TITLE>Home Page of Book Your Hotel</TITLE>
     </HEAD>
     <BODY>
       Book your favorite hotel.
     </BODY>
   </HTML>




      browser output (chrome / edge)         Book your favorite hotel.




            TAG                 TYPE                           DESCRIPTION


  <!DOCTYPE HTML>           empty        Instructs browser about HTML5 version; must be first.


  <HTML> ... </HTML>        container    Root element – wraps entire page.


  <HEAD> ... </HEAD>        container    Header section: meta, title, styles, scripts.


  <BODY> ... </BODY>        container    Contains visible content (text, images, links).




    container vs empty: Container (paired) tag needs closing      </...> . Empty tag has no
   content & no closing (e.g.   <!DOCTYPE HTML> ,    <BR> ).
2. Exploring the <HEAD> section

The     <HEAD>    can contain   <TITLE> ,    <META> ,   <STYLE> ,   <LINK> ,   <SCRIPT> ,
 <BASE> ,        <NOSCRIPT> .




        <TITLE>     – browser tab & search results


      <HEAD>
        <TITLE>Book Your Hotel</TITLE>
      </HEAD>




         title bar shows: "Book Your Hotel" (only one per doc)




          <META>      – metadata for search engines


      <HEAD>
        <META name="description" content="Best hotel booking in US">
        <META name="keywords" content="hotel, online booking, rooms">
        <META name="author" content="Harry Anem">
        <META http-equiv="refresh" content="30">
      </HEAD>




          ATTRIBUTE                  EXAMPLE VALUE                         PURPOSE


      name="description"           "online hotel                 short summary for search
                                  booking"                       engines


      name="keywords"              "hotel, booking"              relevant search keywords


      name="author"                "Harry Anem"                  document author


      http-                        content="30"                  auto-refresh every 30 seconds
 equiv="refresh"




        <LINK>     – external relationships
    <LINK href="StyleHome.css" rel="stylesheet">



Attributes:   rel ,     href ,     hreflang ,    media   (screen, handheld, tv …).



       <SCRIPT>       – client-side scripting


    <SCRIPT type="text/javascript">
       var name = prompt("Please Enter Your Name","John");
       alert(name);
    </SCRIPT>



Attributes:   async ,        defer ,   src ,    type .




       <BASE>      – base URL for relative links


    <BASE href="d:/assets/img/">
    <!-- then <IMG src="mg1.jpg"> resolves to d:/assets/img/mg1.jpg -->

Difference between <DIV> and <SPAN>


                         <DIV>                                <SPAN>
  Type            block-level element                   inline element


  Behaviour       starts on new line, takes full        stays within the same line, only takes needed
                  width                                 space


  Common          group large sections / layout         style small portions of text / inline grouping
  use             blocks




    <DIV style="background:#d9eaff; padding:10px;">
        This is a DIV (block) – it creates a new block.
    </DIV>
    Just before <SPAN style="background: #ffe7b3; padding:3px;">this SPAN</SPAN> stays
    inline.




     This is a DIV (block) – it creates a new block.

    Just before this SPAN stays inline.

         ✅ DIV → block ; SPAN → inline




     <DETAILS> and <SUMMARY> (interactive
    disclosure widget)
How it works: The       <SUMMARY>    element provides a visible heading that users can click. When
clicked, it toggles the visibility of the additional content inside   <DETAILS>   – showing or hiding it
without JavaScript.



    <DETAILS>
        <SUMMARY>Categories of Rooms:</SUMMARY>
        <P>Standard, deluxe, suite …</P>
    </DETAILS>




        Categories of Rooms:     ▶ click summary to expand/collapse




  4. Adding images & multimedia

Image formats commonly used: GIF (drawings), JPEG (photos), PNG (high resolution).
       <IMG>     with attributes


  <IMG src="Room.jpg" alt="Deluxe Room" width="304" height="228">




       <AUDIO>    – simple audio player


  <AUDIO controls src="Audio1.mp3">
       Your browser does not support audio.
  </AUDIO>




       <VIDEO>    – with controls & autoplay


  <VIDEO width="320" height="240" controls autoplay src="video.mp4">
       Video fallback text.
  </VIDEO>




  ATTRIBUTE                        EXAMPLE                      DESCRIPTION


autoplay                autoplay                       starts as soon as ready


controls                controls                       show play/pause/volume


loop                    loop                           restart when finished


muted                   muted                          audio output muted


poster                  poster="preview.jpg"           image while video loads




5. Measuring data & progress bars


    <METER>      – gauge (disk usage, scalar)
<METER value="4" min="0" max="10"></METER>        <!-- 4 out of 10 -->




                           ⚡ 40%




 <PROGRESS>      – task completion


Download: <PROGRESS value="12" max="100">12%</PROGRESS>




                              12% completed




   max     = total work,   value   = completed portion.




6. Semantic tags (HTML5) – meaning &
structure

                 TAG                                            PURPOSE


<ARTICLE>                                  self-contained content (blog post, news)


<ASIDE>                                    sidebar, note, tip (related to main)


<HEADER>                                   introductory heading / navigational block


<FOOTER>                                   footer for page/section (copyright, author)



<NAV>                                      navigation links


<FIGURE>    +   <FIGCAPTION>               image with caption

   <FIGURE>
        <FIGCAPTION> Deluxe Room</FIGCAPTION>
        <IMG src="Room.jpg" alt="deluxe" width="200">
   </FIGURE>




          Deluxe Room [caption + image]




    sample           <ARTICLE>    +     <ASIDE>




   <ARTICLE>
        <H3>BookYourHotel Blog</H3>
        <P>This blog provides hotel details.</P>
   </ARTICLE>
   <ASIDE>
        <P>Get discounts on booking rooms today!</P>
   </ASIDE>




7. Navigation – <A> (anchor) tag

   <A href="homepage.html" target="_blank">BookYourHotel</A>



 href    specifies the URL of a page or any website;   target   can open in a new window/frame
( "Frame1" ,    "_blank" ).




  8. Web page types & editors

   Static web page: fixed content.
   Dynamic web page: generated in real-time (e.g., news sites, Youku).
   Text editor: Notepad, VS Code – save with .htm or .html.
   Graphic editor (WYSIWYG): Dreamweaver – drag & drop elements.

The Internet is an interconnected network; the World Wide Web is a collection of interlinked pages.
